# 图像模板库（MOSS 文生图填空）

用法：认类型 → 复制模板 → 只填 `〔　〕` → 跑 `提示词体检.md`（`--kind image`）。
MOSS 不支持图生图；换装/改光/改表情走 Qwen-Image 编辑指令（见 `提示词.md` 8.5）。

通用铁律：全简体中文、第三人称、现在时、肯定句；只写看得见的东西；不写负向句、不写比例/分辨率/步数、不写"杰作/8K/电影级"。

---

## 模板 1｜人物定妆（正面半身）

适用：主角第一次出场、需要一张"认人"的脸。

```
〔年龄〕岁〔性别〕，〔发型：长度+分缝+束法〕，〔脸型〕、〔眉/眼/痣/疤等一两个特征〕，〔服装：颜色+材质+领口+纹样〕，〔标志物：饰品/武器/持物〕。〔姿态：站姿/半身/朝向〕，〔神情：目光方向 + 嘴角/眼睑状态〕。半身〔景别〕，〔机位：平视/略俯/略仰〕，背景为〔纯色浅灰/环境〕，〔光线：光源+方向+色温/柔光〕，〔色调质感：冷暖+对比+胶片或写实〕。
```

例：
> 二十九岁东亚男性，黑色短发侧分、鬓角修短，方脸、左眉一道浅疤，深灰粗布对襟短衫、立领、袖口卷到小臂，左腕缠一圈旧麻绳。半身站姿，面朝镜头略偏左，目光平视，嘴角放松。半身近景，平视机位，背景为浅灰纯色，左侧柔光打亮面部、右侧留一点暗部，冷灰调、低饱和、写实质感。

## 模板 2｜角色三视图（设定板）

适用：要保证后面每一集都长得一样时。

```
一张角色设定板，纯色浅灰背景。〔左约三分之一为面部大特写，右侧为正面、侧面、背面三视图全身像〕。人物：〔五件套完整复写〕。三视图统一〔站姿：双脚与肩同宽、双手自然下垂/持物〕，服装与发型在三个视角完全一致。〔光线：均匀柔光，无强投影〕，〔色调质感〕。
```

常见错：三视图里写"同上"；只写正面不写背面细节（披风/发髻会崩）。

## 模板 3｜场景板（空间与光）

适用：一场戏反复出现的空间。

```
〔地点：室内/室外 + 具体空间〕，〔空间结构：几面墙/门窗位置/层高/纵深〕，〔陈设：前景、中景、远景各一两个物件〕，〔材质与状态：木/砖/金属 + 旧/新/潮湿/积尘〕。〔光线：光源位置+类型+色温+光比〕，〔时间与天气〕，〔色调质感：冷暖+对比+颗粒〕，无人，广角全景，平视机位。
```

常见错：只写"一个破旧的房间"；不写门窗位置（后面接不上轴线）；不写光从哪来。

## 模板 4｜道具板（视角按「怎么用」定，不按数量套）

先问三件事：①这件道具在分镜里**怎么出现**（被拎起、放桌上、插在鞘里、拔出、掰开、递出……）；②**哪一面/哪个细节**决定观众认得出它；③有没有**装饰、刻字、磨损**需要特写。

视角 = 覆盖「出现形态」+ 必要细节；**2–4 个，不固定**。

| 道具类型 | 建议视角 |
|---|---|
| 称量类（杆秤 / 天平 / 斗） | 被拎起的全身（手提提纽、秤砣下垂）＋放在桌面的全身＋刻度/秤星特写 |
| 刀剑类 | 插在鞘中的全身＋拔出后与鞘并排＋护手/鞘口/铭文特写 |
| 食物（窝头 / 馍 / 饼） | 整只（或一摞）＋掰开/咬口＋（可选）表面颗粒特写 |
| 木棍 / 棍棒 | 整根＋手握段与端头（可选 1 张特写） |
| 信物 / 首饰 | 正面＋背面＋刻字/镶嵌特写 |
| 容器 / 器皿 | 正放＋俯视开口＋（可选）纹样特写 |

写作模板：

```
〔道具名〕的〔N〕个视角：〔形态1：被拎起／放桌面／插在鞘中…〕的全身、〔形态2〕、〔关键细节〕特写；
结构：由〔零件1：材质+形状〕、〔零件2〕、〔零件3〕组成，零件之间〔连接方式〕；
尺寸：〔全长/直径/能否单手握住〕；表面：〔主材颜色+纹理、磨损/包浆/缺口〕；
风格：写实电影道具感、实拍级材质、低饱和自然色、柔和侧光＋侧逆光勾边、浅景深；纯中性灰背景，无手、无人、无参照物、无其它道具；4K 细节。
```

注意：
- 形态词要写具体（「被拎起时秤砣自然下垂」「插在鞘中只露护手」），不要只写「正面图」；
- 特写只给**决定辨识度**的部位（秤星、护手、刻字、咬口），不为凑数加；
- 一件一板；尺寸只用文字，画面里不许放手/硬币/尺子当参照。

常见错：
- 只写「一把宝剑／一根木棍」→ 零件不足，模型自由发挥成别的东西；
- 给窝头硬凑四视角 → 每张都糊，还浪费生成时间；
- 画面里加手／硬币当尺度 → 模型画成握着它的手，或把参照物当剧情道具；
- 刻字写具体汉字 → 必糊，改「刻着磨平的字迹」。

## 模板 5｜状态变体（同一人物的伤/换装/年龄）

适用：剧情推进后人物状态变化，但要认得出是同一个人。

```
同一人物〔五件套原样复写〕，变化：〔只写改动的那一处：左颊浅红划痕 / 外披湿透的黑斗篷 / 少年时期，发型改短寸〕。其余〔发型/脸型/服装主体/标志物〕保持完全不变。〔姿态与景别同模板 1〕，〔光线与色调同前一张，保证像同一天拍的〕。
```

常见错：一次改三处；不写"其余不变"；光线换了导致像两个人。

## 模板 6｜首尾帧（给视频当参考）

适用：要让某一镜的首帧/尾帧精确可控。

```
〔首帧/尾帧〕画面：〔五件套〕，〔姿态与朝向：面朝画左/背对镜头〕，〔动作停在：手举到胸前、刀尖朝下〕，〔构图：主体在画左三分之一，右侧留出〔空间〕给后续动作〕，〔景别 + 机位 + 焦段感〕，〔光线与色温同该场主光〕，〔背景与场景板一致〕，〔质感〕。
```

要点：首帧要留出动作空间；尾帧要写"停在哪"，不要写"正在做"。

## 图像体检清单（30 秒）

1. 主体五件套齐了吗（年龄性别/发型/脸型特征/服装/标志物）？
2. 有姿态与朝向吗？有景别与机位吗？
3. 环境写了几层（至少背景 + 一个前/中景物件）？
4. 光线有方向与色温吗？色调质感有一句吗？
5. 有没有负向句、比例数字、分辨率、"杰作/8K"？
6. 出现画内文字了吗？有就给原文 + 载体 + 位置 + 颜色，且尽量少。
