# 样本库：正样本 + 反例（越用越准）

这份文件让提示词从"每次从零写"变成"先抄好用的、再补差异"。
两件事：**收成功案例**（正样本）、**记失败词组**（反例）。

---

## 一、存放位置与命名

正样本存在项目目录下，不放在技能里（技能是公共的，样本是这部戏的）：

```
<项目>/.agent/样本库/
  index.md                  ← 索引表（每行一条，方便检索）
  shots/对话-001.md         ← 单条样本
  shots/打斗-003.md
```

单条样本格式（`shots/<类型>-<序号>.md`）：

```markdown
---
id: 对话-001
类型: 对话 | 打斗 | 情绪 | 转场 | 特写 | 群像
模型: Pika H3全参 | MiniMax H3 原版 | MOSS 文生图
时长: 6s
比例: 16:9
标签: [雨夜, 审讯, 双人, 中近景]
成片: assets/<节点ID>/xxx.mp4
结论: 可用（人物稳定，光位正确，口型略慢）
---

<提示词全文，六段式原样粘贴>

---
## 为什么好
- 写清了三件可拍的事：〔…〕
- 空间锚明确：〔…〕
- 声音点齐全：〔…〕
## 下次可复用的部分
- 光位句：〔…〕
- 动作分解：〔…〕
```

索引表 `index.md`：

```markdown
| id | 类型 | 模型 | 时长 | 标签 | 成片 | 结论 |
|---|---|---|---|---|---|---|
| 对话-001 | 对话 | Pika H3全参 | 6s | 雨夜/审讯 | assets/…/a.mp4 | 可用 |
```

## 二、什么时候写正样本

满足全部三条才收：
1. 成片通过抽帧自检（人物不漂、手不崩、文字不乱、光向一致）；
2. 用户没有提出返工；
3. 提示词的"信息单元"齐全（见 `提示词.md` §6.5）。

收的时候顺手写下"可复用的句子"，下次直接抄句型，不要抄内容。

## 四、失败案例怎么记

每次返工，在项目 `.agent/复盘.md` 记三行：现象 → 根因 → 规则。
如果根因是"某句话模型听不懂"，就把那句话加进上面的反例表，**当场改**，不要等下次。

高频根因对照：

| 现象 | 根因 | 规则 |
|---|---|---|
| 人物越演越不像 | 只写"保持外貌" | 写五件套；retention 里逐项列 |
| 动作没做完就切 | 没写结束态 | 每镜结尾写停在哪 |
| 画面糊成一团 | 一镜多运镜 | 一镜一个主运镜 |
| 音乐太满 | 没写动态/进入点 | 写乐器+节奏+动态+N/A 判断 |
| 口型不对 | 一句太长/多人同镜说话 | 一句一镜，一人说话 |
| 文字崩坏 | 画面出现招牌/纸张 | 规避载体或拍背面 |
| 风格每镜不同 | 没定风格锚 | 每集开头定风格锚，逐镜复用 |

## 五、检索与复用流程

1. 新镜头 → 先看类型与标签，在 `index.md` 里找同类样本（2–3 条）。
2. 抄"可复用的句子"（光位句、动作分解句、声音层句），不抄内容。
3. 按 `镜头模板.md` 填槽位，把抄来的句子塞进去。
4. 跑 `提示词体检.md`，通过再交。
5. 生成后：通过就收正样本；返工就补反例。
