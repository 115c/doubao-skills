# 镜头模板库（六段式填空）

用法：先认镜头类型 → 复制对应模板 → 只填 `〔　〕` 槽位 → 过 `提示词体检.md`。
**不要自由发挥结构**；结构固定，只换内容。每镜都要独立成段，不要把两镜写进一个模板。

通用约定：
- `〔S1〕` 这类指代必须与画布上的参考图/参考视频/参考音频编号一致；没有素材就不写 `<Subject N>`，改写"三十岁男性，短寸头…"。
- 时间锚 `At 00:0S.mmm` 从 `[Shot 2]` 起必须有，且严格递增。
- 每镜至少 1 个结束态（手停哪、重心在哪只脚、道具什么状态）。

---

## 模板 1｜对话镜（两人同框，一人说话）

适用：信息交换、试探、摊牌、吵架前段。默认 3–6 秒。

```
subject_definitions:
Subject 1 = 〔S1：身份 + 五件套外貌锚点〕；
Subject 2 = 〔S2：身份 + 五件套外貌锚点〕；
场景 = 〔地点 + 空间结构 + 主光位〕。
summary: 对话镜头，〔谁〕向〔谁〕说〔什么目的〕，〔对方反应〕。
retention_analysis: Subject 1 保留〔发型/服装/持物〕；Subject 2 保留〔…〕；场景保留〔…〕；〔不要复制：背景行人/文字/原片色调〕。
detailed_description:
[Shot 1] 〔景别〕，〔焦段〕，机位〔高度 + 方位〕，〔构图：谁在画左/画右，隔什么〕。〔S1〕〔姿态 + 手部 + 朝向〕，〔S2〕〔姿态 + 视线〕。
At 00:0〔X〕.〔XXX〕，〔S2〕〔动作：抬眼/侧头/后退半步〕，〔S1〕〔反应：喉结动/指节收紧/呼吸停半拍〕。
At 00:0〔Y〕.〔XXX〕，〔S1〕开口说话，〔语速 + 语气 + 重音〕，说完〔Closing Beat：垂眼/放杯/转头〕。
〔收尾锁：两人服装、持物、站位全程不变。无第三人物入画。〕
overall_soundscape: 〔环境底噪〕；〔空间回声/混响〕；〔动作声 + 第几秒〕；〔呼吸/衣物摩擦〕；对白见台词。
non_diegetic_music: 〔乐器 + 节奏 + 动态 + 是否人声；不要写 N/A〕。
```

台词写法（单独一行放在 detailed_description 里说话处）：
`(S1) <d>[Chinese] 〔原句〕</d>`

常见错：两人并排站却写"正反打"；只写情绪词（"气氛尴尬"）；台词没进 `<d>`。

## 模板 2｜打斗镜（含命中）

适用：交手、格挡、命中、收势。默认 4–8 秒，命中镜单独成镜。

```
subject_definitions:
Subject 1 = 〔S1：身份 + 兵器 + 服装锚点〕；
Subject 2 = 〔S2：身份 + 兵器 + 服装锚点〕；
场景 = 〔场景 + 地面材质 + 主光位〕。
summary: 〔谁〕对〔谁〕发起〔哪一招〕，命中〔部位〕，结果〔击退/格挡/破防〕。
retention_analysis: Subject 1 保留〔兵器握法/发型/服装〕；Subject 2 保留〔…〕；〔不复制原片脸/背景〕。
detailed_description:
[Shot 1] 〔景别〕，〔焦段〕，机位〔高度 + 相对方向〕。〔S1〕〔起势：重心 + 发力点 + 兵器位置〕。
At 00:0〔X〕.〔XXX〕，〔S1〕〔出招：轨迹 + 速度 + 幅度〕，〔S2〕〔应对：格挡/侧闪 + 身体位移〕。
At 00:0〔Y〕.〔XXX〕，接触：〔命中点 + 火花/碎屑 + 约两帧微停顿〕，〔受力方反应 + 位移 + 兵器偏移〕。
At 00:0〔Z〕.〔XXX〕，收势：〔双方新站位 + 兵器朝向 + 结束态〕。〔无对白，嘴唇闭合。兵器与服装全程不变。〕
overall_soundscape: 〔环境底噪〕；〔起手衣物/脚步〕；〔兵器摩擦 + 第几秒〕；〔命中声 + 力度〕；〔喘息/闷哼〕；〔回声〕。
non_diegetic_music: 〔低频脉冲/鼓点 + 进入点 + 是否随命中重音〕。
```

常见错：一镜塞三招；没写命中后的位移；把冲击帧写进提示词（应后期做）。

## 模板 3｜情绪镜（单人，无台词或极少）

适用：崩溃、隐忍、决意、回忆。默认 3–5 秒。

```
subject_definitions:
Subject 1 = 〔S1：身份 + 五件套〕；场景 = 〔…〕。
summary: 〔谁〕在〔情境〕下〔情绪转折：从 A 到 B〕。
retention_analysis: Subject 1 保留〔…〕；〔不复制原背景〕。
detailed_description:
[Shot 1] 〔景别：中近景/特写〕，〔焦段〕，机位〔高度 + 距离〕。〔S1〕〔起始姿态 + 视线落点〕。
At 00:0〔X〕.〔XXX〕，〔微动作：眼睑/嘴角/喉结/手指/呼吸，逐个写〕。
At 00:0〔Y〕.〔XXX〕，〔转折动作：抬头/闭眼/攥拳/转身〕，〔结束态：停在哪一帧的姿势〕。
〔无对白，嘴唇闭合。面部特征与服装不变。〕
overall_soundscape: 〔环境底噪压低〕；〔呼吸 + 第几秒变重〕；〔衣料摩擦〕；〔空间回声变空〕。
non_diegetic_music: 〔单乐器长音 + 进入点 + 渐强/渐弱〕。
```

常见错：写"她很伤心"；写"泪流满面"却不给眼睑/呼吸动作；镜头一直推。

## 模板 4｜转场镜（空间/时间跳转）

适用：换场、时间跳跃、回忆进入。默认 2–4 秒。

```
subject_definitions:
Subject 1 = 〔S1 或"无人"〕；场景 = 〔新场景 + 与上一镜的空间关系〕。
summary: 从〔上一场〕转到〔本场〕，靠〔物件/动作/光线〕完成过渡。
retention_analysis: 保留〔贯穿物件/光向〕；不复制〔上一场人物〕。
detailed_description:
[Shot 1] 〔景别〕，〔焦段〕，机位〔…〕。〔过渡载体：门/走廊/雨/烟/车灯/手部特写〕，〔运动方向从画左到画右〕。
At 00:0〔X〕.〔XXX〕，〔切换点：进入新空间的光线/声音先到，人物后到〕。
〔新空间第一次出现的三个信息：地点、时间、天气/光〕。
overall_soundscape: 〔上一场声音延续 0.5 秒后衰减〕；〔新场环境声渐入 + 第几秒〕。
non_diegetic_music: 〔过渡用单音/留白；不要两段音乐硬切〕。
```

常见错：用"淡入淡出"（模型做不好）；转场里塞信息；新场没有声音先到。

## 模板 5｜特写镜（物件/手部/面部细节）

适用：证据、道具、表情、杀意。默认 2–4 秒。

```
subject_definitions:
Subject 1 = 〔S1 或物件编号〕；场景 = 〔…〕。
summary: 特写〔物件/部位〕，让观众看到〔关键信息〕。
retention_analysis: 保留〔材质/纹路/持物手〕；不复制〔背景杂物〕。
detailed_description:
[Shot 1] 特写/大特写，〔焦段：85–135mm〕，机位〔与主体平齐/略俯〕，浅景深。〔主体占画面约〔X〕成〕，〔光从哪来、打亮哪一面〕。
At 00:0〔X〕.〔XXX〕，〔微动作：指尖划过/刀锋反光/瞳孔收缩/水珠滑落〕。
〔结束态：停在〔某细节〕上 0.5 秒。无文字、无多余手指。〕
overall_soundscape: 〔近距离材质声：金属/布料/呼吸/心跳 + 秒点〕。
non_diegetic_music: 〔极简或 N/A；紧张时用低频单音〕。
```

常见错：特写里塞全景信息；手部动作写不清；光位没写导致塑料感。

## 模板 6｜群像/环境镜（多人或大空间）

适用：开场、势力展示、战场全景。默认 5–8 秒。

```
subject_definitions:
Subject 1 = 〔主角 + 五件套〕；Subject 2 = 〔…〕；Subject 3 = 〔…〕；场景 = 〔空间结构 + 光源 + 天气〕。
summary: 〔地点〕的〔势力/环境〕状态，〔主角〕在其中〔位置〕。
retention_analysis: 每个 Subject 保留〔可辨识特征〕；不复制〔原片人群密度/文字招牌〕。
detailed_description:
[Shot 1] 〔大远景/远景/全景〕，〔焦段 24–35mm〕，机位〔高/低 + 方位〕，〔横向展开：谁在画左、谁在中、谁在右〕。
〔环境三层：前景遮挡 / 中景主体群 / 远景天际线或建筑〕。
At 00:0〔X〕.〔XXX〕，〔镜头运动：横移/升降/缓推，幅度速度〕，〔人群/旗帜/烟尘的次级运动〕。
〔结束态：视觉重心落在〔谁/什么〕上。无字幕、无招牌文字。〕
overall_soundscape: 〔环境底噪层次：风/人群/机械/雨〕；〔远近声压差〕；〔一声标志性声音 + 秒点〕。
non_diegetic_music: 〔史诗/压迫感：低频 + 铜管或鼓，进入点〕。
```

常见错：人多但没写左右位置；远景写"气势恢宏"；招牌文字不规避（必崩字）。
