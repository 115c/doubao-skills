# 验收与复盘（生成前 · 生成后 · 交付）

用途：定稿剧本/已确认分镜 → 最终提示词 → 提交 → 出片验收 → 交付。
先由本段原文建立「必需项」，再拿**实际提交的提示词**和**真实画布入边**反向核对；不能只检查自己写的摘要。

## 一、提示词写作协议（写之前先做）

1. **写前回读**：回读本集已确认的分镜与台词原文，记下实际文件/节点、版本、覆盖范围；摘要和上一轮记忆不能替代原文。
2. **清单先于引用**：先列本段覆盖镜号，再列首帧/尾帧、角色、场景、道具、音频各自用途，最后正文才引用「参考图 1 / 参考视频 1 / 参考音频 1」。
3. **时间写进最终提示词**：每镜写起止秒；镜内每条表情、动作、环境变化、运镜、声音分别给时窗（`00.0–00.0`），并写清「同时」还是「先后」。
4. **余量有去向**：对白按 7 字/秒预算，省下的时间分配给有依据的表情、动作 beat、环境反应，不拿空镜凑。

## 二、生成前七项内容锁（缺一项 = 不可提交）

> 画幅默认 16:9 横屏；节点比例不是 16:9 时先改回，再提交。

| # | 锁 | 检查什么 |
|---|---|---|
| 1 | 台词锁 | 每条对白/OS 登记 `镜号｜起–止秒｜角色（语气）｜原文`；最终提示词里逐字出现，不改词、不概括；OS 明写「只有观众听见」，不驱动口型 |
| 2 | 镜号锁 | 首行写 `本段覆盖 T##–T##`；逐镜列「原镜号｜段内起止｜对应动作/台词｜状态」；缺镜必须写原因并取得删镜授权 |
| 3 | 文字锁 | 分三级：A 剧情必需且生成可读（原字串/数字进提示词）、B 后期补字（留干净区域 + 补字清单）、C 禁止生成（字幕/水印/乱码） |
| 4 | 数字锁 | 影响剧情的数字、价格、层级、正负号按**原字面**保留（「十七条」不写成「17条」），并核对绑定的人/物/前后状态 |
| 5 | 站位锁 | 固定物锚点、每个角色相对位置与朝向、距离遮挡、机位在侧与拍摄方向；换机位要重算左右与背景 |
| 6 | 反向差额 | 逐项列 `来源原文｜必需项｜最终提示词定位或真实输入证据｜差额/冲突｜修复状态`；未解决差额必须为 0 |
| 7 | 素材与音色锁 | 每个出场角色、每件道具、每条音色各一行：真实文件、来源节点与端口、目标节点与端口、实际入边；只说「参考全部」不算绑定 |

**放行结论**：只有「差额 0 + 镜号全覆盖 + 台词数字逐字一致 + 文字分级完整 + 站位闭合 + 素材实证通过」才写 `ready_to_submit`；否则写 `not_submittable` 并停止提交。改提示词、换模型、改参考顺序、重切段后，检查全部重做。

## 三、生成后抽帧自检（每次必做）

对每个镜头抽 **首帧 / 中段 / 尾帧**（有对白的再加一张说话瞬间），逐张看图，报告以下项：

| 检查项 | 常见问题 |
|---|---|
| 人脸 | 变脸、换人、五官崩、表情与剧情不符 |
| 手部/肢体 | 多指、断肢、穿模、动作不连贯 |
| 文字 | 画面出现乱码字幕、招牌写错字 |
| 穿帮 | 道具消失/换手、服装变化、背景跳变 |
| 动作 | 打击感软、动作跳帧、慢动作滥用 |
| 音画 | 口型对不上、声音与画面不同步、BGM 盖对白 |

- 报告格式：`镜号｜问题｜证据（帧号/截图）｜严重度（阻断/可修）｜建议改法`。
- 没抽帧、没看图，就明确说「未验证」，不能写「已通过」。

## 四、返修单（只重跑受影响的镜头）

```
返修单 v1
- 集/段：第X集 T03–T05
- 阻断项：T04 人脸崩（尾帧）
- 原因：参考图未挂 / 提示词未写身份 / 分辨率过低
- 改法：补挂角色资产图 2，提示词首句加「同一人物，黑色长发，深绿劲装」
- 影响范围：仅 T04；T03/T05 复用
- 状态：待重跑
```

原则：单镜问题单镜修；不因为一个镜头重跑整集；重跑前先确认模型与参数没被改动。

## 五、交付前总检

- 分辨率/比例与平台要求一致（竖屏 9:16）；时长与分镜一致；帧率稳定。
- 音轨：对白清晰、音乐不盖人声、环境声不断层；音量响度统一。
- 字幕：断句正确、错别字为零、时间轴对齐。
- 合规：AIGC 标识、平台红线（血腥/涉政/迷信等）已过。
- 文件命名与目录规范，交付清单与实际文件一致。

## 六、复盘记录（每次返工都写）

写进项目目录 `.agent/复盘.md`，每条四行：

```
## 2026-11-07 T04 人脸崩
- 现象：尾帧人脸变成另一人
- 根因：参考图只挂了场景，没挂角色资产
- 规则：含人物的镜头，角色资产图必须逐项挂载并在提示词首句写身份
```

下次开工先读这份复盘，避免同类错误重复出现。
