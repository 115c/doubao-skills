# 提示词手册：图片 / 视频 / 首尾帧 / 参考素材

> 用法：先按 §1 选对层，再按 §2–§5 套结构，写完过 §11 自检表。
> 原则：**提示词是时间轴，不是形容词清单。** 写什么顺序，模型就按什么顺序演。

---

## 0. 三段锚（每集开头定一次，逐镜复用）

每集开工前先写三行锚，放在分镜表顶部；之后每镜提示词直接复用，不重写。

- **风格锚**：一句话锁色调/光比/质感/颗粒。例：`冷青灰调，硬光高对比，35mm 胶片颗粒，雨夜反光地面。`
- **人物锚**：每个主要人物一行，五件套。例：`男主：三十岁，短寸头，左眉断口，黑色劲装，右腕缠白布。`
- **场景锚**：空间结构 + 主光位。例：`废弃厂房，北向高窗，光从画左上方斜切，地面有积水与碎砖。`

规则：锚定了全集不改，换集才重定；提示词里每个 Subject 都必须能在锚里找到对应行。

## 1. 提示词分层

| 层 | 产出 | 用途 | 关键控制点 | 不要写 |
|---|---|---|---|---|
| ① 图片提示词 | 单张静态图 | 身份板、三视图、场景板、道具板、风格帧 | 外貌、构图方位、光线、材质、画内文字 | 时间线、运镜、声音 |
| ② 首帧 / 尾帧 | 被当成第 0 帧/末帧的图 | 锁开场构图、锁收尾姿态 | 与首段/末段一致的构图、姿态、光位 | "接下来会怎样" |
| ③ 参考素材 | 图 / 视频 / 音频 | 锁身份、服装、动作、音色 | 标号指代、保留等级、用途单一 | 一图兼顾外观+动作+构图 |
| ④ 视频提示词 | 4–15 秒带声音成片 | 正片镜头 | 模式、时间戳、动作顺序、声音三层 | 平台参数、seed、负面字段 |
| ⑤ 后期 | 成片之上的加工 | 冲击帧、字幕、混音、拼接 | 时间点与帧数 | 指望模型做出"抽帧感" |

判断：要"这人长这样"→图片；要"这一秒就是这一格"→首帧；要"最后停在这个姿势"→尾帧；要"从 A 走到 B 并说话"→视频；要"打中那下有冲击"→生成侧留锚点，后期加帧。

## 2. H3 能力边界

| 项 | 事实 | 影响 |
|---|---|---|
| 时长 | 4–15 秒整数，默认 5 | 时长是总预算，不是建议 |
| 分辨率 | 768P 或 2K（短边 1440px，如 2560×1440） | 没有 1080P / 4K |
| 帧率 | 24fps | 5 秒只有 120 帧，"极快三连击"塞不下 |
| 声音 | 32kHz 立体声，与画面同遍生成 | 不写就由模型猜 |
| 画幅 | adaptive / 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 | 纯文生必须给比例 |
| 提示词上限 | 7000 字符 | 正文 350–500 字最稳 |
| 参考上限 | 9 图 + 3 视频 + 3 音频，单次 ≤12 文件 | 见 §5 |

提示词层没有：负面提示词字段（不想要的东西写否定句，§7）；seed / guidance / 采样步数（属节点参数）；括号指令（`(masterpiece:1.2)` 这类语法一律失效）；平台参数（时长、画幅、分辨率放界面）。

中英混排：叙述用中文，**只有格式元素保留英文**——字段名、`[Shot 1]`、`At MM:SS.mmm`、运镜动词、`(S1)`、`<d>[Chinese]`、保留等级、固定指令句。台词、歌词、屏幕文字保留原语言加英文双引号，不翻译。

## 3. 五种模式与对齐行

| 模式 | 输入 | 首句（对齐行） | 适用 |
|---|---|---|---|
| T2VA | 纯文字 | 无 | 原创镜头、风格探索 |
| I2VA | 1 张首帧 | `For the target video, at 0.00 seconds, <Picture 1> from [Shot 1] is fully referenced.` | 定妆图/场景图动起来 |
| FL2VA | 首帧+尾帧 | `Picture 1 from [Shot 1] aligns to 0.00 seconds; Picture 2 from the actual final [Shot N] aligns to the exact S.SS-second end time.` | 首尾都定死：变身、开门、落刀 |
| L2VA | 1 张尾帧 | `<Picture 1> from the actual final [Shot N] aligns to the exact S.SS-second end time.` | 只要"最后停在这一格" |
| Ref2VA | 多主体参考 | 先定义 `<Subject N>`，再写六字段 | 多角色同框、换装、动作迁移、音色复用 |

I2VA 与参考模式**互斥**。对齐行后空一行再写字段。

## 4.0 默认用六段式（项目约定）

本项目**默认生视频模型 = comfyui / Pika H3全参**（备选：MiniMax H3 原版（多参考）），提示词一律按官方**六段式**组织：

```
subject_definitions
summary
retention_analysis
detailed_description
overall_soundscape
non_diegetic_music
```

即使没有任何参考素材，也照六段写：`subject_definitions` 里写主体身份与外观锚点（"Subject 1 = 三十岁男性，短寸头，深灰夹克"），不要因为"没图"就退化成三段式。
三段式只在"节点/供应商明确只接受三字段"时作兼容备选（见 4.1–4.3）；有参考素材（图/视频/音频）时必须六段式。

**画幅默认 16:9 横屏**：描述构图时按横屏写（左右站位、横向留白、横移/摇镜），不写竖屏的上下堆叠；`ratio` 默认填 16:9，仅在用户明确要求时改 9:16 / 21:9。

## 4. 视频写法定式：三段式

Base 模式（T2VA/I2VA/FL2VA/L2VA）固定三字段：

```
integrated_multimodal_description: ……画面与时间轴
overall_soundscape: ……环境与物理声
non_diegetic_music: ……配乐，或 N/A
```

### 4.1 第一段：画面与时间轴

内部六块，一块不跳：

| 块 | 写什么 | 示例 |
|---|---|---|
| ① 风格与画质 | 风格、介质、色调、光比 | `电影感写实风格，冷青色夜雨，高对比硬光。` |
| ② 主体锚定 | 是谁、穿什么、拿什么、站哪 | `她（<Subject 1>）身穿深蓝金绣长裙，右手握香槟杯，站在露台栏杆前。` |
| ③ 环境与光 | 空间、前后景、光源方向 | `身后是虚化的城市灯带，左侧壁灯打亮半张脸。` |
| ④ 动作时间线 | `[Shot N]` 分段，按发生顺序 | 见下 |
| ⑤ 表演细节 | 目光路径、眼睑、嘴角、呼吸、手部 | `目光从酒杯抬向画外左侧，停留两秒。` |
| ⑥ 收尾锁 | 不变的物件 + 否定句 | `金色刺绣与右手香槟杯全程不变。无溶解转场。` |

```
[Shot 1] 她站在栏杆前，镜头固定（Static Shot）一秒，随后以小幅、慢速向她的上半身推近（Push In）。
[Shot 2] At 00:02.400，切到她右手特写：指尖沿杯沿缓慢划过一圈。
[Shot 3] At 00:04.200，回到中景，她抬眼看向画外左侧，嘴角先右后左扬起。
```

四条铁律：

1. `[Shot 1]` 不带时间戳；从 `[Shot 2]` 起必须 `At MM:SS.mmm`。
2. 时间戳严格递增，不超总时长（5 秒镜头不能写 `At 00:06.000`）。
3. 切镜必须带来新信息：新主体、新空间、新状态、新视点、新时间。只变远近角度用运镜。
4. 一镜一个主变化，并写清结束态（手停在哪、重心落哪只脚）。

### 4.2 第二段：整体声景

只写环境声与物理声，四件套：**环境底噪 + 材质/物理声 + 非语言人声 + 空间混响**。

```
overall_soundscape: 夜晚城市低频底噪持续；远处车流偶尔掠过；杯底与石栏轻碰一声；裙料摩擦细碎；空间偏开阔，带轻微露台回声。
```

声音与画面动作一一对应（画面有杯子才写碰声）；写音色与力度，不写"紧张的氛围"；呼吸、闷哼、脚步放这里，台词不在这里。

### 4.3 第三段：非同步配乐

四要素：**有无 / 乐器 / 节奏 / 动态**，可加"是否有人声"。

```
non_diegetic_music: 低音量慢速爵士钢琴，配柔和刷鼓点；节奏舒缓，动态平稳，无人声演唱。
```

不要配乐写 `N/A`；要音乐却写 N/A 是官方失败模式，只写"悲伤的旋律"同样会失败。不写曲名、不写"像某部电影"。情绪靠乐器与动态：紧张=短促断奏+低频脉冲；温柔=长音+弱起。

### 4.4 Ref2VA：六段式

| 字段 | 作用 | 写法 |
|---|---|---|
| `subject_definitions` | 定义每个 `<Subject N>` 是什么、用哪份素材 | 一 Subject 一行；图给外观、视频给动作、音频给音色 |
| `summary` | 一句话标任务类型 | `keyframe completion` / `reference generation` / `video editing` / `video continuation` / `audio reuse` / `audio reference`，可组合 |
| `retention_analysis` | 每个 Subject 保留到什么程度 | `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference` |
| `detailed_description` | 画面与时间轴 | 同 4.1 六块 |
| `overall_soundscape` | 环境与物理声 | 同 4.2 |
| `non_diegetic_music` | 配乐 | 同 4.3 |

`retention_analysis` 是防漂移核心：**只保留你写出来的特征**；"保留她的样子"等于没写。

## 4.5 字段映射表（分镜列 → 提示词句）

分镜表里的每一列都有固定去向，别漏、别重复写。

| 分镜字段 | 写进哪里 | 写法要求 |
|---|---|---|
| 镜号 S04 | `[Shot 1]`（每镜独立计数） | 不抄 S04，只写 Shot 序号 |
| 景别 | 第一句 | 大远景/远景/全景/中全景/中景/中近景/近景/特写/大特写 |
| 焦段 | 第一句 | 8–16 鱼眼 / 14–24 超广 / 24–35 广角 / 35–50 标准 / 50–85 中焦 / 85–135 长焦 / 微距 |
| 机位 | 第一句 | 高度（地面/齐腰/齐眼/俯拍/仰拍）+ 方位（正/侧 45°/背后/越肩） |
| 运镜 | 第二句 | 类型 + 幅度 + 速度；一镜只一个主运镜 |
| 画面内容 | 2–4 句 | 起势→过程→接触→结果，每步带秒点 |
| 光线 | 单独一句 | 光源 + 方向 + 色温 + 光比 + 体积光/雾 |
| 声音 | `overall_soundscape` | 底噪 / 动作声（带秒点）/ 人声或静默 |
| 配乐 | `non_diegetic_music` | 乐器 + 节奏 + 动态 + 进点；不要就 `N/A` |
| 时长 | 时间戳上限 | ≤20 秒写 2–3 个时间戳；>20 秒写 4–6 个 |
| 台词 | `<d>[Chinese] …</d>` + `(S1)` | 一句一镜，一人说话 |
| 画幅 | 不写进提示词 | 由模型比例参数控制（默认 16:9 横屏） |

## 5. 参考素材引用规则

### 5.1 上限与硬规则

图片 ≤9、视频 ≤3、音频 ≤3，单次总文件 ≤12。音频**不能是唯一参考**，必须配图或视频；I2VA 与 reference 模式互斥；FL2VA 只用两张图做首尾锚点；音频语言稳定支持中英法德意日韩葡俄西阿 11 种。

### 5.2 标签语义

| 标签 | 指什么 | 何时单列 |
|---|---|---|
| `<Subject N>` | 从素材提取的**可复用内容单位**：人、物、场景、服装、道具、风格、动作、姿势、效果 | 默认都用它，描述"用进目标片的内容" |
| `<Picture N>` | **图片本身**作首帧/关键帧/尾帧/构图锚点/分镜方案 | 只有图锚定某帧或提供明确分镜时才单列 |
| `<Video N>` | **源视频整体**被编辑、延续，或提供镜头节奏与计时结构 | 视频承担整体结构角色时；纯动作迁移可放进 Subject |
| `<Audio N>` | 被**积极使用**的音频：整段/部分复制，或参考音色、音乐、词、效果、节拍 | 视频自带声音 ≠ 要 Audio 标签 |

判定：图只定义"长什么样"→写进 Subject；要"第 0 帧就是这张图"→单列 Picture 1 + 对齐行；视频带声但你只要动作→不要 Audio；一个 Subject 可组合"图给外观+视频给动作+音频给音色"。

### 5.3 编号与指代

1. 首次出现即定义，之后只用编号，不重复形容。
2. 编号全片唯一：`<Subject 1>` 在第 1 镜和第 5 镜是同一个人。
3. 编号与素材顺序对齐：`<Picture 1>` 是上传的第 1 张图。
4. 一份稿只用一套体系，不混用"图1 / 图片1 / Image 1 / `<Picture 1>`"。
5. 正文只提用途，不提文件名。

### 5.4 固定英文指令句（逐字用）

身份取图、动作取视频：

```
Use Image 1 for the subject's appearance and identity. Use Video 1 for the body movement only. The subject from Image 1 performs the same movement as Video 1.
```

只要动作、不要原视频的脸：`Use Video 1 for the body movement only. Do not copy the person's face, clothing, or background from Video 1.`

环绕/旋转加中间帧锚定：`At 00:05.000, the composition aligns to <Picture 2>.`

### 5.5 落地检查

- 素材里没有的特征，不要写进 `retention_analysis`（模型会硬造）。
- 素材里有但不想保留的，显式写"不复制"（发型、妆容、背景、文字）。
- 图片只证明外观，不证明"他会武功""这甲能挡刀""身后有一队人"。
- 换装/换年龄新起一组，两个形态塞同组会把两张脸揉成一张。

## 6. 表演与时间控制

### 6.1 口型：台词必须绑人

| # | 规则 | 说明 |
|---|---|---|
| 1 | 台词放进 `<d>[Chinese] 原文</d>` | 只写引号台词不放进 `<d>`，会变画外音、嘴不动 |
| 2 | 用 `(S1)` `(S2)` 绑说话人 | 按发声顺序编号，跨镜头复用同一 ID |
| 3 | 一句一镜 | 长句拆镜，别让一个镜头念 30 字 |
| 4 | 台词后给 Closing Beat | 转头、放杯、垂眼，给嘴一个收口动作 |
| 5 | 无对白显式锁嘴 | `无对白，整片嘴唇保持闭合。` |
| 6 | 音频参考锁音色 | ≤3 条，修剪到本片段、时长匹配；加语气节奏（`语速偏慢，句尾略沉`） |
| 7 | 对白戏用中近景/特写 | 远景口型不值得赌 |

```
(S1) 抬眼看向 <Subject 2>，语速偏慢：<d>[Chinese] 你迟到了三分钟。</d> 说完垂眼，把杯子放回桌面。
```

### 6.2 姿态与动作

提示词层**没有姿态参数**，只有三种手段：

1. 文字：谁 + 做什么 + 幅度 + 速度 + 结束态。`她右手抬起约与肩平，以小幅度、慢速向前伸出，指尖停在门把上方两厘米。`
2. 图给身份 + 视频给动作（§5.4 固定句）。
3. 中间帧锚定：长动作拆"起—中—止"三格，用 `<Picture N>` 锚中间帧。

视频动作迁移是**语义级**（学到"挥拳"这件事），不是骨骼级；要骨骼精度走控制类节点。每个动作都要写结束态，否则角色会一直动到最后一帧。多角色同框逐个给动作句。

### 6.3 镜头运动：类型 + 幅度 + 速度

| 类别 | 词 |
|---|---|
| 变焦 | Zoom In / Out（机身不动，焦距变） |
| 纵深 | Push In / Pull Out（机位沿轴前后移） |
| 横移 / 升降 | Truck Left / Right；Pedestal Up / Down |
| 摇 / 俯仰 | Pan Left / Right；Tilt Up / Down（原地转） |
| 环绕 / 跟随 / 主观 | Arc Shot；Tracking Shot；POV |
| 滚转 / 抖动 / 静止 | Roll Clockwise / Counterclockwise；Shake Slightly / Strongly；Static Shot |

幅度 `with small amplitude` / `with large amplitude`；速度 `at slow speed` / `at fast speed`；中幅常速可省略。

三条纪律：一镜一个主运镜（推+摇+环绕同上是必糊）；机位用空间关系写（机位在哪、朝哪拍、主体面朝哪、背景是什么），比"正反打""过肩"稳；H3 默认会漂，要固定就写 `镜头固定（Static Shot）`。

### 6.4 时长与节奏

| 时长 | 能装 | 建议镜数 |
|---|---|---|
| 4–5 秒 | 一个动作 + 一个反应 | 1–2 |
| 6–8 秒 | 起势 + 变化 + 收尾 | 2–3 |
| 9–12 秒 | 一个小事件（有转折） | 3–5 |
| 13–15 秒 | 完整小段落 | 4–6 |

每镜至少 1.5 秒。切镜点放在动作中间（挥到一半切）比放在动作结束后更有力。慢动作要写清哪一段慢、慢多少，并说明镜头没跟着慢：`人物动作放慢至约三分之一速，镜头保持常速跟随`。时长不够就减内容，不压语速、不删因果。

## 6.5 信息单元标准（每镜必满）

字数不是标准，**能拍出来的信息单元**才是。交稿前逐镜数一遍：

| 单元 | 最少 | 长什么样 |
|---|---|---|
| 动作节点 | 3 | 起势 / 过程 / 接触 / 结果，任选 3 个，每个带秒点或顺序词 |
| 空间锚 | 2 | 前景遮挡、地面材质、中景陈设、远景层次，任选 2 个 |
| 光线 | 1 | 光源 + 方向 + 色温（光比、体积光加分） |
| 镜头 | 1 | 焦段 + 机位 + 运镜（幅度 + 速度） |
| 声音点 | 3 | 底噪 / 动作声带秒点 / 人声或静默 |
| 结束态 | 1 | 手停在哪、重心在哪只脚、道具什么状态 |

写法：一个单元一句，句号断开；不要一句话里塞三个单元。

不合格：`中景，他拔剑砍向对手。`（动作 1、空间 0、光 0、镜头 1、声音 0、结束态 0）

合格骨架（按 `镜头模板.md` 填槽位即可）：
> `[Shot 1] 中景，50mm，机位齐腰高、侧前方 45°，浅景深。`（镜头）
> `男主站在断墙左侧，黑色劲装湿透，右手握剑柄、指节发白，肩线压低。`（主体）
> `前景是断裂砖墙与水面反光，中景是两人与倾倒木架，远景是雨幕里的巷口与路灯。`（空间）
> `侧逆光从左后方打来，5600K，肩背与剑锋镶冷白边，正面路灯补暖光，光比 3:1，雨丝在光柱里可见。`（光）
> `At 00:01.200，后脚蹬地，长剑从右下斜撩到左上，剑锋甩出一串水珠。`（动作）
> `At 00:02.600，剑尖擦过横举的刀面，接触点溅起白蓝火星，各自后退半步。`（接触+结果）
> `At 00:04.000，收势，剑尖垂向地面，重心落回左脚，披风缓缓落下。`（结束态）

自检 30 秒：先过 `6.6 动作表` 与 `6.8 逻辑六问` → 数单元、缺哪个补哪个 → 查禁用词 → 跑 `提示词体检.md`（Toonflow 内用 `sandbox` 工具执行 `python3 prompt_lint.py 提示词.md --duration 6`）。

## 6.6 先填动作表，再写句子（2026-11-08 新增，硬规定）

写任何一镜之前，先在草稿里填这张表；表填不出来就不许写提示词。

| 动作节点 | 谁发力 / 支撑点 | 轨迹与速度 | 接触点 / 落点 | 结束态 | 道具状态 |
|---|---|---|---|---|---|

- 每行四要素齐全（发力点、轨迹、接触/落点、结束态），缺一项就会"人物在空中飘"；
- 接触类动作必须写"对方被击后怎么变"（退半步 / 刀被压偏 / 撞上桌角）；
- 一镜最多 3–4 个节点、每个节点 ≥0.3 秒。

不合格 → 合格：

- ❌ `他一拳把对手打飞。`
- ✅ `右脚前踏踩实，右拳从腰侧直线打出，接触对方下颌；对方上身后仰、连退两步撞上木桌，茶杯晃倒。`

细节规则见 `逻辑与镜头.md`（含 12 条物理常识、30 条反例）。

## 6.7 镜头行模板（每镜必须是一行完整的镜头句）

> `[Shot N] <景别>，<焦段>mm，机位<高度>、<角度>，<运镜>（<幅度>+<速度>），起幅<…>，落幅<…>。`

- 六要素：景别 / 角度 / 机位与运动 / 焦段 / 光线 / 起幅落幅，**缺 3 项机检直接判 FAIL**；
- 只写一个主运动（推、拉、摇、移、跟、升降、手持、固定，八选一）；推+拉、摇+移同句算冲突；
- 主体运动与镜头运动别对着干（人向左冲出画，镜头还向右摇）。

各类镜头的默认槽位见 `镜头模板.md`。

## 6.8 逻辑自检六问（每镜写完过一遍）

1. **谁在发力？脚踩在哪？** 没有支撑点，动作不成立。
2. **接触点在哪？接触后谁的运动状态变了？** 没变化 = 没打到。
3. **这段时间做得完吗？** 节点数 × 0.3 秒 ≤ 时长，否则删节点。
4. **镜头和主体是不是对着动？** 是就改一个。
5. **同一镜里位置、朝向、道具状态有没有跳变？** 有就补过渡或拆镜。
6. **有没有"同时做两件相反的事"？** 有就拆成两拍。

机检覆盖：互斥动作、无支撑腾空、攻击无方向、动作密度、运镜冲突、抽象词、参考素材上限（见 `提示词体检.md`）。

## 7. 负面约束与失败诊断

### 7.1 三类必锁

| 类型 | 例子 | 写法 |
|---|---|---|
| 台词提到但画面不该出现的物品 | 台词说"刀" | `画面中不出现刀。` |
| 不想要的音乐 | 只要环境声 | `non_diegetic_music: N/A` |
| 不该出现的人 | 私密对话 | `无其他角色入画，背景无行人。` |

否定句（prose negation）写在正文末尾，一到三句，具体到物件：

```
无溶解转场、无流体形变。不要出现多余的中文文字、乱码或错别字。整片保持她右手里的香槟杯和金色刺绣不变。
```

要点：否定 + 具体对象。"不要奇怪的东西"无效，"无多余文字、无乱码"有效。

### 7.2 失败诊断表

| 症状 | 主要原因 | 改法 |
|---|---|---|
| 动作顺序乱、前后颠倒 | 一段话塞多个动作，没有时间锚 | 按发生顺序逐个写；每镜一个主变化+结束态 |
| 表情僵硬像面具 | 只写情绪词（"她很伤心"） | 物理化：目光焦点、眼睑、嘴角、呼吸、手部、重心 |
| 嘴不动 / 声音变画外音 | 台词没进 `<d>`，或没绑 `(S1)` | 台词进 `<d>` + `(S1)`；补 Closing Beat |
| 口型对不上 | 一句太长，或一镜多人说话 | 一句一镜；长句拆镜；同镜只让一个人说 |
| 角色越演越不像 | 没写 retention，或只写"保持外貌" | 列具体特征：发型、痣、服装、持物、饰品 |
| 服装道具中途消失 | 没做状态追踪 | 结尾加"XX 全程不变"；换装后全部换新描述 |
| 镜头乱切、跳轴 | 时间戳乱、切镜无新信息、越轴 | 时间戳递增；只变距离用运镜；正反打同侧 |
| 想锁死却在动 | 没写 Static Shot | 显式写 `镜头固定（Static Shot）` |
| 音乐不对或太满 | 只写情绪词，或该 N/A 却写了描述 | 乐器+节奏+动态+是否人声；不要就 N/A |

## 8. 图片提示词（MOSS / Qwen-Image）

### 8.1 两套工具别用错

| 工具 | 能力 | 用于 |
|---|---|---|
| MOSS-Image | 纯文生图，**不支持图生图** | 角色板、三视图、场景板、道具板、九宫格、海报 |
| Qwen-Image-2.1 | 图生图、图片编辑、多参考、局部重绘 | 换装、改光、改表情、增删物件、风格迁移 |

### 8.2 MOSS 正文写法

一段话写完，不写标题、不写解释、不用列表、不用 JSON。顺序：**版式声明（多格才要）→ 主体外貌服饰 → 动作姿态 → 方位 → 场景道具 → 景别机位 → 光线 → 色调质感**。

硬规则：全简体中文、第三人称、现在时、肯定句、观察者视角；只写看得见的东西；不写"杰作/8K/极致画质/masterpiece/best quality"；不写负向句（图片模型对否定基本无效，改正面描述）；正文不写比例、分辨率、像素；画内中文文字照抄原文用中文引号，并说明载体、位置、字号、颜色。

长度：单图 200–400 字；复杂/文字密集 400–800 字；九宫格每格 50–120 字；角色板 300–600 字。

多格版面：开头声明版式（`一张 3×3 九宫格分镜，共 9 个等大画格，画格之间有细白边。`）；每格"第 N 格："开头；同一人物跨格发型、服装、体型、配色逐格复写，不写"同上"；角色板写"左约三分之一为面部大特写，右侧为正面、侧面、背面三视图全身像，纯色浅灰背景"。

### 8.3 比例、分辨率、步数与画面的关系

| 参数 | 影响 | 写在哪 |
|---|---|---|
| 比例 | 构图空间：9:16 人物占满留白少；16:9 适合环境与双人；1:1 适合头像海报 | 节点参数，正文最多写"竖构图"辅助 |
| 分辨率 | 细节密度与文字可读性，越高越易崩字 | 节点参数，正文绝不写 |
| 步数 | <20 细节不足结构松；25–35 稳定；>50 易过锐、纹理重复 | 节点参数 |


结论：**提示词管内容，参数管质量。** 混写只会稀释内容。

### 8.4 人物一致性：靠身份短语，不靠名字

五件套逐图原样复写：**年龄性别 + 发型（长度/分缝/束法）+ 脸型特征（眉/痣/疤）+ 服装（颜色/材质/领口/纹样）+ 标志物（饰品/武器/持物）**。

```
二十八岁东亚女性，黑色长直发中分及腰，鹅蛋脸、右眉尾一颗小痣，深蓝丝绒立领长裙、金色云纹刺绣，右手无名指一枚细银戒。
```

变体只改一处：换装只改服装短语；受伤在末尾加"左颊一道浅红划痕，袖口撕裂"；年龄变化新起一组，明确"同一人物的少年时期"并重写发型与服装。

### 8.5 Qwen-Image 编辑指令

中文需求写中文指令；只改指定属性，其余逐项"保持完全不变"；多图用 `<image1> <image2>` 标明角色（`image1` 为被编辑画布）；不写负向句，不写分辨率。

```
把 <image1> 中人物的外套改为深灰色羊毛大衣，保留她的发型、面部、站姿与背景光线完全不变。
```

### 8.6 图像信息单元标准（每张图必满）

和视频一样：**数单元，不数字数**。缺一项就补一项。

| 单元 | 最少 | 长什么样 |
|---|---|---|
| 主体五件套 | 1 组 | 年龄性别 + 发型（长度/分缝/束法）+ 脸型特征（眉/痣/疤）+ 服装（颜色/材质/领口/纹样）+ 标志物（饰品/武器/持物） |
| 姿态与朝向 | 1 | 站/坐/跪/回身/抬手/持物，面朝哪一边 |
| 景别与机位 | 1 | 特写/近景/半身/全身/全景 + 平视/略俯/略仰 + 正面/侧面 |
| 环境 | 1 | 地点 + 至少一层前后景（纯色背景也要写"纯色浅灰"） |
| 光线 | 1 | 光源 + 方向 + 色温（或"均匀柔光"） |
| 色调质感 | 1 | 冷暖、对比、胶片/写实/渲染、颗粒 |

可选单元（有就写，没有不算缺）：版式（多格/三视图）、画内文字（原文 + 载体 + 位置 + 颜色 + 相对字号）。

不合格：`一个穿古装的男人，站在街上。`（五件套 0、姿态 0、景别 0、环境 1、光 0、质感 0）

### 8.7 图像模板

六类模板在 `图像模板.md`：人物定妆、角色三视图、场景板、道具板、状态变体、首尾帧。照抄骨架只换内容，别每次从零写。

### 8.8 图像体检

交稿前过一遍（Toonflow 内用 `sandbox` 工具跑 `python3 prompt_lint.py 提示词.md --kind image`，见 `提示词体检.md` 第四节）：

- [ ] 五件套齐；没有"同上""一样的人"。
- [ ] 姿态朝向、景别机位、环境层、光线方向色温、色调质感都在。
- [ ] 无负向句（"不要/没有/无"结尾句），负面内容改正面描述。
- [ ] 无比例数字、分辨率、步数、seed；正文不出现 16:9、1280×720。
- [ ] 无"杰作/8K/电影级/超清/masterpiece"。
- [ ] 单图 150–500 字（三视图/九宫格可到 800）。
- [ ] 画内文字已给原文与载体，且尽量不出现。
- [ ] 评分 ≥80 才交。

### 8.9 道具：先看分镜怎么用，再定视角（2026-11-08 定版）

道具最容易「不像」，因为模型没见过你的那件东西。**只写名字必崩**，必须写结构；**视角数量不固定**，由它在戏里怎么出现决定。

**第 0 步：翻分镜**。看这件道具出现在哪几镜、以什么形态出现——被拎起来？放在桌上？插在鞘里？拔出来？掰开？递给谁？这些形态就是视角清单。

**第 1 步：拆零件**。3–6 个可辨认零件，缺一个就不可辨（秤 = 秤杆 + 秤盘 + 秤砣 + 提纽；窝头 = 面团 + 指窝 + 粗粝表面 + 蒸裂纹）。

**第 2 步：定视角（2–4 个）**：
- 称量类：被拎起的全身 + 放桌面全身 + 刻度特写；
- 刀剑类：插鞘全身 + 拔出与鞘并排 + 护手/铭文特写；
- 食物/木棍类：整只（整根）+ 掰开/握持段，**两个就够**；
- 信物：正面 + 背面 + 刻字特写；
- 容器：正放 + 俯视开口。

**第 3 步：写「用旧」与「用途」**：谁用、怎么用、坏在哪（磨亮、缺口、油渍），让道具贴剧情。

硬规则：
- **不许出现参照物**：手、硬币、尺子、旁边摆的其它道具都不要——模型会把它们画成画面内容；尺度只用文字（「全长约 78cm，单手可提」）。
- **一件一板**；**形态写具体**（「被拎起时秤砣自然下垂」），别只写「正面」。
- **刻字不写具体字**：写「刻着磨平的字迹／模糊的星点」。
- **带风格锚**（三段锚里的风格句），否则会和人物/场景不在一个世界。

体检：`python3 prompt_lint.py 道具.md --kind prop`，查零件数、视角/形态数、参照物、尺寸、材质、风格、背景，**≥80** 才交。

## 9. 投喂前清洗

字数红线：H3 正文 350–500 字（上限 7000 字符）；Seedance 2.0 ≤1900/2000；2.5 ≤2600/3000。

压缩顺序：删管理话术 → 删低收益后缀 → 合并重复限制 → 缩短空泛形容词。**不得删**：素材用途、人物锚定、空间关系、摄影机行为、台词语气、段末状态。

可投喂语义：把"接下一段 / 承接上一镜 / 如分镜 2 所示"改写成本镜可见的段末状态或起始姿态；把"情绪要到位"改写成本镜可见的目光、呼吸、手部。稿内每个 `图N`/`视频N`/`音频N` 必须已定义，三类不混用。

## 10. 后期：冲击帧

命中瞬间的 1–3 帧高对比画面，靠视觉暂留"让人感觉到，而不是看到"。**后期做，不靠提示词。**

| 档 | 场合 | 帧数 | 做法 |
|---|---|---|---|
| L1 轻碰撞 | 格挡、擦击 | 1 | 黑白高反差 |
| L2 重碰撞 | 重击命中 | 2–3 | 白闪 → 负片 + 缩放 + 亮度回缓 |
| L3 大招 | 终结技 | 3–5 | 白闪 → 负片 → 黑白 + 放射线 + 鱼眼 + 回缓 |

生成侧只给锚点：`接触瞬间短促亮白火花，动作出现约两帧微停顿，随即被击退半步。` 负片、抽帧、定格、放射线不写进提示词。一镜最多打一次；闪烁不超 3 帧。
