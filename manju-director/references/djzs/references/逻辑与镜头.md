# 逻辑与镜头（动作成立 + 镜头可拍）

这页解决两个最常被用户骂的问题：**动作不符合常理**、**镜头描述太薄**。核心思路：**先把动作拆成物理事实，再把事实写成句子**；镜头同理，先定六要素，再写一句完整的镜头行。

---

## 一、动作分解表（写句之前必须先填）

每镜先填这张表，一行一个动作节点；表填不出来，说明这一镜还没想清楚，**不许动笔写提示词**。

| 动作节点 | 谁发力 / 支撑点 | 轨迹与速度 | 接触点 / 落点 | 结束态（重心、手、道具） | 道具状态 |
|---|---|---|---|---|---|
| 起势 | 右脚后撤半步、前脚掌着地 | 手臂抬到肩高，0.4s | — | 肩线压低，剑尖指向斜下 | 剑在右手，鞘在左腰 |
| 发力 | 后脚蹬地，腰胯先转，肩随后 | 剑从右下斜撩到左上，0.6s | 剑刃中段擦过对方刀面 | 双方各退半步，剑停在左上 | 刀面留白痕 |
| 收势 | 前脚踩实，重心回中 | 手臂下落，0.5s | — | 剑尖垂向地面，披风落下 | 剑回右手自然位 |

**三条硬规定**

1. 每个动作节点必须写清「谁发力、踩在哪、往哪去、停在哪」——缺一项就是让人物在空气里飘。
2. 接触类动作必须写「接触点 + 接触后谁的运动状态变了」（被击退半步 / 刀被压偏 / 人撞上木架）。
3. 一个动作节点至少给 0.3 秒；6 秒镜头最多 3–4 个节点。**写了 6 个节点的 6 秒镜头，模型只能糊。**

例（不合格 → 合格）：

- ❌ `他一拳把对手打飞。`
- ✅ `右脚前踏踩实，右拳从腰侧直线打出，接触对方下颌，对方上身后仰、退两步撞上木桌，桌面茶杯晃倒。`

## 二、物理与人体常识（12 条，逐条对照）

1. **没有支撑就不会动**：起跳要屈膝、后退要蹬地、转身要拧腰；只写"腾空"不写蹬地，等于反重力。
2. **力的方向要一致**：拳头向左打，人就向左倾；写"被打飞"必须写飞的方向，且与受力方向相反。
3. **重量感**：铁器、尸体、湿衣都比看上去重；单手提重物时身体会侧倾，不会笔直站着。
4. **惯性**：急停要前倾、脚底打滑；被推会先踉跄再稳住，不会瞬间站定。
5. **接触点**：刀砍在刀上要有火花与震手；打在布上不会出声；打在沙地上会扬尘。
6. **同时性**：一个人同一瞬间只能做一件主动作（跑的同时不能"站住"，拔刀的同时不能"收刀"）。
7. **视线跟随**：看向哪里，头/眼/身体朝向要一致；背对说话要回头。
8. **地面决定动作**：沙地留脚印、泥地打滑、石阶会绊、水面会溅；没有地面描写，动作就像在真空。
9. **道具不会自己变**：刀已入鞘就不能下一句又握着；碗碎了不能下一镜完好。
10. **距离与焦段**：长焦压缩空间、广角夸大前后景；两人贴身打斗用长焦会糊成一片，改用中景 35–50mm。
11. **光源位置固定**：一场戏里主光方向不能来回跳；换机位要说明"反打"。
12. **时长换动作**：1 秒只能一个动作；3 秒两个；6 秒三到四个；10 秒以上才铺完整回合。

## 三、镜头六要素（每镜必须齐）

| 要素 | 写法 | 机检关键词 |
|---|---|---|
| 景别 | 大特写 / 特写 / 近景 / 中景 / 中全景 / 全景 / 远景 | 同左 |
| 角度 | 平视 / 俯拍 / 仰拍 / 侧拍 / 斜侧 / 背面 / 荷兰角 | 同左 |
| 机位与运动 | 机位高度 + 运镜（推/拉/摇/移/跟/升降/手持/固定）+ 幅度 + 速度 | 推镜、拉镜、摇摄、平移、跟拍、手持、固定机位、环绕 |
| 焦段 | 24mm 广角 / 35mm / 50mm 标准 / 85mm / 135mm 长焦 / 微距 | `\d+mm`、广角、长焦、标准镜、微距 |
| 光线 | 主光方向 + 色温 + 光比 | 侧逆光、顶光、柔光、5600K、光比 |
| 起幅→落幅 | 镜头从哪开始、到哪结束 | 起幅、落幅、从…到… |

一行式模板：

> `[Shot 2] 中景偏近，35mm，机位齐胸高、侧前方 45°，跟随横移 1.5 米（中速），起幅带进左侧断墙，落幅停在两人交手的中线。`

三拍法（每个镜头都按这三段写，避免"一镜到底没变化"）：

1. **起幅**：观众第一眼看到什么（主体 + 空间锚）。
2. **运动**：主体怎么动、镜头怎么跟（只写一个主运动）。
3. **落幅**：停在什么构图（谁在前景、谁在焦点、画面留白在哪）。

## 四、可拍性三问（每镜写完自问）

1. **看得见吗？** 这个动作在所选景别/焦段里，观众能不能看清接触点？看不清就换景别，不是加形容词。
2. **做得完吗？** 时长 ÷ 动作节点 ≥ 0.3 秒？做不完就删节点，不是写"快速"。
3. **接得上吗？** 上一镜结束态（位置/朝向/道具）和这一镜起幅一致吗？不一致就补一句过渡或换机位。
