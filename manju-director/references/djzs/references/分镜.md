# 分镜（子镜表）

分镜只做一件事：把剧本翻成一条一条「能直接拿去生成」的子镜。
产出物只有一个——**子镜表**。表写不细，后面提示词就没料可写，生成只能靠运气。

## 〇、画幅基线：默认 16:9 横屏

本项目默认横屏 16:9，不是竖屏。分镜、构图、机位、运镜都按横屏写：

- 双人对话默认**左右并排**或一左一右过肩，不要叠成前后两层。
- 主体可偏左/偏右三分线，在运动方向一侧留出空间；横向留白就是张力。
- 群像、环境、打斗优先**横向展开**：左右错身、横移跟拍、横向摇镜。
- 需要强调高度时用低机位仰拍，不要把画面切窄。
- 9:16 竖屏与 21:9 宽银幕仅在用户明确要求时使用（竖屏语法见第四节）。

## 一、子镜表是唯一分镜载体（宫格故事板已取消，为什么）

2026-11-02 定版：不再做宫格/漫画式分镜故事板，画布上也不建故事板节点。原因三条：

1. **宫格本身是一张要生成的图，错一格整张废。** 九格里有一格脸崩了，整张重做；子镜表改一个字就行。
2. **宫格不会自动变成镜头。** 模型按「一条视频＝一次生成」干活，它读不懂格子之间的关系；时长、运镜、声音这些，宫格根本画不出来。
3. **分镜真正要交代的东西，宫格装不下。** 谁在第几秒转头、光从哪边来、出口帧什么姿势——这是文字活，不是画活。

宫格取消后，子镜表承担全部职能：拆子镜、定景别与运镜、定动作与站位、定光影与声音。

**一条子镜的参考素材只有四类**（上限 **9 图 / 3 视频 / 3 音频**）：

- 该镜出场的人物资产
- 场景资产
- 道具资产
- `音色·<角色名>` 音频

**例外只有一种**：个别镜头文字＋资产确实出不来，才为这一镜单独做一张关键帧参考图（不是宫格），一次只补需要的那几镜。别一上来就整套做。

两件配套硬规矩：

| 规矩 | 怎么做 |
|---|---|
| 不出现分格画面 | 提示词负面约束写「不出现分格画面、九宫格、漫画框线、分镜说明文字」 |
| 无书写载体强制 | 画面里出现纸张/单据/账本/借据/匾额/招帖/对联/木牌，模型一定把台词写上去。要么禁掉载体，要么改拍背面、剪影、手部特写 |

## 二、子镜表字段

十二个字段，一个都不能少。中间是可选值，右边是怎么选。

| 字段 | 可选值 | 怎么选 |
|---|---|---|
| **镜号** | `T01` `T02`…；拆出来的子镜 `T05-1` `T05-2` | 一个子镜一个号，不跳号、不重号。剧本的场次号另起一列，别混。动了编号必须写明原因 |
| **时长** | 1.5–5 秒最常见；接触帧 0.1–0.2 秒；单镜超 6 秒要理由 | 按 **24fps** 算，1 帧≈0.042 秒，所以写 0.1 秒的倍数最省事。口播按 **4–5 字/秒**估（含停顿；7 字/秒只是生成前预检上限）。同一生成段里所有子镜相加，必须正好等于这段的生成时长 |
| **景别** | 大远景 / 远景 / 全景 / 中全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 | 先问「这一镜观众必须看清什么」：看清关系用中景以上，看清情绪用近景，看清一个细节才上特写 |
| **焦段** | 鱼眼 8–16mm / 超广 14–24mm / 广角 24–35mm / 标准 35–50mm / 中长焦 85mm / 长焦 135–200mm / 微距 | 24mm 交代环境，35mm 通用，50mm 对话，85mm 人像与压迫，135mm 偷窥与孤立。一集里别五个焦段乱跳 |
| **机位** | 高度（平视/微仰/微俯/大仰/大俯/顶拍/地拍）＋方向（正面/侧 45°/侧 90°/背面/荷兰角）＋轴侧（A 侧/B 侧） | 机位决定看到哪块背景。**每换一次机位，都要重算左右、遮挡和背景**，不能照抄上一镜 |
| **运镜** | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 | 一个子镜只选**一个主运镜**。固定是默认，不丢人。要复合运动，写清连续路径和为什么非这样不可 |
| **人物/非人物镜头** | 人物镜头（有脸、有表演）／非人物镜头（空镜、道具、手、背影、脚） | 有对白的镜必须是人物镜头且嘴可见；OS 例外，OS 不对嘴。非人物镜头用来过渡、施压、藏信息 |
| **动作与站位** | 谁、在哪（画面百分比或固定物锚点）、朝哪、手上有什么、从哪到哪、接触到什么、结果是什么 | 站位优先用**不动的地标**绑定：门框左缘、桌沿、柱子、石阶。写「站在旁边」等于没写 |
| **光影** | 光源（窗/灯/火/月光/手机屏）、方向（顺/侧/逆/顶/底）、明暗（高调/低调）、色温（暖 3200K / 中性 4000K / 冷 5600K）、介质（烟/尘/雨/雾） | 先有光源，再有光效。光向同一场里不许乱换；要变，必须有剧情或光源动机 |
| **声音** | 对白 / OS / VO / 环境声 / 音效 / 配乐 | 写清谁在说、第几秒响、画内还是画外。环境声要有来源；对白不许两人同时说 |
| **出场对象** | 人物、场景、道具，逐个写名字 | 这一列直接决定挂哪几张参考图。漏一个人，模型就自由发挥 |
| **参考编号** | 参考图 1…9、参考视频 1…3、参考音频 1…3 | 编号必须和画布连线一致，每条提示词内重新编号。写了编号画布上没有，等于编造引用 |

排版底线：**一镜一个主变化**。信息变、情绪变、位置变，一次只挑一个。一个子镜里又揭示身份又打人又换场，模型只会给你一锅粥。

## 三、镜头语法速查

每张表都是「什么时候用 + 常见错误」。拿不准就回来看一眼。

### 景别

| 景别 | 什么时候用 | 常见错误 |
|---|---|---|
| 大特写 | 眼睛、手指、伤口、关键道具的细节 | 全集都在大特写，观众不知道人在哪 |
| 特写 | 情绪爆点、反应、关键信息揭示 | 特写里没有新信息，只是脸大 |
| 近景 / 中近景 | 对话主力，竖屏的默认景别 | 两个人对话全用近景，空间关系丢了 |
| 中景 | 动作起手、两人对峙、手上有活 | 用中景拍大场面，什么都看不清 |
| 全景 | 交代空间、人和环境的关系、人物进出画 | 竖屏用全景，人小得看不清脸 |
| 远景 / 大远景 | 孤立、渺小、大场面、开场定调 | 竖屏慎用；一集开头就来大远景＝劝退 |

### 焦段

| 焦段 | 什么时候用 | 常见错误 |
|---|---|---|
| 24mm | 环境交代、近身打斗、狭窄空间、夸张透视 | 拿它拍人脸特写，鼻子变形 |
| 35mm | 通用纪实、半身带环境、走动跟拍 | 当万能焦段，全集没有远近变化 |
| 50mm | 对话、接近人眼、最不容易出错 | 全靠它就显得平，压不出也疏不离 |
| 85mm | 人像、压迫感、背景压平、亲密或威胁 | 用它拍全身打斗，人一动就出画 |
| 135mm | 远距偷窥、孤立、压缩空间 | 手持用它，画面抖到没法看 |

### 机位

| 机位 | 什么时候用 | 常见错误 |
|---|---|---|
| 平视 | 平等、客观、对话默认 | 全集平视，画面像监控 |
| 仰拍 | 强者、威胁、高大、宣誓 | 随手仰拍，天花板入画，空间乱 |
| 俯拍 | 弱势、被压制、可怜、审视 | 拿俯拍拍主角高光，气势全泄 |
| 顶拍 | 命运感、渺小、地图式交代 | 竖屏顶拍信息量极低 |
| 地拍 | 怪物视角、脚步逼近、压迫 | 用多了像拍蚂蚁 |
| 轴侧 | 每个机位都要标 A 侧 / B 侧 | 换机位不重算左右，两人突然换位 |

### 运镜

| 运镜 | 什么时候用 | 常见错误 |
|---|---|---|
| 固定 | 默认。稳、省、不穿帮，靠人物进出画和表演推进 | 以为不动就是没电影感，于是乱推 |
| 推 | 情绪升温、逼近真相、注意力收缩 | 切近景当成推；一推到底不收 |
| 拉 | 抽离、暴露环境、原来不止这些 | 拉得太快，观众还没看清就没了 |
| 摇 | 扫视空间、发现画外、跟着视线走 | 摇到一半停住，像机器坏了 |
| 移 / 跟 | 走位、展示空间、真正跟着人走 | 人物动就写跟拍，其实机位没动 |
| 升降 | 气势、俯仰关系变化、段落收尾 | 一镜里又升又移又推，模型必糊 |
| 手持 | 不安、真实、打斗、慌乱 | 对话也手持，观众晕 |

### 构图

| 构图 | 什么时候用 | 常见错误 |
|---|---|---|
| 中心构图 | 竖屏默认；对峙、宣誓、正面压迫 | 两人对话都放正中，像证件照 |
| 三分 + 视线空间 | 人看向画外时，把空间留在他看的那边 | 人看右边，右边却是墙 |
| 框中框 | 门框、窗、车窗外；困住、窥视 | 框太小，人脸被切 |
| 前景遮挡 | 层次、偷窥、紧张 | 前景挡住的正好是关键信息 |
| 对角线 | 动势、失衡、追逐 | 静态对话硬拗对角线，像要摔倒 |
| 留白 | 孤独、悬念、压迫 | 竖屏左右留白，画面空掉一半 |

### 光影

| 光影 | 什么时候用 | 常见错误 |
|---|---|---|
| 顺光 | 交代清楚、喜剧、日常 | 全集顺光，画面像证件照 |
| 侧光 | 立体、善恶两面、内心冲突 | 侧光方向每镜都换，剪起来像跳轴 |
| 逆光 | 剪影、神秘、英雄登场、希望 | 逆光还要求看清表情，两头不靠 |
| 顶光 | 压抑、审讯、绝望 | 顶光配笑脸，观众读不懂 |
| 底光 | 恐怖、邪恶、非人 | 日常戏用底光，像鬼片 |
| 实用光源 | 窗、灯、火、手机屏、月光，有源才可信 | 无来源的神光，一眼假 |

### 转场

| 转场 | 什么时候用 | 常见错误 |
|---|---|---|
| 硬切 | 默认，九成镜头都该用它 | 该硬切的地方加淡入淡出，节奏立刻拖 |
| 动作接动作 | 上一镜抬手，下一镜手已落下 | 动作接不上，观众看见剪了一刀 |
| 视线接视线 | 上一镜看过去，下一镜看到的东西 | 看的方向和下一镜物体位置相反 |
| 声音先入 | 下一镜的声音提前 0.3–0.5 秒进 | 提前太多，观众以为穿帮 |
| 匹配剪辑 | 同形状、同构图、同动作跨时空 | 为炫技硬凑相似，观众一头雾水 |
| 遮挡转场 | 人恰好扫过镜头遮住画面 | 遮挡物太大，黑屏半秒像卡了 |
| 黑场 | 时间跳跃、场与场之间 | 集尾用黑场，等于把悬念关掉 |

## 四、竖屏（9:16）语法（仅用户明确要求时）

竖屏不是「横屏转个方向」，是另一套语法；默认项目走 16:9，本节仅在用户点名竖屏时使用。

### 1. 构图

- 画幅 9:16，窄而高。主体**居中偏上**，头顶留约 1/5，脚可以切掉。
- 横屏的左右并排，到竖屏要改成前后分层：过肩、前景背影＋后景脸。
- 双人对话别并排站。一个在前景虚、一个在后景实，视线才成立。

### 2. 镜头经济性

- 能用 3 个镜头讲完，就别用 8 个。竖屏信息密度低，镜头一多就碎。
- 一镜只说一件事：要么给信息，要么给情绪，别兼着来。
- 成片 1 分钟按 12–20 个子镜估；打斗段可以密到 25 个以上。

### 3. 表演克制

- 手机屏幕小，微表情看不见。要「大动作＋停顿＋眼神方向」，不要「皱眉思考」。
- 演「忍住不哭」：写「下颌绷紧、呼吸停半拍、眼睛往上抬」，别写「悲伤」。
- 反应比动作值钱：被打的人、听话的人怎么反应，往往才是这一镜的信息。

### 4. 节奏

- 前 3 秒必须出钩子：冲突、危险、指控、反转、欲望，任选一个。
- 大约 2 秒一次画面或动作变化，只当诊断用；长镜和静止更能增压时就保留。
- 切点跟动作和情绪走，不跟字数走；话没说完也能切。

### 5. 段内衔接五维度

| 维度 | 接什么 | 断了会怎样 |
|---|---|---|
| 180° 轴线 | 机位不过轴，人物左右关系不变 | 两人突然换位，空间崩了 |
| 视线匹配 | 看的方向、高度、下一镜的接收方对得上 | 两人像在各看各的 |
| 动作衔接 | 上一镜起手，下一镜落下，动作重叠 60–80% | 观众看见跳帧 |
| 道具状态 | 朝向、持械手、单实例（同一道具只有一个）不变 | 剑换手、杯子凭空多一个 |
| 景别跳跃 | 相邻镜景别有级差，不连 3 镜同景别 | 画面平、看不出切点 |
| 声音（补充） | 环境声不断层，对白不重叠 | 声音一断，空间就散了 |
| 光向（补充） | 同一场里主光方向、色温不变 | 像换了个地方拍 |

五条里**动作衔接与道具状态最容易被忽略**，交付前专门看一遍。

### 6. 运镜五模式

| 模式 | 用在哪 | 手感 |
|---|---|---|
| 固定＋人物进出画 | 对话、压迫、省预算 | 最稳，几乎不穿帮 |
| 缓推 | 情绪升温、逼近真相 | 每秒推进不超过画面的 5%，快了就晕 |
| 横移 / 跟移 | 走位、展示空间、赶路 | 速度跟人物走，别快过脚步 |
| 手持跟拍 | 打斗、慌乱、追逐 | 要有呼吸感，不是地震 |
| 升降 / 环绕 | 气势、关键揭示、段落收尾 | 一集用 1–2 次，多了就廉价 |

一个子镜只选一个模式。真要复合运动，写清连续路径和必要性，别堆术语。

## 五、打斗动作镜头怎么拆

先定一件事：**这场谁赢、赢在哪一下。** 没有胜负逻辑的打斗，只是两个人乱挥。

### 一个动作拆七个相位

| 相位 | 拍什么 | 时长 | 常见错误 |
|---|---|---|---|
| 起势 | 预备、蓄力、眼神锁定目标、重心下沉 | 0.4–0.8 秒 | 一上来就打，没有预备，打击感为零 |
| 过程 | 位移、轨迹、衣角与头发被带起 | 0.2–0.5 秒 | 只拍拳头不拍身体，像贴图 |
| 接触 | 碰上的那一帧：皮肤变形、火花、尘土 | 0.1–0.2 秒 | 接触帧糊掉，观众看不见打中 |
| 顶点 | 力量最大、形变最大、表情最狠 | 0.1–0.3 秒 | 顶点和接触挤在一帧，力度读不出 |
| 结果 | 对方后退、飞出去、倒地、武器脱手 | 0.3–0.8 秒 | 打完两人站着不动，像排练 |
| 反应 | 表情、呼吸、伤口、旁观者 | 0.3–0.6 秒 | 只拍赢家，输家没反应，戏就断 |
| 出口 | 定格姿势、转身、下一段的起手位 | 0.2–0.4 秒 | 出口姿势接不上下段，剪辑必跳 |

### 拆镜三条规矩

1. **一拍一镜**：一个相位一个子镜，别把起势＋接触＋结果塞进一镜。
2. **接触帧单独给镜**：这是打击感的命门，宁可短到 0.1 秒。
3. **轴线别乱**：打斗按移动方向定轴；换轴必须有可见的运镜或中性机位过渡。

### 出口帧 ＝ 下段入口帧

每段最后写一行「出口帧」：

```
出口帧：谁（画面什么位置、什么姿势）、手在哪、看哪、光从哪边来、脚下踩着的是什么。
```

下一段第一镜必须能直接用这一帧接上：姿势不变、手位不变、光向不变。接不上，说明这一段拆错了，回去改出口。

### 打击感三件套

- **预备慢**：起势比打出去慢一倍，观众才跟得上。
- **接触顿**：接触瞬间给 1–2 帧微慢或定格；24fps 下就是约 0.04–0.08 秒。
- **反应大**：受力方的头、肩、脚步要明显位移，衣服和头发要有延迟。

三个都做到，480P 也有打击感；缺一个，4K 也软。

## 六、分镜表交付自检表

逐条打勾，缺一条就回去改。

1. 镜号连续，不跳号、不重号；拆出来的子镜用 `-1` `-2` 标。
2. 每镜都写了时长；同一段相加，正好等于生成时长。
3. 每镜只有一个主变化、一个主运镜。
4. 有对白的镜，说话人写清、嘴可见；OS 标了「不对嘴」。
5. 台词逐字保留原文，没概括、没改词、没合并。
6. 影响剧情的数字按原字面写：「十七条」不写成「17 条」。
7. 站位用固定物锚点，全表搜不到「站在旁边」这种空话。
8. 换过机位的镜，左右、遮挡、背景都重算过。
9. 同一场里光向和色温一致；有变化就写了光源动机。
10. 每镜的出场对象列全，参考编号和画布连线对得上。
11. 参考素材不超 9 图 / 3 视频 / 3 音频。
12. 画面里没有必须写字的载体；有就改成了背面、剪影或手部特写。
13. 段与段之间，出口帧能接上入口帧；五维里动作、视线两维专门核过。
14. 开场 3 秒有钩子；集尾留了悬念。
15. 打斗镜七个相位齐，接触帧单独有镜。
