# 短剧助手 DJZS（V1）

> 画布使用提示：图像高清放大 / 视频高清放大节点**必须在提示词框里填任意一个字**（例如「高清放大」），否则发送按钮是灰的；视频放大的输入要从左侧「参考视频」圆点接进来（Toonflow 里视频只走参考位，所以模式显示「混合参考」属正常）；视频节点新建后默认 9:16，记得点一下 16:9。

> 这是第 1 版（V1），先用起来，遇到问题再迭代。

本技能是**唯一入口**：先说清当前在哪一步，再只读对应的一份参考文件，不要一次全读。
旧技能（sd-* 六件套、sw-* 十一件、toonflow-production、workflow、v118workflow、shortDramaAssistant、short-drama-factory、fuyaoai-vip、h3-prompt-writing、minimax-h3-prompt-optimizer、cinematic-director-zh、localPromptOptimize、impact-frame-studio、productionLessons）已被本技能合并，**不要再分别加载**。

## 0. 硬规则（先记住，违反即返工）

1. **默认生成配置**（用户 2026-11-06 定版，除非当次明确改）

   | 类型 | 供应商 / 模型 | 参数 |
   |---|---|---|
   | 图片 | comfyui / Moss 文生图（mossImage） | 1K、**16:9**、30 步、扩写按需 |
   | 视频 | comfyui / **Pika H3全参**（默认） | 混合参考（imageReference:9 + audioReference:3，不用首尾帧）、**16:9**、480P、时长按分镜 |
   | 视频（备选） | comfyui / MiniMax H3 原版（多参考） | 需要加速 LoRA 或手动采样步数时切换 |
   | 图像高清放大 | comfyui / **图像高清放大（SeedVR2）**（默认） | 长边 1920、均衡模式；4K 只在用户要求时 |
    | 视频高清放大 | comfyui / **视频高清放大（SeedVR2）**（默认） | 长边 1920、均衡模式、RIFE 2 倍插帧（24→48 帧）、保留原声与时长 |
   | 人物音色 | toonflow / seed-audio-1.0 | zh-CN、24kHz、wav |
   | 文本 | Ollama / qwen3.8:27b | 本地 |

   **画幅默认 16:9 横屏**：分镜、构图、机位、运镜一律按横屏写（左右站位、横向留白、横移/摇镜）；9:16 竖屏与 21:9 宽银幕只在用户明确要求时用。

2. **跨集资产复用（2026-11-06 用户定版，违反即返工）**：前面集数已出过的人物、场景、道具、`音色·<角色>`，后面集数**一律引用，不重新生成**。做法：后续集画布建**显示节点**——图片用 `remote-imageNode` ＋ `node:setImage`，音频用 `remote-audioNode` ＋ `node:setAudio`，路径直接填前面集该节点 outputs 的工作区相对路径（`assets/<源节点ID>/xxx.png|wav`）。节点命名标来源：`资产·程苍（引用·第01集）`。只有造型/年龄/身份变了、或从未生成过，才新建生成节点。**音色全剧只生成一次。**

   建资产节点前**必查一遍**：①读前几集 `.agent` 里的资产清单/画布节点；②列出可复用项（人物、场景、道具、音色）与它们的 `assets/<节点ID>/…` 路径；③能引用的一律引用，只补本集缺失。**重复生成同一资产按返工处理。**

3. **提示词默认按官方标准**：图片一律按 MOSS 官方正文写法（中文自然语言、主体→动作→环境→光线→镜头→质感）；视频一律按 H3 **官方六段式**组织（subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music），即使没有参考素材也照六段写。
4. **两段式出片**：先全片 480P 样片 → 用户挑满意画面 → **用户下令**再统一跑 720P/30 步。不自动升档、不擅自改用户已定参数。
5. **样片闸口**：先拿信息最全的 1 镜跑通「分镜→提示词→资产→生成→验收」全链路，模板冻结后再批量。
6. **自检抽帧**：每次出片自己抽首/中/尾帧或读图检查并如实报告，不等用户指出；没跑、没看图就明说。
7. **不做宫格/漫画故事板**（2026-11-02 用户定版）：分镜载体只有「子镜表」；参考素材 = 该镜出场的人物资产 + 场景资产 + 道具资产 + `音色·<角色>`（≤9 图 / ≤3 视频 / ≤3 音频）。
8. **无书写载体强制**：画面出现纸张/单据/账本/匾额/招帖/对联/木牌 → 模型必写错字；要么禁掉载体，要么拍背面/剪影/手部特写。
9. **素材真实性**：不得编造引用、音色绑定或生成结果；提示词里写的参考编号必须在画布上真实存在。
10. **批量任务一次排队，长任务不判失败**：同一批图片/视频要**一次性把全部任务提交给 ComfyUI 排队**（本机 ComfyUI 支持队列，多任务可同时排队执行），提交完再统一等结果；不要出一张就停手等用户催，也不要一张一张串行提交。
    视频渲染很久（十几分钟到半小时都正常），等待期间**不得因超时判定失败**：只要任务 id 还在、ComfyUI 没明确报错，就继续等或稍后复查；只有 ComfyUI 返回明确错误才算失败。
11. **复盘落库**：每次返工或用户提出修改 → 在项目目录 `.agent/复盘.md` 记「现象 → 根因 → 可执行规则」，下一次开工先读。
12. **提示词五步走**（2026-11-08 定版，缺一步即返工）：
    - **视频**：①每镜先填**动作分解表**（发力/支撑点、轨迹、接触点、结束态、道具状态，见 `逻辑与镜头.md` 与 提示词.md §6.6），填不出来不许写句；②每集定**三段锚**（风格/人物/场景，§0）；③按 **4.5 字段映射表** 把分镜列逐项落到句子，镜头行按 **§6.7 六要素模板**（景别/角度/机位运动/焦段/光线/起幅落幅）；④按 **6.5 信息单元标准** 凑满六项并过 **§6.8 逻辑六问**；⑤交稿前跑 `提示词体检.md`（`sandbox` 执行 `python3 prompt_lint.py 提示词.md --duration 6`），**≥80** 才交。
    - **图片**：①按 **8.6 图像信息单元标准** 凑满六项（五件套 / 姿态朝向 / 景别机位 / 环境 / 光线 / 色调质感）；②同类型图套 `图像模板.md`（定妆 / 三视图 / 场景 / 道具 / 状态变体 / 首尾帧）；③交稿前跑体检（Toonflow 内用 `sandbox` 工具：`python3 prompt_lint.py 提示词.md --kind image`），**≥80** 才交。
14. **道具资产按「结构 + 用法视角」出**（2026-11-08 定版）：每件道具先拆 3–6 个零件、写清材质与尺寸；**视角由分镜里的出现形态决定，2–4 个不固定**（秤：被拎起 + 放桌面 + 刻度特写；刀剑：插鞘 + 拔出并排 + 护手特写；窝头/木棍：两个就够）。**画面里不许放手、硬币、尺子或其它道具当参照**，尺度只用文字；一板一件；刻字写「磨平的字迹」。缺失的道具按剧情补，能复用前集的引用不重生成。

## 2. 剧本阶段要点（细节见 编剧.md）

- **先立戏核**：一句话说清「谁、要什么、被什么挡住、代价是什么」；说不清就不写。
- **短剧节奏**：前 3 秒给钩子，每集 1–2 个反转，集尾必留悬念；对白按 **4.5–5 字/秒**估算（含停顿），**7 字/秒**只作生成前预检上限。台词量与集长对不上时，先算台词秒数再决定压缩还是拆分，不要硬塞。
- **人物**：主角要有「渴望 vs 错误信念」；对手必须强到能逼主角改变；配角各有自己的目的。
- **单场戏**：晚进早出；每场必须有一次价值转折（关系/信息/处境变），没有转折就删。
- **对白**：像人说话，不像说明书；有话不直说，用动作和潜台词；每个角色有自己的用词习惯。
- **格式**：场号 + 场景 + 日/夜 + 人物 + 动作 + 对白；交付前过「剧本交付自检表」。

## 3. 分镜阶段要点（细节见 分镜.md）

- 子镜表字段一个不能少：镜号、时长、景别、焦段、机位、运镜、人物/非人物镜头、动作与站位、光影、声音、出场对象、参考编号。
- 横屏优先（本项目默认）：左右站位、横向留白、横移/摇镜；一个镜头只说一件事。
- 镜头经济：能用 3 个镜头讲完就别用 8 个；切点跟着动作和情绪走，不跟着字数走。
- 段内衔接：动作接动作、视线接视线、声音接声音；出口帧要能当下一段入口帧。
- 打斗镜头单独拆（见 打斗.md）：起势 → 过程 → 接触 → 顶点 → 结果 → 反应 → 出口。

## 4. 提示词阶段要点（细节见 提示词.md）

- **图片**：中文自然语言整段描述，先说主体与动作，再说环境光影与镜头，最后风格质感；比例/分辨率/步数按画布节点设置，不写进正文。
- **视频（H3，默认六段式）**：先定模式（T2VA/I2VA/FL2VA/L2VA/Ref2VA），再按六段写：subject_definitions / summary / retention_analysis / detailed_description / overall_soundscape / non_diegetic_music。
- **镜头写单元，不写字数**：每镜必须凑满六个信息单元（动作 3 / 空间 2 / 光 1 / 镜头 1 / 声音 3 / 结束态 1），同类型镜头套 `镜头模板.md`；交稿前跑 `提示词体检.md`（`tools/prompt_lint.py`），**≥80 分才交**。
- **参考素材**：提示词里按编号指代（参考图 1/2/3…、参考音频 1…），编号必须与画布真实连线一致；上限 9 图 / 3 音频。只挂资产与音色，**没有故事板**，要写【参考范围】段＋负面约束禁分格画面。
- **口型**：说话镜头写清「谁在说、说什么、语速与情绪」，台词放进 `<d>[Chinese]…</d>` 并绑 `(S1)`；画外独白镜头必须写【口型强制】全程闭唇。
- **负面约束**：只写必要项（不要字幕、不要分格、不要水印、不要多余手指等），不要堆一长串。

## 5. 打斗阶段要点（细节见 打斗.md）

- 四要素：**节奏**、**身法**、**招式**、**特效**。
- 先定「这一场谁赢、赢在哪一下」，再设计动作；没有胜负逻辑的打斗只是乱挥。
- 每个动作要有「发力点 → 轨迹 → 结果」；打击感来自：预备动作、接触瞬间的定格或慢放、受力方的反应。
- 镜头：主体不清时用中景跟拍，命中瞬间切特写或冲击帧。

## 6. 验收要点（细节见 验收与复盘.md）

- 生成前七项内容锁：逐字台词与 OS、原镜覆盖、文字/字幕、字面数字、固定物站位、反向差额、素材与音色真实绑定。
- 生成后抽帧检查：人脸/手部/文字/穿帮/动作连贯/音画同步；不合格写返修单，只重跑受影响的镜头。
- 交付前：分辨率、时长、帧率、音轨、字幕、AIGC 标识齐全。
