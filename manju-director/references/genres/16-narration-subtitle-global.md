# 解说 · 字幕 · 出海 · 二次创作

> 这一层管「片子做完之后怎么让它更好用、更能发、能发到别的语言」。我没写大全，写的是**能落到文件格式上的规范**：SRT 怎么写、旁白怎么排、翻译保留什么、二次创作的红线在哪。

---

## 1. 解说旁白（Storyboard Narration）

漫剧常用"画面 + 旁白"叙事，尤其是改编网文、节奏快的爽剧。

**写法三条**：
1. **一句一镜**。旁白以镜为单位，不跨镜；一镜一句话，最长 18 字。
2. **旁白只补画面说不出的**：时间跳跃、人物关系、心理动机。画面已经在演的事不要复述（"他推开门走进来"这种就是废话）。
3. **旁白与对白不同时占位**。同一镜里既有人说话又有旁白 → 观众听不清。二选一，另一条挪到下一镜或砍掉。

**旁白稿格式**（跟着子镜表走）：

```text
S07 | 00:08-00:11 | 旁白：他以为这一剑能了结一切。
S08 | 00:11-00:15 | 旁白：可山门里的灯，三年前就灭了。
```

## 2. SRT 字幕文件规范（交付必带）

**格式**：标准 SRT，UTF-8 无 BOM，扩展名 `.srt`。

```text
1
00:00:01,200 --> 00:00:04,000
他以为这一剑能了结一切。

2
00:00:04,000 --> 00:00:07,500
可山门里的灯，
三年前就灭了。
```

**硬规范**：

| 项 | 要求 |
|---|---|
| 时间码 | `时:分:秒,毫秒`，三位毫秒；起止之间用 ` --> `（前后各一个空格） |
| 单行字数 | 中文 ≤ 14 字；一行放不下就换行，**最多两行** |
| 每条时长 | 1.0–5.0 秒；低于 0.8 秒观众读不完 |
| 相邻条间隔 | ≥ 2 帧；不许时间码重叠 |
| 换行位置 | 在语义停顿处换，不要把一个词拆两行 |
| 标点 | 句末不加句号；`！？` 保留；省略号用 `……` |
| 说话人 | 两人对话时在行首加 `角色名：`，只加一次不要每条都加 |
| 专名 | 人名、地名、招式名全片统一写法，建一张对照表 |

**不要做的事**：
- 不要把字幕烧进画面再让模型生成（它必写错字，且改不了）。
- 不要一条字幕跨三个镜头。
- 不要用字幕解释画面已经在演的东西。

---

## 3. 出海（翻译与本地化）

**翻译四条纪律**：

1. **先建专名表再翻**：人名、地名、门派名、招式名、称号，一次性定死译法，全片统一。同一个"少主"不要一会儿 young master 一会儿 heir。
2. **文化负载词加意译，不加注释**：`走火入魔` → `qi deviation` 这类行内译法可用；`江湖` 直译会丢意，译成 `the martial world` 并在首次出现时补半句语境。
3. **字幕长度按目标语言重排**：英文比中文长 1.6–2 倍，一条中文 14 字的句子译成英文往往要拆成两条，**时间码重新分配**，不要硬塞。
4. **口型对不上是正常的**：中文口型配英文字幕，不要让模型重生成画面去对口型（成本高且会变脸）。用字幕 + 重新配音两条路，配音改了就要重新卡时长。

**BGM 与音效**：跨语言版本保留原音效（打击、环境），**只换人声与字幕**。BGM 若含中文歌词，出海版必须换掉，否则观众听出戏。

**交付**：每条语言一版视频 + 一份 SRT；文件命名 `项目_集号_v3_en.mp4` / `.en.srt`。

## 4. 二次创作（重剪 / 混剪）

**能做的**（正规二创）：
- 重排叙事顺序（倒叙、插叙），改变信息释放节奏；
- 换配乐与音效，重做情绪曲线；
- 重新配旁白，换叙述视角（第一人称 / 旁观者）；
- 同一批素材做成不同时长版本（15s / 60s / 3min）。

**踩线的**（不做）：
- 以"规避平台原创识别"为目的的搬运、抽帧、镜像、变速、加滤镜去重——**这类需求我直接拒绝，不给方法**。
- 拿他人成片换配音当自己作品发布。
- 用他人 IP 角色做商用内容。

**判断标准一句话**：改写的是**叙事与表达**，你就是作者；改写的只是**像素排列**，你就是搬运。

---

## 5. 内容改良的三条合规底线

1. **真人素材**：只有授权参考才能做真人形象；无授权一律虚构角色。
2. **可识别 IP**：不用他人角色、标志、品牌做商用内容；致敬可以，复制不行。
3. **平台规则**：AI 生成标识按平台要求标注；不为了过审而删改成误导性内容。

- [ ] 人名地名招式名全片统一？有对照表？
- [ ] 出海版重排了字幕长度、换掉了中文歌词 BGM？
