# 参考素材契约：每个素材只管一件事

> 多参考翻车，90% 是因为**一个素材被当成"什么都参考"**。这一份把每张图、每条视频、每段音频写成一份**有作用域的契约**：借什么、作用在谁身上、哪段时间有效、保护什么、**不继承什么**。
> 核心口径来自 Seedance 2.5 多模态参考规范（`liyue-aigc/seedance-2-5-video-director`）与本书 `01-tech-core.md` §3。

---

## 1. 开工先填资产锁表（不许直接写正文）

| 资产 | 角色 | 生效时间 | 必须保留 | **不许继承** |
|---|---|---|---|---|
| `@Image 1` | 身份 / 场景 / 道具 / 画风 / 分镜 | 全片 或 某段 | 列出受保护特征 | 无关背景、原文字、原排版、原姿势 |
| `@Video 1` | 源片 / 动作 / 机位 / 编辑对象 / 转场 / 白模 | 全片 或 某段 | 选中的运动或画面 | 不想要的身份、材质、音频、视口元素 |
| `@Audio 1` | 音色 / 台词演绎 / BGM / 节奏 / 环境声 | 全片 或 某段 | 选中的声学特征 | 底噪、无关人声、不要的音乐 |

**规则**：
- 只用真实存在的行，**不许写"假设有 @Image 2"**。
- 用户只说角色不说顺序时，**沿用上传顺序**，并把映射写出来。
- 一个素材要当两种用途时，**拆成两条契约**，分别写作用域。

---

## 2. 参考契约句法（唯一正确写法）

```text
参考来源 + 借哪些特征 + 作用到哪个主体/哪一镜 + 生效时间 + 必须保护什么 + 不继承什么
```

**正确**：

```text
20-25 秒仅参考 @Video 2 中"预备—冲刺—起跳—空中举剑—挥砍"的重心与动作节奏，映射给 @Image 1 的小骑士；不要继承 @Video 2 的灰模人物、场景材质和其他时间段的动作。
```

**错误**（会被当成"整体照抄"）：
- `参考 @Video 2 的动作。`
- `参考这些图保持一致。`
- `风格照这个来。`

**四条铁律**：
1. 一个素材**只负责它声明的那一件事**。动作参考不许顺带管身份、背景、音色、画风。
2. 生效时间必须写。全片就写"全片"，否则写"第 3–7 秒"。
3. "不继承"必须写，不写就会被搬进成片（背景、文字、排版、原姿势、原光）。
4. 参考里**没有的信息不许指望它长出来**，要在正文补齐。

---

## 3. 人物参考怎么解释（保守优先）

**默认语义 = 完整可见的那个人**：身份、五官、脸型、肤色、年龄感、发型发色、身高、体型比例、可见服装（逐件）、鞋、配饰、整体气质。**不许自主改色、换款、增删配饰**，除非用户明确允许造型变化。

**不可见侧/背面**：按可见的剪裁、颜色、材质、结构、穿法**一致重建**，不许另设计一套衣服。

**默认不继承**：原图背景、构图、姿势、文字、裁切、原光线——除非用户另外指派了这些角色。

**收窄口径**：用户说"只参考脸""只锁身份"时，只保这一项，其余（服装造型）标为"创作补充"并说明。

**一张图里有情侣/群像**：按位置或用户命名**逐人独立绑定**，保持相对身高与比例；明写禁止：串脸、换装、复制身体、角色对调。

**图上不了但用户声明是人物参考**：契约保持符号化，按"完整可见人物"处理，**不许靠编衣服来补**。

**写实人物**（只在需要时写到这个深度）：
`specific adult age and ethnicity + skin tone and real texture + 3-4 distinctive facial traits + gaze/emotion + hairstyle/color/state + garment cut/color/material/wear + body frame/posture/temperament`

写实三锚：保留微毛孔与皮肤真实纹理、自然不对称、情境相关的轻微瑕疵（**别给塑料皮**）；眼神用可见的视线行为 + 内在情绪，不靠空洞形容词；头发给剪法、质感、状态与环境反应。
**锁死**：年龄、脸、发轮廓、服装、身材比例、身份，跨镜不变。
**默认**：纯文字描述的人物一律设为虚构、明确成年；真人身份只从用户授权的参考还原。
**别过度**：远景和快镜别塞看不见的面部微细节。

## 4. 多人群像：逐人绑定

```text
角色 A = @Image 1；角色 B = @Image 2；……
```

每人锁七件：身份五官 / 发型服装 / 身材比例 / 空间位置或入场方向 / 归属道具 / 动作与视线目标与关系 / 台词的音色来源。

群体要**明写人数**，区分主角与次要角色。身体接触时写清接触点与遮挡，别让胳膊糊成一条。相关时才加：`不串脸、不换装、不复制身体、不多肢、不转移道具`。

---

## 5. 音频参考：音色要绑到人和句子

- 用**干净、无底噪**的人声参考。
- **一条音轨只绑一个角色**，并把台词原文写出来。
- 说明保留哪些特质：音高/音色、情绪张力、语速、停顿、气息、强度、气声还是喊。
- 音色作用域要限定到**那句台词或那段时间**。
- 禁止这种写法：`用 @Audio 1 的声音`。

**正确**：`角色 A 在 8-11 秒说"……"，音色参考 @Audio 1，保持低沉、克制、略带停顿的悬疑语气。`

**台词长度必须合理**：说不完就砍字或延长这一拍，不要硬塞（同 `01-tech-core.md` §7）。

---

## 6. 去 BGM / 只保人声：四种说法别混

| 需求 | 写法 |
|---|---|
| 去音乐、保对白与环境 | `移除 @Video 1 的背景音乐，仅保留清晰人声对白和指定现场声；画面、原字幕及其他受保护视觉元素保持不变。` |
| 全静音 | `静音全部声音` |
| 只留对白 | `只保留人声对白，去掉音乐与现场声` |
| 换音乐 | `用 @Audio 2 替换原背景音乐` |

要写清哪些非人声保留、哪些去掉。**不许同时写"无 BGM"又提"配乐要求"**——自相矛盾的指令会让模型二选一，结果不可控。

---

## 7. 创意迁移：搬逻辑，不搬画面

借的是**镜头节奏、运动语法、转场方式、情绪弧线、喜感/萌感状态、构图逻辑、色彩推进、平台节奏**，不是搬它的脸和场景。

```text
参考 @Video 1 的 [要借的创作特征]，转译到 @Image 1 的 [目标主体] 与 [新场景]；保持 [目标必须不变的部分]，不要继承 [源片不想要的部分]。
```

---

## 8. 局部增删改：背景要按原信息补齐

六件必须写：**位置**（标记区 / 画面哪一侧 / 哪个物体 / 与谁的关系）→ **目标**（具体人/物/背景元素）→ **操作**（增/删/换成什么）→ **时间**（全程/固定区间/渐变进入）→ **重建规则**（按原透视、视差、遮挡、运动、材质、光照补齐）→ **保护清单**（哪些人、动作、构图、背景、声音、文字不许变）。

带标记时写：`红框内 / 红框外`、`蓝色标记处`、`箭头指向处`，不许写"改这里"。

---

## 9. 透视重构

```text
把 [源视角/构图] 改为 [目标视角/构图/运动]，同时保持 [主体、动作时序、空间、背景、身份]。
```

控制项：机位高度与角度（俯/平/仰）、视点（第一人称/第三人称/固定正面）、景别与焦段、运动（推/拉/摇/俯仰/环绕/跟）、重建的场外空间与比例逻辑。
如果目标视角由某条参考视频提供，写清"借它的视角特征，不继承它的原始内容"。

---

## 10. 绿幕合成

分开写三层：
1. **前景**：绿幕源、要抠的主体，保轮廓、运动、时序、身份；
2. **背景**：目标场景或底片；
3. **匹配项**：机位角度、比例、地面接触、视差、光向、色彩溢光、阴影、大气、运动模糊；
4. **交互时序**：爆炸、天气、粒子、掠过物的时间对位；
5. **清除项**：绿边、边缘光晕、闪烁、悬空脚、贴上去的光。

不是绿幕素材就别写"绿幕合成"这个词。

---

## 11. 指令冲突时的优先级（不许和稀泥）

1. 明确受保护的源素材或身份
2. 明确的编辑目标与时间区间
3. 明确的素材角色分工
4. 明确的时长、台词、音频、字幕要求
5. 风格与创作补充

**同级两条明确指令打架 → 问一句，不许自己选。**
低优先级（风格参考）与高优先级（身份/源片锁）冲突 → **保高优先级，只取兼容的风格特征**。

## 12. 自检（写完契约逐条过）

- [ ] 有没有哪条写成"参考它"这种没作用域的空话？
- [ ] 人物参考是按"完整可见人物"处理的？收窄的有没有写明？
- [ ] 多人群像逐人绑定了？人数写了吗？
- [ ] 音色绑到人和句子了？台词能在这个时长内说完？
- [ ] 局部修改写了背景重建规则与保护清单？
- [ ] 冲突时是提问还是自己选了？（必须提问）
