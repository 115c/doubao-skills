# 提示词输出契约（可机检的那一层）

> `01-tech-core.md` 管**写什么**（五块结构、时间轴、身份锁）。这一份管**写成什么形状**、以及**交付前怎么机器验一遍**。
>
> 分工：写内容靠 `01`，定形状靠这里，验形状靠 `djzs/tools/prompt_lint.py` + 本文件 §8 的十条机检。
> 来源：LocalMiniDrama 1.2.9 的「全能片段」用户消息构建器（`universalSegmentPromptBundle.js`）—— 它把提示词做成了**行数、秒数、槽位都能被程序校验的固定格式**。这是它比我们强的地方，抄的是形状，不是它的引擎。

---

## 1. 为什么要输出契约

自由写提示词的通病：读着像那么回事，但**没法判对错**。

- 写了"5 秒"，实际段内时间加起来 8 秒 → 时间轴崩。
- 写了"分镜1、分镜3"，跳号 → 模型漏一拍。
- 写了 `@场景`、`@林薇` 指代参考图 → 模型不知道这是第几张，人物乱绑。
- 写了"多画面并列" → 出来一张分屏图，不是片子。

上了契约之后，这些错**不用人眼看，脚本就能判**。

---

## 2. 全能模式（多图参考 · 单条成片）：3 + M 行

**总行数 = 3 + M**，M 是你决定的时间轴节拍数（1–8）。

```
第1行： 画面风格和类型: <画风参数 + 类型>，<光色与质感>，<排除清单>
第2行： 生成一个由以下M个分镜组成的视频。
第3行： <锚点句 —— 见 §2.1，必须整句固定>
第4行： 分镜1： T1秒: <该子时段内的动作 + 运镜>
…
第3+M行：分镜M： TM秒: <…>
```

**四条硬约束**：

| 约束 | 判法 |
|---|---|
| `T1 + T2 + … + TM` **严格等于**本条总时长 | 求和比对，差 0.1 秒都不行 |
| 每个 `Tk > 0` | 不许出现 `0秒` |
| 分镜序号**连续无跳号**，且末尾号 = 第 2 行声明的 M | 逐行读号 |
| 除这 3+M 行外**不许有任何附加行**（不写说明、不加 markdown、不加英文小标题） | 行数校验 |

**为什么第 2 行要写死这句话**：它是**声明段数**的位置。模型生成时先声明、再逐段写，漏段率明显低于"直接开写"。这句话同时也是机检的锚点——第 2 行的数字必须等于实际分镜行数。

### 2.1 第 3 行锚点句（二选一，整句照抄）

**A. `@图片1` 是场景时**：
```
环境、光影与陈设定性参考 @图片1。若 @图片1 为宫格或多画面拼图，禁止成片复刻其分格或并列布局，仅提取统一的室内空间与光线语义；须单镜头完整连续画面。
```

**B. 首张参考图是角色时**：
```
本片段以首张参考图 @图片1 作为画面锚点展开。
```

**为什么要单独一句**：宫格场景图是漫剧最常见的参考素材，模型天生爱复刻格子。把"禁止分格"写在**固定的一行**里，比夹在一大段描述中间更有效——它每次都在同一位置被读到。

## 3. M 怎么定（不许照抄公式）

系统给的启发值 `M ≈ 总时长 / 5`（上限 8）**只是提示，不许直接采用**。定 M 看四件事：

| 看什么 | 影响 |
|---|---|
| 对白密度 | 对白长、机位少 → **M 取小**（甚至 M=1，用一行写满时间流动） |
| 机位与运镜变化 | 每换一次机位/景别，至少要给一个节拍 → M 取大 |
| 段落边界 | 本镜的段落标题与上一镜**不同** → 转场或新叙事块，M 可加大，前几秒先给空间/情绪，再入冲突 |
| 剧本高潮位置 | 高潮拍必须独占一个节拍，不和铺垫挤一行 |

**反向纪律**：同段落延续、又只有对白 → M 保守。把 8 个节拍全塞进一个静止对话镜，观众看到的是 8 次无意义切换。

**M=1 时**：写 `分镜1： <总时长>秒:`，一行写满整段的时间流动（起手 → 中段 → 落点），不是"一句话概括"。

## 4. 槽位语法（参考图怎么指）

这是**最容易错、错一次全片人物乱绑**的地方。

**规则**：

1. 只能用 `@图片N`（**阿拉伯数字**），`N` 与参考图上传顺序严格一致。
2. `@图片N` 与后面的文字之间保留**一个半角空格**（`@图片1 的侧脸`，不是 `@图片1的侧脸`）。
3. **禁止**用 `@场景`、`@姓名`、`@道具名` 指代参考图。名字列表只用来理解剧情，不是占位符。
4. `@图片1` 若是场景 → 只写环境/光影/陈设；**人物外貌与动作从 `@图片2` 起**，并且要写明"禁止写「@图片1 中的某某」"。
5. 场景参考若是四宫格/九宫格 → 只取家具、装修、色调、空间关系、光影；**成片必须单镜头连续画面**，不许复刻网格（见 §2.1 A）。
6. 一张图都不给时：**不许编造 `@图片N` 指向不存在的素材**。要么先补图，要么整段不写槽位、只按剧本与分镜字段写运镜和情绪。

**绑定块写法**（每个角色一行，便于逐行核对）：

```
「林薇」→ @图片2（外貌/动作绑定 @图片2 ，示例：@图片2 的侧脸；禁止「@图片1 中的林薇」）
「顾长风」→ @图片3（外貌/动作绑定 @图片3 ，示例：@图片3 的侧脸）
```

## 5. 邻镜上下文必须注入

单看一镜写提示词，必然写不出衔接。写每一条时，**必须同时喂进邻镜**：

| 注入项 | 内容 | 长度限制 |
|---|---|---|
| `CONTEXT_PREV` / `CONTEXT_NEXT`（简版） | 上一镜 / 下一镜的动作（无动作则退化为「地点 + 时间」） | 各截 **160 字** |
| `NEIGHBOR_PREV_DETAIL` / `NEIGHBOR_NEXT_DETAIL`（详版） | 镜号、标题、段落名、动作、对白、旁白、景别、运镜、氛围 | 按字段给，不截断 |
| `SHOT_ORDER` | 本镜在全集中的序号 / 总数 | — |
| `SHOT_POSITION_TAG` | `first_in_episode` / `middle_of_episode` / `last_in_episode` | — |
| `BOUNDARY_HINT` | 段落标题变了 → 转场概率高 → M 可加大；没变 → M 保守 | — |
| 全集剧本 | 供理解上下文 | 截 **20000 字符**，超了标 `[TRUNCATED]`，靠分镜字段补 |

**首镜与末镜**：前邻写 `(first shot)`、后邻写 `(last shot)`，不许省略——不写模型会自己编一个"前面还有戏"。

## 6. 经典模式（首帧/尾帧链路）的契约

走"文本 → 首帧 / 尾帧 → 视频"这条链时，契约换成另一套：

| 段 | 必填 | 校验 |
|---|---|---|
| 首帧提示词 | 景别 + 机位 + 人物状态（表情/姿态/服装）+ 空间 + 光 + 画风参数 + 排除清单 | 无文字载体；不含运镜动词 |
| 尾帧提示词 | 同首帧，但**状态必须是首帧动作的落点** | 与首帧同一空间、同一光向；人物服装不变 |
| 视频提示词 | 起点状态 → 动作过程 → 落点状态 → 运镜 → 声音 | 起点=首帧、落点=尾帧，三处人物与空间描述必须一致 |

**判定口径**：首帧、尾帧、视频三段里，**人物外观描述、空间描述、光向**出现不一致，就是硬伤，先修一致性再谈美感。

---

## 7. 参考图缺失时的行为（硬闸）

没有场景/角色/道具参考图时，不允许"先跑一条看看"。

- 走全能模式 → **不生成**，先要求补至少一张参考图。理由：无图时 `@图片N` 全是编的，出来的片子和后续资产体系对不上，等于白烧。
- 走经典模式 → 可以先出首帧图，但出视频前必须先把首帧图作为参考挂上，否则人物必飘。

## 8. 交付前十条机检（可脚本化）

`djzs/tools/prompt_lint.py` 已有的 20 条保留，这里追加**形状类**十条：

| # | 检什么 | 不合格判据 |
|---|---|---|
| 1 | 段数声明 | 第 2 行的 M 与实际「分镜k」行数不等 |
| 2 | 时间求和 | `ΣTk` 与总时长差 > 0.05s |
| 3 | 单段时长 | 存在 `Tk ≤ 0` |
| 4 | 序号连续 | 出现跳号（1,2,4）或重号 |
| 5 | 行数 | 总行数 ≠ 3 + M（有附加行/说明行/markdown） |
| 6 | 槽位写法 | 出现 `@图片1的`（缺空格）、`@图片１２`（全角数字）、或 `@场景`/`@姓名` 指代参考图 |
| 7 | 场景首图错绑 | `@图片1` 为场景，却把人物外貌写进 `@图片1` |
| 8 | 分格禁令 | 有场景拼图参考时，正文没写"单镜头连续画面/无分格" |
| 9 | 邻镜缺失 | 首镜缺 `(first shot)` 或末镜缺 `(last shot)` 标注 |
| 10 | 无图编造 | 无参考图却出现具体 `@图片N` 指向某人物/场景 |

**用法**：脚本报红就改，别拿"读着挺顺"当通过。十条全绿 + 原 20 条 ≥80 分，才允许提交生成。

## 9. 自检

- [ ] 走的是全能模式还是经典模式？契约对上了吗？
- [ ] M 是按对白密度/机位/段落边界定的，不是照抄 `总时长/5`？
- [ ] `ΣTk == 总时长`，序号连续，行数 = 3 + M？
- [ ] 第 3 行锚点句整句照抄，一个字没改？
- [ ] 槽位全用 `@图片N` 且带半角空格，没有 `@姓名` 指代？
- [ ] 邻镜上下文（含首末镜标注）都注入了？
- [ ] 参考图缺失时，是否按 §7 停下来补图，而不是硬跑？
