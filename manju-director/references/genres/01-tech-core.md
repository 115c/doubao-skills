# 漫剧提示词技术要求总纲

> 这一份是所有题材共用的底层规格。题材文件（02–08）只写「这一族额外要什么」，通用结构、硬参数、失败修法全部以本文件为准，不重复在题材文件里写第二遍。

**来源**：`LearnPrompt/awesome-seedance`（2613★，1070 条带完整 prompt 的实测案例、27 套分类模板、80+ 可安装 AI-video Skill，数据同步自 goodcase.ai），以及本技能内 `djzs/references/提示词.md`、`fuyao/references/06-seedance2-adapter.md`、`cinematic/banks/*`。凡两处口径冲突，按 §8 裁决。

---

## 1. 一条提示词的五块结构

顺序不能换。换顺序会让模型把约束当描述读，权重全错。

| 块 | 装什么 | 硬要求 |
|---|---|---|
| **① 全局块** | 时长、画幅、帧率、片种（cinematic dark fantasy / 2D anime / live-action thriller）、整体画质词 | 三行以内。片种必须点名，只写 style 会得到四不像 |
| **② 固定块** | 全片不变：人物（脸/发/身高/体型/服装逐件）、道具、地点、主色、光源 | **写一次**，末尾加一句「全片不变」。禁止在每一段里重写服装发型 |
| **③ 时间轴块** | 一段一拍，段头写时间码 + 机位英文原词，段内写画面/动作/细节/音效 | 段长 2–5 秒；闭区间首尾相接；总和 = ①声明的时长 |
| **④ 全局约束块** | 负向清单、硬性禁止、物理规则、越轴禁令、最后一帧停在哪 | 单独成块放**最后**。塞进某一段里只作用于那一段 |
| **⑤ 技术收尾串** | 调色方向、雾/颗粒/镜头质感、渲染风格关键词 | 一串逗号短语收尾，不写整句 |

**为什么①必须写片种**：模型在它知道的一切风格之间取平均。`anime style` 给你一张通用 3D 脸；`90s cel-shaded Japanese animation, thin colored line art, 2–3 band cel shading` 才给你赛璐珞。

## 2. 时间轴：怎么切、怎么接

- **段长**：纪实跟拍 2 秒一段，广告 3 秒一段，有音轨驱动可到亚秒级锚点。**漫剧按 3–5 秒一段**（对白戏 3 秒，动作戏 2–3 秒）。
- **闭区间首尾相接**：`0-4s` 接 `4-8s` 接 `8-15s`。写「15 秒」却只列到 12 秒，模型会把最后一段拉长填满，动作全变形。
- **一段一个主要动作**。两个动作挤一段 → 时间被平均分 → 两个都做一半。
- **段间显式交接**：每段末写一行「结束时 → 状态 X」，下一段开头写「承接：同一批人、同一套服装、不切镜」。
- **机位术语用英文原词**放在段头括号里（`Ground-level Low Angle`、`Dynamic Tracking`、`Handlebar POV`、`Slow Dolly In`、`Dutch Angle`、`Top-down Overhead`），正文用中文。混写比全译稳。
- **纯文生视频的时间分辨率约 0.5 秒**。写到 0.01 秒只是噪音，除非你有配好的音轨或参考视频在驱动。

## 3. 身份锁：跨镜头不换脸的唯一做法

漫剧最大返工项。一次没锁住，整集重跑。

1. **Token 声明**：给每张参考图一个固定名，全篇原样复用 —— `@图1`、`@角色A`、`@场景1`、`@道具刀`。
2. **继承清单逐条枚举**，禁写「保持一致」：身份、五官、脸型、肤色、年龄感、发型、发色、身高、体型、身材比例、上衣、下装、鞋、饰品、整体气质。参考案例里生效的写法列了 13 项。
3. **不继承清单**（最容易漏、漏了必崩）：参考图的背景、房间、家具、文字、分割布局、原始姿势、画角、原图光线 —— 全部声明「不在成片里出现」。
4. **跨镜头声明**：转头、低头、遮挡、快速运动、手靠近脸时保持同一张脸；同一张脸不许在角色之间互换。
5. **负向**：禁止克隆、分身、五官平均化、双胞胎化。
6. **草图/插画当参考**必补：`use only as design blueprint, render as fully rendered 2D animation`（或对应画风的渲染指令），否则线稿感留在成片。
7. **别塞没 token 指名的参考图**。每多一张，属性串味概率翻一倍。

## 4. 画风锁：可测量 + 排除清单

**只写画风名 = 抽卡。** 画风要写成能量测的规格：

| 维度 | 写法 |
|---|---|
| 线条 | 粗细（thin 1–2px / bold 4px）、是否有色（colored line art）、断线程度 |
| 阴影 | 赛璐珞段数（2 段 / 3 段）、是否有透明感中间影、硬边还是软边 |
| 高光 | 瞳孔层数、头发高光层数、是否锐利 |
| 材质 | 布/革/金属/宝石/湿地面/玻璃**各自**不同的反射与粗糙度 —— 一句「有质感」等于没写 |
| 背景 | 比角色暗一档；用角色固有色当主光和影色（这是读成 2D 而不是渲染 3D 的关键） |
| 色彩 | 主色 / 辅助色 / 点缀色 / 材质母题，每个角色抽一组并命名，禁止互相交换 |

**排除清单是必需项，不是可选项。** 没有排除清单，2D 会塌成通用 3D，3D 会塌成半写实。列举该排掉的**相邻画风**：粗黑轮廓、单层平涂、廉价 TV 动画感、通用 3D 美少女脸、塑料 CG 感、半写实、写实照片感、低密度背景、浑浊色彩。

**快动作会让赛璐珞退化**：高速段里必须重申一次上色规格。

具体六种画风的参数级写法见 `09-style-locks.md`。

## 5. 动作与打斗

写 `epic fight` 只会得到两个人互相挥空。要成立靠四件事：

1. **流派 + 生物力学**：`authentic Taekwondo biomechanics`、真实解剖、重量、重力、动量、肌肉发力意图。
2. **连招链**：直拳 → 勾拳 → 低扫 → 对方格挡滑步下潜 → 封挡 → 反击体踢，逐拍写，不许概括。
3. **接触点**：每一击写在哪个部位接触、谁被推到哪里、什么被打飞。不写接触点 = 两人在彼此附近挥。
4. **不越轴**：左右关系固定，明确写「不许越轴、不许翻转轴线」。

**禁布娃娃**：`NEVER ragdoll / NEVER limp / NEVER floppy`，核心始终发力，倒地也要有肌肉意图。
**禁待机**：不摆架子、不重置、不瞬移、不跳位、不间歇。
**武器锁**：全场共几把、手只握在哪一段（如「鍔之后的柄上」）、刀身/鍔/柄/鞘在每个 CUT 都保持一体。
**血腥尺度必须声明**：不声明会被安全过滤削软。要打就写替代物（黑色数字粒子、故障碎片、尘爆），并加 `No blood`。

**切太碎会读不出来**：7–10 秒的打斗控制在 3–4 段以内。

漫剧打斗的题材级差异见 `02-fantasy-wuxia.md` §5、`03-urban-revenge.md` §5。

## 6. 大场面与奇观

- **一个实体一个定义块**：人物 / 怪兽 / 载具 / 城市场景各写一段，每段末尾标清它只提供什么 —— `Appearance only`、`Environment only`、`Vehicle only`。
- **尺度靠参照物和机位买**，不靠形容词。`sell the size with low angles and the city for scale`，低机位 + 楼 + 人群做参照。只写 `massive` 出来的怪兽和人一样高。
- **一条片只给一个奇观**，其余镜头全是走位铺垫。15 秒塞 5 个奇观，每个都是半成品。
- **镜头路径写成可执行动作**：每次换场点名穿过什么（`pushes directly toward the center of the ripple` → 穿进瞳孔 → 穿过水晶内部结构）。
- **最后一帧必须声明停在哪**：`Final frame on X, stable and clean`，否则收尾抖或糊。

## 7. 对白、口型、情绪

- **语种单独成行**写在所有台词之前：`台词语言：中文（普通话）` / `Natural Mandarin dialogue only`。台词包进引号或花括号，避免被当场景描述读。
- **说话人标签**：每个角色一个（`男：`/`女：`/`反派：`），不写标签会平均分配口型预算。
- **一拍只有一个人说话**。两个同时开口 = 口型预算对半分，两个都糊。另一个只给身体反应。
- **反应写成因果链，不写表情清单**：先听见 → 短暂停顿理解 → 表情开始变化 → 身体跟上 → 前一个表情留余韵 → 进入下一个状态。逐条列眉/眼/鼻/嘴会得到表情包式切换。
- **生理表征写成行为，不写症状**：要「脸红」会得到均匀粉色滤镜；改成「视线短暂移开、嘴角压不住、语速变慢、手停一下」，害羞才立得住。
- **每一拍以一行结束状态收尾**，给下一拍明确起点。
- **台词长度**：3 秒的拍子超过 8 个词就失步。先砍台词，再调别的。
- **专有名词和数字是最不可靠的部分**：品牌名、金额、日期从对白里挪出去，改成后期上屏字。
- **连续对白片**必须明写 `no silent moments and no voice-over`，否则模型给你配乐 + 一张动的嘴。
- 有音轨时：口型依据音频里的**真实人声**，无人声段落闭唇，背景人物不许跟着张嘴。

## 8. 参数口径裁决（仓库 vs 本画布）

| 项 | 仓库（awesome-seedance） | 本画布实测 | 采谁 |
|---|---|---|---|
| 视频模型 | Seedance 2.5 / 2.0（网页版） | `toonflow / Seedance 2.5` | 画布实测；两者都是 2.5，提示词语法通用 |
| 单条时长 | 案例覆盖 15s / 30s / 60s / 80s | 节点 15s | **画布 15s**。要 30 秒以上必须拆成多条 15s 再拼（见 `01-tech-core` §2 分段法） |
| 分辨率 | 案例多为 1080p / 4K | 720p | 画布 720p。画质词仍可写，但不要指望 4K 细节锚点能在 720p 成立 |
| 画幅 | 16:9 / 9:16 都有 | 16:9 默认 | 按平台交付要求定；竖屏短剧写 9:16 |
| 参数写法 | 参数不进正文 | 同 | 一致：时长/画幅/分辨率不写进提示词正文 |

**执行顺序**：先 `node:getConfig` 读真实配置 → 再按 §1 写提示词 → 交稿前跑 `prompt_lint.py`。

## 9. 通用负向清单（按需取，别全堆）

**画质类**：`low resolution, blurry, jpeg artifacts, oversharpened halos, watermark, subtitle burn-in, timestamp, UI overlay`
**人体类**：`extra fingers, fused hands, twisted limbs, distorted face, melted features, duplicated head, two bodies merged`
**运动类**：`floating, hovering, teleporting, sliding without friction, ragdoll flailing, idle posing, animation reset, motion blur smearing`
**镜头类**：`axis jump, 180-degree flip, unexplained camera teleport, whip-pan smear, random zoom`
**文字类**：`readable text, signage, logo, subtitle, garbled characters on background props`
**画风类**：按 §4 的排除清单逐项写（这一项每族不同，见各题材文件）

> 中文场景最常漏的一条：**画面里出现的任何书写载体（匾额、账本、招帖、药方、报纸、手机屏）模型必写错字**。要么禁载体，要么拍背面/剪影/手部特写。

## 10. 交稿自检（8 条，全过才交）

1. 片种、时长、画幅写在最前？
2. 固定块写了几次？回答必须是**一次**。
3. 时间码闭区间首尾相接、总和 = 声明时长？
4. 每段只有一个主要动作？段末有结束状态？
5. 参考图都有 token，且继承清单 + 不继承清单都写了？
6. 画风是可测量参数 + 排除清单，不是画风名？
7. 负向清单单独成块在最末？
8. `prompt_lint.py` ≥80 分（视频 `--duration N`；图片 `--kind image`）？

脚本位置：`references/djzs/tools/prompt_lint.py`。
