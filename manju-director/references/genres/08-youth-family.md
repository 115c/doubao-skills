# 青春校园 · 萌宝亲子 · 家庭日常

> 这一族卖的是**具体**。观众信不信，取决于你能不能给出一个只有那个年纪/那个家里才有的细节：风扇转头的频率、校服第二颗扣、冰箱门上贴的东西、奶奶的搪瓷缸。写「很青春」「很温馨」等于零。

---

## 1. 子类型与画法差异

| 子类型 | 戏核 | 那个只有它有细节 | 镜头主力 | 画风 |
|---|---|---|---|---|
| **校园/初恋** | 那一年最大的事，现在很小 | 走廊逆光、蝉、风扇、汗、制服第二颗扣 | 中景跟拍 + 手部 | 2D 赛璐璐 |
| **热血竞技** | 不服 | 球、拍、跑道的白线、护腕 | 低机位 + 冲击帧 | 2D 动作 |
| **社团/高考** | 一群人一起干一件傻事 | 黑板角落、便利贴、夜自习的灯 | 群像 + 空镜 | 2D |
| **萌宝** | 世界是按他身高设计的 | 只到他胸口的门把手、踮脚、够不到 | 低机位（他的眼睛高度） | 3D 卡通 |
| **亲子/祖孙** | 有一件事只有他们俩懂 | 搪瓷缸、老花镜、糖罐 | 双人半身 + 手 | 3D 卡通 / 2D |
| **婆媳/家庭矛盾** | 谁在忍谁 | 一碗汤、一双拖鞋、电视遥控器 | 门框内景 + 反打 | 2.5D |
| **乡村/年代** | 日子过得下去靠一件小事 | 灶、井、晒场、自行车 | 大景 + 生活微距 | 2D / 厚涂 |
| **职场日常** | 打工人 | 工位、微波炉、下班电梯 | 固定机位 + 微距 | 2.5D |
| **治愈/日常** | 什么都不发生 | 一双手、一口锅、一只猫 | 全片只拍局部 | 2D 手绘 |

## 2. 视觉规格

### 2.1 身高决定机位（萌宝与儿童向的硬规则）

- 儿童主角：**机位在他的眼睛高度**（约 90–110cm），所以门把手、桌沿、大人的腿会占据画面。
- 大人入画时只给**腰部以下**或**手**，不给全脸（这是「孩子的世界」的视觉证据）。
- 抱着拍的镜头从**上方**看，孩子仰头——这是亲密视角。

### 2.2 校园的物理（每片挑 2–3 个）

走廊逆光（`long corridor backlit, dust in the beam`）、蝉声与热浪（`heat shimmer above the track`）、风扇转头（`ceiling fan rotating, shadow sweeping the wall`）、汗（`sweat on the nape, shirt sticking to the back`）、粉笔灰、雨天的伞群、书包带压出的肩痕。

**挑两三个写死，别全写。** 全写就成 MV。

### 2.3 家庭场景的具体物（每片至少三件）

冰箱门上贴的东西（无字）、搪瓷缸的磕痕、拖鞋的位置、电视遥控器压在报纸上（**报纸不写字**）、厨房抽油烟机的油渍、阳台晾的衣服、一双穿旧的鞋。这些是「有人住在这儿」的证据，比暖光有用。

### 2.4 光色

- 校园 → 高饱和，夏日白 + 青，阴影偏蓝（不要暖黄，暖黄会让它变成回忆）
- 回忆/毕业 → 过曝 + 颗粒 + 柔边
- 家庭暖 → 低色温，实用光源（顶灯/台灯/灶火），不要打「电影光」
- 年代/乡村 → 低饱和，土黄 + 靛蓝 + 一点朱红

## 3. 镜头语法

1. **中景跟拍**（`Medium Tracking, follow from behind`）—— 走廊、跑道、回家的路。
2. **手部特写**（`Close-up on hands`）—— 递东西、攥衣角、握笔。这一族最贵的镜头仍是手。
3. **低机位儿童视角**（萌宝专用）
4. **门框/窗框内景**（家庭戏的偷看与被看）
5. **生活微距**（水开、饭熟、猫伸爪、拖鞋被踢歪）
6. **空镜收尾**（放学后的空走廊、收好的碗）

## 4. 提示词骨架（15 秒 / 4 段，放学走廊）

```text
15 秒，16:9，24fps，2D 赛璐璐校园动画，夏日高饱和，阴影偏蓝，走廊逆光。

【固定块】A：男，十七岁，黑色短发略长压眉，白短袖校服衬衫（第二颗扣没系，领口松），藏青校服裤，白球鞋鞋头有灰，右肩背包带压出一道痕。全片不换装。
B：女，十七岁，黑色长直发扎低马尾，同款校服，袖口挽到小臂，抱三本书在胸前。
场景：教学楼长走廊，右侧一排窗，日光斜穿形成光柱，地面有尘。全片同一地点、同一光向。

[0-3s] 中景，背后侧跟（Medium Tracking, side follow from behind）：A 从走廊一端走来，光柱一次次扫过他的肩。书包带压痕清楚。音效：蝉、风扇、远处球场拍球。
结束时：他停住，脚下是光柱边缘。

[3-7s] 中景，过肩（Over-the-shoulder, medium）：B 迎面走来，低头看书，走到他旁边时错身。她的袖口挽到小臂，手上抱着书，指节压在书脊。
结束时：两人错身而过，她没抬头。

[7-11s] 特写，浅景深（Close-up, shallow DOF）：他右手抬起，手指碰到自己第二颗扣的位置，又放下。喉结动了一下。背景走廊被虚化成一片亮。
结束时：手垂回身侧。

[11-15s] 固定机位中景（Static, medium）：他已经转身继续走，走廊尽头是空的。风扇影子从墙上一格格扫过。
结束时：最后一帧停在空走廊与风扇影上，稳定清晰。

【全局约束】不许出现可读文字、黑板字、书封字、校名牌、海报。不许两人脸互相串。不许越轴。不许出现第三个人。不许写实照片质感。不许暖黄怀旧色调。不许旁白。

【技术收尾】long corridor backlight with dust, lamp shadow sweeping, high-saturation summer grade with blue shadows, 2D cel-shaded rendering, light film grain.
```

## 5. 萌宝/亲子的写法差异

| 项 | 萌宝（3D 卡通） | 亲子/祖孙（2D 或 3D） |
|---|---|---|
| 机位 | 儿童眼高，成人只给腰以下 | 双人半身，同高 |
| 动作 | 踮脚、够不到、摔倒不哭 | 递、扶、擦手 |
| 表情 | 靠**整个身体**表达（肩膀、脚） | 靠**手**表达 |
| 光 | 高调柔光，几乎无硬阴影 | 实用暖光，允许暗部 |
| 收尾 | 一个「他终于够到了」的动作 | 一件旧物被放回原位 |
| 禁止 | 大眼睛卖萌特写、塑料反光 | 煽情音乐式慢推 |

**萌宝的常见崩法**：把小孩画成缩小的大人（比例错）、把小孩画成大头娃娃（头身比失真）。必须写：`toddler proportions, head-to-body ratio about 1:4, short limbs, rounded belly, chubby hands with dimpled knuckles`。

---

## 6. 常见崩法与修法

| 现象 | 根因 | 修法 |
|---|---|---|
| 「很温馨」但毫无记忆点 | 没有具体物 | 每片至少三件生活具体物（§2.3） |
| 像广告片 | 光太干净 | 用实用光源，加污渍与旧痕 |
| 校园像影楼 | 全是暖黄逆光 | 夏日用高饱和 + 蓝阴影 |
| 小孩像缩小的大人 | 比例没写 | 写头身比、短肢、圆腹、胖手（§5） |
| 黑板/书本出现乱码 | 书写载体 | 禁可读文字；黑板拍擦痕、书本拍书脊/背面 |
| 情绪靠配乐，画面空 | 没有行为证据 | 情绪写成动作（攥衣角、擦手、够不到） |
| 人物换镜变脸 | 固定块缺失 | 固定块写一次 + 不继承清单 |
