# 外部技法库：续写 / 编辑 / 转场 / 动态漫

> 这一份补的是前 9 个文件**没覆盖**的能力：把已生成的片子接着写、改其中一个元素、把两段接成一段、把静态分格画动起来。
> 素材来源：`liyue-aigc/seedance-2-5-video-director`（814★，Seedance **2.5** 官方口径 blueprints）、`beshuaxian/higgsfield-seedance2-jineng`（1063★，15 个题材 skill，2.0 口径）、`LearnPrompt/awesome-seedance`。**下面是重写过的操作规范，不是原文照搬**——原仓库多为 2.0 口径且部分机器翻译，句子不通的地方我已按实测逻辑改写。版本差异见 §9。

## 1. 视频续写：前接还是后接，先问清

**这是最容易搞错的一步。** 用户说「向前续写 / 往前延长 / 继续故事」时，语义是歧义的：

| 用户说法 | 判断 | 依据 |
|---|---|---|
| 「补前情」「前传」「接在开头」「衔接首帧」 | **前接**（插在原片之前） | 新段要**结束于**原片首帧 |
| 「接着结尾」「然后」「后面发生什么」「继续」 | **后接**（追加在原片之后） | 新段要**开始于**原片末帧 |
| 只说「向前续写 / 向后续写 / 延长一下」 | **歧义，不许猜** | 必须先问：新增片段放在原片之前，还是原片之后 |

**标准开头句（可直接抄）**：

```text
参考 @Video 1 的原始内容，在原片之后追加 5 秒。原视频区间保持不变，以下提示仅作用于新增区间。
```

**前接要写死的四件**：
1. 原片首帧的目的状态（人脸朝向、手在哪、光从哪来）；
2. 新增区间里的动作或场景；
3. 收束动作：从新增区间自然落到原片开头，允许一次指定转场；
4. 新增区间**最后一帧必须等于**原片首帧 —— 这一条不写，接缝必跳。

**后接要写死的四件**：
1. 从原片末帧继承的起点状态（位置、姿态、手持物、光线方向、镜头朝向）；
2. 新增区间的新动作，按时间顺序；
3. 从原片结尾自然延伸出来（不是重新起一个场）；
4. 新增区间的**最终状态**（要停在哪儿）。

**衔接锁 6 项（前后接都要写）**：机位与焦段、运动方向与速度、光源方向与色温、空间朝向（左右关系不翻）、道具手持状态、声音底噪与音轨延续。

**禁止**：无理由黑帧、硬切、道具突然出现或消失、人物身份或服装变化、光线跳变、音轨断裂、镜头无理由重置。

## 2. 视频编辑：只改一个元素，其余全部锁死

用户要「把蓝裤子改成黑西装裤」「把手里那杯咖啡去掉」「把背景换掉」时用。

**核心句式 = 精确目标 + 改什么（增/删/换）+ 生效时间 + 保护清单**：

```text
在 0-8 秒内，将画面中央人物的蓝色牛仔裤替换为深黑色西装裤；人物身份、上衣、动作、背景、机位和原声保持不变。
```

- **必须写成 A→B**（从什么变成什么），不能只写「改成黑裤子」。
- **删除类**要追一句：被删区域按原透视、原运动、原材质、原光照、原遮挡补齐；只写「去掉」会留下空洞或糊块。
- **带标记编辑**（框选/涂抹/箭头）要写：标记工具 + 标记内部改什么 + 标记外部不许动 + 方向。
- **保护清单永远写全**：身份、服装、动作、背景、机位、原声。少写一项，模型就顺手改那一项。

## 3. 把两段接成一段（无缝衔接）

**标准开头句**：

```text
无缝连接 @Video 1 与 @Video 2，但不要修改两段原视频的既有内容。
```

然后写五段：

1. **出场触发**：Video 1 最后那个动作或视觉信号是什么；
2. **过桥状态（必须全屏）**：遮挡物 / 匹配物 / 模糊 / 粒子 / 光 / 镜头穿过的表面 —— 任选一种，它必须**盖满整屏**，缝才看不见；
3. **入场动作**：从过桥状态怎么进入 Video 2 的第一动作；
4. **五类锁**：形状、屏幕位置、比例、方向与速度、颜色材质 + 声音过桥；
5. **禁止**：黑帧（除非刻意）、跳帧、硬切、闪烁、文字、logo、字幕、改动原片内容。

**过桥物选择**：雾/尘/水/烟/衣袖/门框/头发/光斑/镜头擦过墙面。别选细碎物（雨丝、发丝单独一根），盖不满就会出现半屏缝。

## 4. 转场词表（10 类，按用途选，不许乱加）

| 转场 | 什么时候用 | 必须写清什么 |
|---|---|---|
| 自然切 | 常规叙事 | 呼吸位、动作或视线是否对得上、不许突兀跳时 |
| 淡入 / 淡出 | 开场、收尾、时间流逝 | 黑还是白、持续多少秒 |
| 叠化 | 回忆、梦、抒情时间过渡 | 重叠时长、构图是否对位 |
| 白闪 / 黑闪 | 冲击、卡点 | 触发它的动作或声音、闪的确切时刻 |
| 划像 | 明确换地点、复古语法 | 划的方向、速度、遮住的边缘 |
| 遮挡 / 遮罩 | 空间穿越 | 遮挡物是什么、盖满的时刻、揭开方向 |
| 匹配物 | 蒙太奇 | 共用的形状/位置/比例/颜色/运动 |
| 甩镜 / 动作转场 | 动作、赶路、加速 | 甩的方向、力度、模糊量、入场方向 |
| 运动接力 | 换装、换地点 | 连贯的身体动作、落地姿态 |
| 推近 / 拉远 | 微距、嵌套世界 | 目标细节、满屏的时刻、揭出的目的地 |
| 墨扩散 | 东方诗意过渡 | 墨的触发物、扩散方向、揭示时机 |

**硬规则**：不准为了「看起来电影感」加转场。转场必须有叙事或物理动机，没有就不加，直接切。

## 5. 多格分镜图当输入：可以，但有红线

社区里有大量「multi-grid storyboard」写法（把一张多格图丢进去让模型按格出片）。**它的合法用法只有一种**：

- ✅ **作为输入素材**：声明「@Image 1 是完整的顺序分镜图，每一格是一个完整镜头，不是角色参考、不是场景参考」；然后**逐格**给：时长、构图、机位高度、主体动作、空间关系、转场或结束状态；最后收一句全局风格、物理规则、连续性、禁止项。
- ❌ **作为交付载体**：本技能硬规则 9 仍然有效——**分镜交付物只有子镜表**，不做宫格/漫画故事板。宫格图只是中间输入。
- ⚠️ 几何精度要求高的（机位、走位）用**线稿或火柴人**分格，不要让模型猜形状；外观、环境、运动、渲染细节必须在提示词里补齐，图里没有的东西它不会自己长出来。

## 6. 动态漫：把静态分格画动起来

用户给的是漫画页、条漫、插画故事板，要「让它动」。这一族的核心不是重画，是**在保留原画的前提下加运动**。

**三条推断规则（照做，别让模型自由发挥）**：

1. **姿势 → 运动弧**：每一格给「起始姿势 → 结束姿势」，中间的弧让模型补。只写「让他动起来」= 抖动。
2. **运动线方向 → 运动方向**：原画里速度线从左上到右下，就写「以左上至右下的对角线方向移动」；螺旋线写旋转；波浪线写柔软摇摆；直线写直冲。
3. **面板大小 → 屏幕时长**（供参考，不是硬标）：整页/大格 2–3 秒；常规格 1–2 秒；快切小格 0.5 秒。

**另外三件**：
- **拟声字/音效字**（POW、轰、唰）→ 转成**视觉冲击**：一帧白闪、去饱和、快速缩放、镜头抖动，**且不许把字画进画面**（书写载体禁令仍然有效；真画出来必是乱码）。
- **对白泡泡** → 转成配音或后期上屏字，按阅读顺序标说话人（左→右 / 右→左 / 竖排），一格只给一个人开口。
- **风格三句锁**：保留原线条与上色、新增运动不得改变基础画面、新增姿态必须服从原画解剖与透视。

**条漫转横屏**：竖向滚动变成横向推移（`vertical scroll becomes horizontal pan`），第一屏就是钩子，别把开场放在第二屏。

## 7. 装配顺序（2.5 官方建议，可与我们的五块结构互换）

原仓库给的语义顺序是 8 步，跟我们的五块结构是同一件事的两种切法，按需选：

| 2.5 装配顺序 | 对应本库五块结构 |
|---|---|
| ① 输出声明（模式/时长/比例/分辨率） | ① 全局块 |
| ② 资产声明（每张参考图管什么、不管什么） | 身份锁的继承/不继承清单 |
| ③ 一句话片意（主体+地点+事件+调性/风格+一个特殊镜头想法） | ③ 时间轴块的开头一句 |
| ④ 全局设定（环境、材质、风格、镜头家族、角色设计、表演核心） | ① + ② 固定块 |
| ⑤ 时间顺序的剧情或编辑操作 | ③ 时间轴块 |
| ⑥ 专项指令（表演/物理因果/现场覆盖/剪辑规则） | ③ 段落内部 |
| ⑦ 声音（对白、音效、环境、音色、音乐、字幕政策） | ③ 每段末的声音行 |
| ⑧ 全局连续性与禁止变更 | ④ 全局约束块 |

**一条原则**：只在需要时写时间码。单拍短片用散文比时间码更好；动作序列有歧义、或用户明确要卡点时，才上时间码。

## 8. 超过 15 秒怎么组织（本画布限制下的拼法）

本画布单节点 15 秒，成片靠多条拼接。长片（30–180 秒）**按幕/场组织，不按秒堆**：

- 开头写清总时长与比例。
- 每一场给五件：叙事功能（这场在干嘛）、大致或精确时间范围、地点、动作、机位策略、转场。
- **状态链必须显式**：位置、服装、手持物、时间天气、未解决的目标——每一项在跨场时写「延续」或「已改变」。
- 只在需要同步的拍点用精确时间码。
- 结尾收在一个**已解决的画面状态**，不要罗列事件。
- 30 秒级：`参考层 → 全局设定 → 时间轴分幕 → 全局收束`。每一幕写：时间范围 + 戏剧功能 + 可见动作/表情 + 机位构图 + 声音或对白 + 期望结束状态。
