## 2. 三步定位法（别跳过）

**第一步：定族**。问三句就够 —— 主角的对手是**人**还是**天**（玄幻）？矛盾在**钱和脸**上还是**命和秘密**上（都市 vs 悬疑）？结局是**翻身**、**在一起**、还是**活下来**（爽 / 情 / 惊）？

**第二步：定画风**。漫剧主流只有四种，选一种，不要混：
- **2D 赛璐璐日漫** —— 玄幻、武侠、校园、言情的主流。参数见 `09-style-locks.md` §1
- **国漫厚涂** —— 玄幻、古装、山海题材，比日漫厚重，色更沉
- **3D 卡通渲染** —— 萌宝、亲子、搞笑、部分都市爽剧
- **2.5D 半写实** —— 悬疑、末世、科幻，介于动画与实拍之间

**第三步：定时长节奏**。15 秒能装 4–5 个 3 秒拍 = 一个完整反转。竖屏短剧一集按 60–90 秒算，就是 4–6 条 15 秒单元拼。别在一条 15 秒里塞两集的信息量。

## 3. 每族「三件必须先定的事」

写提示词之前，这三件不定，后面全返工：

| 族 | 必须先定 ① | ② | ③ |
|---|---|---|---|
| 玄幻修真 | 修为阶段（决定特效量级） | 本片唯一奇观（只能一个） | 灵气视觉语法（粒子/光丝/符纹，选一种） |
| 武侠江湖 | 兵器谱（全场共几把） | 场地（竹林雪/客栈/雨夜破庙） | 打斗流派（写实武术 / 飘逸轻功 / 二者绑定比例） |
| 都市爽剧 | 阶层对比的两个空间 | 主角「被看轻」的具体物件 | 翻盘那一拍的触发动作 |
| 情感言情 | 两人之间那件没说出口的事 | 定情道具 | 情绪转折绑的那次光线变化 |
| 悬疑惊悚 | 那条「不该出现」的规律 | 单一光源位置 | 最后一帧停在什么上（必须不了结） |
| 古装历史 | 品级/位份（决定服饰） | 权力空间（宫道/堂审/内室） | 谁在说谎 |
| 科幻末世 | 世界已毁到什么程度 | 参照物（用来量巨构尺度） | 资源稀缺的那一件东西 |
| 青春校园 | 那一年 | 那间教室/走廊 | 一个夏天专属的物理（蝉、风扇、汗、逆光） |
| 家庭生活 | 家里那一件旧物 | 谁在忍谁 | 收尾那一顿饭/一次对视 |
| 搞笑 | 笑点落在哪个看得见的东西上 | 荒诞设定 | 一本正经的相机规格 |
| 纯动作/MV | BPM | 队伍/主角的外观锚点 | 节拍锚点表 |

## 4. 跨族混搭的边界

漫剧常见的混搭，能混的和不能混的说清楚：

| 组合 | 能不能混 | 怎么做 |
|---|---|---|
| 玄幻 + 言情（仙侠虐恋） | 能 | 特效量级砍到 30%，靠特写和光做情绪；大场面只留结尾一个 |
| 都市 + 玄幻（都市异能） | 能，但要早定 | 现代空间里只允许**一种**超自然语法，前 3 秒必须出现，否则观众当都市剧看，后面崩设定 |
| 悬疑 + 古装（古装探案） | 能 | 光源改成烛/月/灯笼，禁现代电光 |
| 校园 + 玄幻（校园异能） | 能 | 校园制服必须全程不换，异能只在手部与眼周出现 |
| 2D 画风 + 3D 画风 | **不能** | 两套词表混写 = 半写实，是失败态。选一套，另一套的词进排除清单 |
| 萌宝 + 恐怖 | 不能 | 调性互斥，观众会跑 |
| 战神 + 甜宠 | 能 | 用「先打脸、后宠」的十秒结构，别在同一拍里同时做 |
