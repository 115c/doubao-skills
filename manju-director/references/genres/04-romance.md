# 情感言情 · 甜宠 · 霸总 · 虐恋 · 重生

> 这一族卖的不是剧情，是**两个人之间那件说不出口的事**。全片只做一件事：让观众看见「他其实想说什么，但没说」。所有镜头、光线、道具都为这件事服务。写成「他很爱她」就等于什么都没写。

---

## 1. 子类型与画法差异

| 子类型 | 戏核 | 那件没说出口的事 | 定情道具 | 收尾动作 |
|---|---|---|---|---|
| **甜宠** | 宠是习惯不是礼物 | 他早就记住她的所有小毛病 | 一杯温的、一双拖鞋 | 递过去，不说 |
| **霸总/契约** | 权力关系下的真心 | 他在签合同那刻改了一个字 | 合同/钢笔 | 把合同推过去，翻到改的那行 |
| **虐恋/追妻** | 错过是结构性的 | 他当年其实在场 | 旧照片/票根/一条疤 | 她转身，他伸手没碰到 |
| **追妻火葬场** | 悔要付出可见代价 | 他毁掉自己最贵的东西 | 车钥匙/公司印章 | 扔掉/烧掉 |
| **闪婚/先婚后爱** | 陌生人被迫共处 | 两个人的作息悄悄对齐了 | 一双牙刷/一把伞 | 两把伞只带了一把 |
| **白月光/校园回忆** | 记忆比现实亮 | 她不是他想的那个版本 | 校服第二颗扣/一封信 | 画面转白，只剩一件物 |
| **重生/复仇言情** | 这一次不重复 | 她记得上一世他怎么死的 | 伤口位置/一句话 | 她先动手 |

## 2. 视觉规格

### 2.1 距离与遮挡是唯一的情感语法

言情不靠表情，靠**物理距离**与**遮挡关系**：

| 关系状态 | 画面写法 |
|---|---|
| 疏远 | 两人之间必有一物（桌角、门框、雨幕、玻璃） | 
| 靠近 | 前景遮挡（窗帘、枝叶、人的肩膀）只露半张脸 |
| 心动 | 同一帧内，一人在焦内一人在焦外 |
| 决裂 | 背影 + 空出画面一半 |
| 复合 | 两人第一次出现在**同一个焦平面**上 |

### 2.2 光

- 甜宠 → 柔光，高光溢出，暖白 + 奶油色，几乎无硬阴影
- 虐恋 → 冷蓝 + 一道暖（暖永远只在一个人身上）
- 回忆 → 过曝 + 颗粒 + 边缘柔化（`bloom, halation, soft vignette`）
- **情绪转折必须绑一次光线变化**：`golden hour → blue hour`、外景冷蓝切内景暖黄。这是观众感知「变了」的最快通道。

### 2.3 雨、雪、风、水

言情四大件，用来替人做表情：雨打伞面的角度、雪落在睫毛上停一秒、风吹起发尾、水汽糊住镜子。**每一条 15 秒最多用两件**，全上会变成 MV。

### 2.4 服化

必须写：发（长度/分缝/是否有碎发在耳边）、上衣（版型 + 面料 + 领口深浅）、下装、鞋、耳饰/腕饰。**领口、耳饰、腕饰三样是特写镜头的锚点**，一次定死。

## 3. 镜头语法

1. **半身特写 + 浅景深**（`Close-up, 85mm equivalent, shallow DOF`）—— 这一族 70% 的镜头是这个。
2. **双手同框**（`Two-shot on hands only`）—— 递东西、碰到、缩回。言情最贵的镜头是手，不是脸。
3. **耳后/颈侧**（`Over-shoulder, tight on nape`）—— 靠近时的正确机位，比正脸有效十倍。
4. **视线反打** —— 她看他的方向，再切他看到的东西。
5. **空镜过渡** —— 雨滴、水杯、半开的门。用来装「没说出口」的那 2 秒。

## 4. 提示词骨架（15 秒 / 4 段，雨夜重逢）

```text
15 秒，16:9，24fps，2D 赛璐璐言情动画，冷蓝主调，暖色只出现在女主身上。

【固定块】女主：二十四岁，黑色长直发至腰，齐刘海，米白针织开衫（袖口起绒），深灰长裙，棕色短靴，左耳一颗小珍珠。全片不换装、不换发型。
男主：二十八岁，黑色短发向后梳，湿透的深灰大衣（肩线塌），白衬衫领口松一粒扣，右手无名指内侧一道旧疤。
场景：雨夜街角咖啡馆门口，唯一光源是店内暖黄灯从玻璃后透出。全片同一地点、同一光源。

[0-3s] 中景，逆光剪影（Backlit, medium wide）：她背对镜头站在门口，伞面被雨打出声音，玻璃后的暖光把她的轮廓切出来。音效：雨、店内模糊人声。
结束时：伞沿滴水，她没有动。

[3-7s] 特写，浅景深（Close-up, 85mm, shallow DOF）：门被推开，暖光扫过她的侧脸，睫毛上有水。她抬眼，视线停在画面右外侧。
结束时：她的嘴角还没动，眼神先变了。

[7-11s] 过肩双人，手部同框（Over-shoulder, hands in frame）：她的手指在伞柄上收紧，指节发白；他的手从画面右侧伸入，停在离她手背两厘米处，没有碰。雨声盖过一切。
结束时：他的手停在那里，没有收回。

[11-15s] 特写，跟摇（Close-up, slow follow）：镜头跟着她垂下的视线，落到他大衣口袋露出的一角旧票根。她的手终于松开伞柄。
结束时：最后一帧停在那张露出一角的票根上，稳定清晰。

【全局约束】不许出现可读文字、票根字样、招牌、字幕。不许两人同框时脸互相串。不许越轴。不许写实照片质感。不许出现第三个人。全片不得有旁白与静默空档，雨声与呼吸必须连续。

【技术收尾】soft bloom, halation on warm practicals, light film grain, cool blue grade with one warm source, 2D cel-shaded rendering, shallow depth of field.
```

## 5. 情绪怎么写成因果链（不写成表情清单）

**错的**：`她先是惊讶，然后害羞，最后笑了`。
**对的**：

```
她听见 → 手上动作停住（0.5 秒）→ 视线短暂移开，落到地面 → 喉咙动了一下 → 嘴角压不住，先往上一点又被压下去 → 最后放弃，笑出来 → 同时低下头，发尾遮住半张脸
```

**生理表征一律写行为**：
- 脸红 → 视线移开 + 语速变慢 + 手停一下（不要写 `blush`，会得到粉色滤镜）
- 心跳 → 锁骨处的呼吸起伏变快 + 手按在胸口
- 想哭 → 吸气一次，鼻子红，眨眼变慢，视力不聚焦
- 生气 → 下颌收紧 + 呼吸从鼻子出 + 手指压在桌沿

**每一拍结尾写一行结束状态**，下一拍从那个状态起。

## 6. 台词纪律

- 一拍 ≤ 8 个词（3 秒内）。超了就失步。
- 一句狠话 / 一句软话，**全片各留一句**，其余全砍。
- 专有名词、金额、日期从对白挪出去，改成上屏字（模型念不对数字）。
- 两人同拍说话 = 口型预算对半，都糊。只一个人开口。
- 有音轨时明写：口型依据音频真实人声，无人声段闭唇，背景人物不张嘴。

---

## 7. 常见崩法与修法

| 现象 | 根因 | 修法 |
|---|---|---|
| 像 MV 不像剧 | 雨雪风全上 + 空镜过多 | 15 秒只用两件天气、最多一个空镜 |
| 两人关系看不出来 | 没有遮挡/距离设计 | 按 §2.1 的五行表选一个状态写死 |
| 情绪假 | 写了表情清单或生理症状 | 改因果链 + 行为化（§5） |
| 脸一换镜就变 | 固定块缺失 | 固定块写一次 + 「全片不换装」+ 不继承清单 |
| 画面出现乱码招牌 | 书写载体 | 禁可读文字，玻璃后的人声做成模糊音 |
| 结尾没有余味 | 收在正脸 | 收在一个物件上（票根/伞柄/两只手），不给结局 |
| 光线没变化，观众无感 | 缺转折 | 补一次色温跳变（暖→冷 或 反） |
