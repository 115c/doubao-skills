# 10 · 情绪与爽点：让读者真的感到，而不是被告知

> 情绪不是"写一个人的反应"，是**让读者的处境判断发生改变**。
> 最常犯的病：拿身体细节当情绪翻译器。

## 一、情绪四通道（并列，不排高低档）

写到情绪节点，先看**上下文是否已经成立**：前面已让读者看懂，就删掉补充反应，直接进下一句或下一件事。仍需落一拍时，从四条里只取**最准的一条**，不把"动作＋身体＋比喻＋心理解说"叠成四重注释。

| # | 通道 | 写法 | 例 |
|---|---|---|---|
| 1 | 直接点明情绪 | 高强度爆发与过场都可直写 | "他听烦了""她心里发寒""他彻底慌了" |
| 2 | 当下的判断、算账、吐槽 | 写权衡、盘算、起疑、误判 | "这会儿翻脸吃亏的是自己，先把字签了拿到账本再说" |
| 3 | 台词与行动选择 | 说了什么、咽下什么、撤回什么条件、改走哪条路、付了什么代价 | 愤怒使他当场撤回报价、叫停合作 |
| 4 | 改变局面的动作或物件后果 | 动作失败、疼痛失衡、场上物件真出了变化 | 笔尖划破签名、钥匙插错锁孔 |

**不需要为避开普通情绪词绕成三十字肢体表演。**"他慌了"三个字往往比"瞳孔骤缩、指尖发颤"更有力。

## 二、反动作代偿：硬判据

**判定线**：凡是不改变选择、关系或物理结果的手眼、姿态、道具微动作，一律判为动作代偿，删或改。

命中清单（两类都算）：

- 急促套话：指尖一颤、指节泛白、嘴唇抿紧、呼吸一滞、瞳孔一缩、喉咙发紧、后背发凉
- 慢速道具代偿：慢慢拢住药包、指腹摩挲杯沿、按住桌角、视线落在某处停半秒、手往袖里一缩

**处置**：删掉，或改写成角色此刻的判断、算账、直白情绪、台词。**禁止同义动作轮换**（把"攥拳"换成"指甲掐进掌心"仍然是代偿）。

### 删除测试

| 情况 | 处理 |
|---|---|
| 上下文已显出不耐烦 | 直接进下一句对话，或"他听烦了"带过 |
| 心思转向、权衡利弊 | 直接写他算清了哪笔账、怕什么后果 |
| 愤怒使谈判改变 | 写他撤回报价、叫停合作、当面追问 |
| 紧张妨碍正在做的事 | 可以写笔尖划坏签名、钥匙插错锁孔 |
| 手眼／道具只是在句尾标注情绪 | 删，或改成一句直白判断 |

> 例外：造成**伤势、动作失败、实际后果**的身体细节照写，因为那是事实，不是标签。

## 三、危险与威胁：不许空口断言

一样东西"危险""碰不得"不由旁白宣布。两种合法写法：

1. **有代价的试探**：伸手一探被震开，多看两眼便神思恍惚。
2. **行家的利害掂量**：一眼认出这门禁制去年折了两名执事，硬闯得搭上半条命。

## 四、数字作为叙事工具

| 用法 | 操作 | 例 |
|---|---|---|
| 建立重量 | 用具体金额／年限替代"很久""很多" | "成婚六年，他连我对花生过敏都记不住" |
| 伤害递增 | 数字随得寸进尺逐次放大 | 先垫两百 → 每月要一千 → 最后逼交五万奖学金 |
| 反差暴击 | 两笔悬殊数字并排算清 | "给弟弟买婚房眼都不眨八十万；我住院，他为两千块跟医生吵半小时" |
| 时间重量 | 用年限托出付出与薄情的落差 | "我在边关啃了十年干粮，回京那天父亲说我只配住下人房" |
| 折算切身用度 | 不停在账面，顺手折成正急用的开销 | "卖了一千二，够妹妹交两学期住宿费" |

**铁律**：张数、天数、重量前后必须算得拢且合乎常识。算不拢是硬伤。

## 五、贯穿道具：每次重现都要加信息

| 类型 | 例（含义如何变化） |
|---|---|
| 信物型 | 镀金长命锁：贴身戴十年深信妈疼自己 → 中段摔断露出黄铜，五十块假货 → 结尾连催款单一起退回断联 |
| 工具型 | 母亲记了二十年的家庭旧账本：日常记账 → 摊牌时成为断亲铁证 |
| 痕迹型 | 凶手左腕留着常年戴玉镯的浅白压痕 → 身份被认出 |
| 数字型 | 八万块抚养账单：从"抚养"变成"要还的债" |

记账格式：

```
物件：{名称}
| 章 | 当次含义 | 新增信息或意义变化 |
```

## 六、爽点公式（九个可复用模块）

| 模块 | 结构 | 用在 |
|---|---|---|
| 装逼 | 被打压嘲讽（可选）→ 展示能力 → 拉出落差 → 关键人物态度改变 | 期待感 |
| 打脸 | 被低估 → 现场验明 → 看低者改口 → 旁人分层反应 | 爽感释放 |
| 以小博大 | 低成本筹码进适配能力的场子 → 独门手段＋一点运气 → 高额回报 | 悬殊越大越爽 |
| 点石成金 | 旁人嫌弃的人／物 → 主角看出门道 → 改造 → 发挥高价值 | 慧眼型 |
| 慧眼识真 | 主角凭独有情报认出宝物／人才 → 众人嘲笑 → 当场验明 → 看低者改口 | 知识与身份双爽 |
| 歪打正着 | 先暗示关键 → 对手费尽心机争抢，主角做别的事顺手截胡 | 反讽型 |
| 少年热血 | 面对强敌／绝境 → 明知不敌仍为底线出手 → 拼出转机 | 燃 |
| 临危受命 | 危机超出在场能力 → 配角办法用尽 → 主角接手破局 | 立威 |
| 误会 | 立核心误会 → 顺信息差衍生小误会 → 定解开条件与阻碍 | 感情拉扯（伤根基的误会要及时解） |

**可叠用**：以小博大接英雄救美（双重兑现）；点石成金接装逼（先抑后扬）；临危受命里同时亮实力与救人。

**连用三次同型**时：保留目标情绪与分工，**换掉人物、场景、事件和破局手段**；情绪也腻了才换模块。

## 七、反转类型与规矩

| 类型 | 反转什么 | 必备 |
|---|---|---|
| 身份反转 | 谁是谁 | 前文给过至少两处可回溯的细节 |
| 认知反转 | 读者以为的因果被推翻 | 真相版本必须能解释前文所有事实 |
| 立场反转 | 阵营与敌我 | 立场变化的动机必须早埋 |
| 代价反转 | 赢了之后发现输了别的 | 战利品／败军之口带出隐情 |

**禁令**：机械降神（临时出现的新人／新能力解决问题）；只靠"隐藏实力"骗读者。

## 八、动静起伏（不给配额，给判断）

一章整体要有推进（冲突爆发、正面交锋、热火朝天的劳作）与停顿（信息悬置、对话空白、环境压力、必要的日常过程）的起伏，但**不给每个场景设数量指标**。

- 连续几个场景全"动"→ 复核是否暴力疲劳（有意连续的追逐／战斗可保留）。
- 全"静"→ 复核是否停滞（有意延长的等待／压迫可保留）。
- 情绪高低不对应固定动作类型：爆点可以突然安静，低谷也可以持续劳动。

## 九、衬托：谁说这件事重要

"厉害／难得／要命"由**懂行或有利害关系的人**当场点出，不由叙述者自夸。四种落法：

1. **内行估价**：老掌柜一眼认出刀口是失传锻法。
2. **强手失态**：稳坐钓鱼台的大人物不得不站起身或招架。
3. **打破常例**：考官失声"往年从没人撑过三息"。
4. **点明代价**：交代旁人平常要拿什么苦功或家底才换得到。

**难度必须在出手前或交锋当下立住**，并先给一把比高低的尺子（前一个天才拼尽全力留半寸印，主角随手一击三寸透孔）。
反面：懂行的人在场，却只让他"笑了笑，跟旁边说了句什么"，把最该点破分量的台词吞掉了。
