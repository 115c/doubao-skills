# 15 · 平台、发布与运营

> 同一本书，发错平台等于白写。这一层在六个对标仓库里几乎是空白，所以我们自己建。
> **时效声明**：平台规则、稿费、全勤、审核口径都会变。本模块给的是**结构与判断方法**，具体数字（单章字数下限、签约门槛、分成比例）必须按平台当期官方规则核实后才写进方案，不许照本文件的历史经验当承诺。

## 一、平台性格（决定节奏，不是决定好坏）

| 平台类型 | 读者行为 | 对写法的要求 |
|---|---|---|
| 免费流量型（广告分成） | 边刷边看，前 3 秒决定 | 章首即冲突，单章短（快节奏档），章章有爽点 |
| 付费订阅型 | 先看免费章再决定订阅 | 免费段要给足卖点，上架卡点前后必须放大高潮 |
| 女频向 | 关系与情绪优先 | 允许慢一点，但每章要有温度变化 |
| 短篇／故事型 | 一次性读完 | 单点爆破，结尾反转或余味（见 17） |
| 出版／实体 | 编辑与读者都要"文学性证据" | 语言与主题先行，结构可非类型化 |

## 二、字数与节奏（结构层，具体数值按平台规则校正）

| 项 | 快节奏档 | 均衡档 |
|---|---|---|
| 单章字数 | 2100-2300 | 约 3000 |
| 单章事件数 | 2-3 件，至少一次小反转 | 2-3 件，允许一段铺垫 |
| 卷体量 | 50-80 章 | 40-70 章 |
| 爆发章占比 | 25-30% | 15-20% |

**通用底线**：单章低于平台下限会被判"更新不足"，高于 4000 字在移动端会被划走。**宁短不拖。**

## 三、上架卡点倒推（付费平台的核心技术）

```
1. 定上架章号 N（按平台规则）
2. 在 N-2 到 N 之间排"本卷最大高潮的前半段"
3. 在 N+1 到 N+3 给兑现（读者付费后的第一口必须甜）
4. 从 N 往前倒推：反派登场、赌注建立、筹码积累分别落在哪几章
5. 卡点之前不许写与本卷主线无关的打脸
```

卡点写错的两种典型：高潮在上架前就打完了（读者没有付费理由）；高潮在上架后第 10 章才来（付费读者当场流失）。

## 四、书名、简介、标签（三件套）

### 书名（2-8 字为主，特殊题材可到 10 字）

五种打法，一批候选里每种只用一个：

| 打法 | 操作 | 例 |
|---|---|---|
| 核心冲突提炼 | 从最大矛盾里取两个词 | 《失踪者线索》 |
| 主角特征 | 取主角最独特的一面，不用全名 | 《深夜掌勺人》 |
| 意象隐喻 | 一个可被反复解读的象征 | 《雾中灯塔》 |
| 反差 | 两个矛盾元素并置 | 《她最后一次微笑》 |
| 悬念留白 | 指向具体事物但不解释 | 《第三封信》 |

**禁用**：XX之道／XX觉醒／XX纪元／XX崛起（AI 味模板）；"命运""选择""真相"这类无指向单词；直接剧透结局；"震惊""竟然"式标题党。

### 简介（三句话结构）

```
第 1 句：身份＋处境（谁，在哪，被什么卡住）
第 2 句：异常或代价（出什么事了，为什么不能不管）
第 3 句：承诺（读者会看到什么体验，不写结局）
```

**简介三不要**：不要罗列世界观名词；不要写"且看主角如何……"；不要把反转写出来。

### 标签

主类型＋子类型＋核心体验＋一个差异化词（如：都市／复仇／打脸／账本）。**标签是检索入口，不是自我评价**，不要写"热血""精彩"。

## 五、连载运营（数据不好时的诊断顺序）

| 症状 | 先查 | 再查 | 最后才动 |
|---|---|---|---|
| 点击低 | 书名／封面／标签 | 简介第一句 | 改正文 |
| 点进来但第 1 章走 | 前 300 字抓手 | 首章事件密度 | 改开头 |
| 前 10 章走 | 卖点是否露头 | 爽点密度 | 改结构 |
| 上架后走 | 卡点高潮与兑现 | 单章断点 | 改卷纲 |
| 老读者流失 | 钩子是否兑现 | 情绪母题是否扎堆 | 改章纲 |

**更新纪律**：固定时段更新（读者会形成习惯）；断更超过 3 天要提前说明；存稿至少 10 章再开更。

## 六、投稿与签约（不做承诺，只给动作）

1. **投稿材料**：书名＋简介＋标签＋前 3 章正文＋大纲（1 页）。
2. **投稿前自查**：前 3 章是否履行合同（见 14）；简介是否三句话；有没有抄袭嫌疑（见 21）。
3. **签约条款必看四项**：授权范围（独家／非独家）、改编权归属、结算方式、解约条件。看不懂就要求对方解释，不要凭"行业惯例"签。
4. **不许承诺收益**：任何"这样写能月入 X"的说法都是编的。能给的是结构判断与数据诊断。

## 七、发布前最后一遍

- [ ] 书名符合平台字数与检索习惯，无 AI 模板词
- [ ] 简介三句话齐全，第三句是承诺不是结局
- [ ] 标签 4 个以内，主类型在最前
- [ ] 前 3 章过 06 的自查表
- [ ] 单章字数在平台区间内
- [ ] 上架卡点已按第三节倒推
- [ ] 存稿 ≥10 章
- [ ] 敏感内容自查（暴力、未成年人、真实人物、医疗法律建议等，按平台规则处理）
