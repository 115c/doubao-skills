# 09 · 对白：权力博弈、潜台词、声音、信息嵌入

> 对白不是"让人物说话"，是**让人物用说话争夺东西**。
> 一句话没有目的，就删掉；有目的但读者看不出来，就改。

## 一、每句台词先问三个字：他要什么

| 目的 | 表现 |
|---|---|
| 要东西 | 请求、讨价、威胁、撒娇、试探 |
| 要面子 | 找台阶、抬杠、反讽、替自己开脱 |
| 要关系 | 示好、道歉、解释、试探对方在不在乎 |
| 要时间 | 拖、装傻、转移话题、说废话 |
| 要对方难受 | 冷嘲、翻旧账、点名痛处 |

**没有目的的台词＝说明书。**

## 二、权力博弈对话（对抗场必用）

三段式：**压制 → 反转 → 心死／松动**。

| 阶段 | 谁掌握话语权 | 写法 |
|---|---|---|
| 压制 | 对方 | 对方出价／定规矩／给羞辱，主角只有短句回应（短句＝处于下位） |
| 反转 | 主角 | 主角抛出一个对方不知道的事实或筹码，句子变长，开始定规矩 |
| 心死／松动 | 主角或对方 | 一方不再争辩，改用行动（走、签、摔东西、答应条件） |

三条操作要点：

1. **筹码要具体**：不是"我有证据"，是"三月十七那晚，你从后门带进来的人，我认得他的鞋"。
2. **反转前必须先给读者一个疑点**，否则反转是作弊。
3. **赢的一方不要话多**：话越多越像在解释，越像心虚。

## 三、潜台词：说 A 指 B

| 表层 | 潜台词 | 触发方式 |
|---|---|---|
| "你吃了吗" | 我想知道你过得好不好，但我不肯先低头 | 关系僵→暖 |
| "这房子我租了三年" | 我在这有根，你别赶我 | 权力不对等 |
| "你姐当年也这么说" | 你没资格 | 翻旧账 |
| "随你" | 我在等你挽留 | 情感拉扯 |

**规则**：潜台词只在水面下能听见，**不许人物自己点破**（"他这句话其实是在说……"＝把戏拆了）。读者听不懂怎么办？让第三方误解一次，读者就懂了。

## 四、人物声音四道区分（同 03 第五节，对话场必查）

句长｜词汇域｜称呼方式｜生气时的退化方式。
**测试**：抽 5 句遮住名字，猜是谁；错 2 句以上重写。

## 五、信息嵌入：别让角色互相科普

| 手法 | 例 |
|---|---|
| 外来者提问 | 新人对本地规矩一无所知，问一次，读者跟着懂 |
| 文件／公告 | 一张告示、一份契约、一条系统提示 |
| 旁人失口 | 有人急了说漏一句，信息＋关系双推进 |
| 争吵中带出 | 两个人争同一件事，各自说出自己那半截事实 |
| 后果演示 | 有人违规，代价当场发生，不用解释规则 |

**禁令**：两个本地人互相讲解本地常识；一个人对另一个人复述对方刚经历过的事。

## 六、对白刀口（删减清单）

| 症状 | 处置 |
|---|---|
| 打招呼、寒暄、客套 | 删，直接从正题开始 |
| 重复上一句的信息 | 删 |
| 人物把自己的动机说清楚 | 改成行动或让对方猜 |
| 连续三句以上同一句式 | 换句长 |
| 每句都是完整书面句 | 加口气词、停顿、半截话 |
| 所有冲突靠"你不懂""你听我解释" | 改成双方各有筹码 |
| 对白后紧跟一句解释性旁白 | 删旁白，让台词自己成立 |

## 七、对白段落的三条格式规则

1. **一人一段**：换人说话就换段。
2. **动作插在说话人前面**，不插在中间打断句子（除非被打断是真事件）。
3. **同一段里不超过两次"某某说"**，其余靠动作、称呼、语气承接。

## 八、快速体检

任选一章，抽 10 句台词：

- 有几句能删而读者无感？超过 3 句 → 对白注水。
- 有几句能分辨说话人？低于 7 句 → 声音没做。
- 有几场戏是"两人把话说清楚"就解决了冲突？有 → 冲突太软，改成"说清楚也没用"。
