# 01 · 选题与 Premise：值不值得写，写多长，靠什么跑

> 只在"只有一个点子/一句话简介"时用。已经有成稿或明确章纲，跳过本模块直接进 05。
> 这一层错了，后面每一章都在替它还债。规矩：**先判断值不值得写，再写正文；先给卖点、冲突、故事引擎，再给大设定。**

## 一、把一句话压成五件东西

用户给的简介无论多长，先压成这五件。压不出来就是不能开写。

| 产出 | 要求 | 不合格的样子 |
|---|---|---|
| 题材与子类型 | 一个主类型＋一个修饰（如"都市＋复仇""古言＋宅斗"） | "古风奇幻爱情成长"（四个都想要＝没有） |
| 卖点（消费点） | 读者为**什么体验**付费：爽、甜、虐、烧脑、怕、治愈、猎奇、知识 | "文笔好""有深度"（这是结果，不是卖点） |
| 一句话 hook | 一句能贴到封面上的话，含异常、矛盾或代价 | "一个少年的成长故事"（无异常） |
| Premise | 谁＋在什么处境下＋被迫做什么＋失败会怎样（四段齐全） | 缺"失败会怎样"＝没有赌注 |
| 故事引擎 | 能反复产出事件的**一台机器**：升级、解谜、关系拉扯、资源争夺、规则破解、身份庇护 | "靠剧情推进"（这不是引擎） |

### Premise 四段模板

```
【谁】一个（身份＋最痛的缺口）的人，
【处境】在（时间／地点／规矩）里，
【被迫】必须（具体行动），
【否则】（失去什么／变成什么）。
```

验收：把这四段念出来，如果听的人会问"然后呢"，合格；如果听的人说"哦，挺好的"，重写。

### 故事引擎的三个机检问题

1. **能不能列出 20 个互不重复的事件？** 列不到 20 个，只够写短篇或中篇。
2. **每个事件是否都由引擎自动生成，而不是靠作者硬想？** 例如"每次找到一个碎片，就解锁一段真相并被一方追杀"，这才是引擎。
3. **引擎跑到第 100 章会不会自己空转？** 会空转的（如"打脸所有看不起他的人"），要么换引擎，要么一开始就定长度上限。

## 二、红黄绿判定：这个点子现在能不能写

三项全绿才开写；两黄一绿先补再开；出现红就先停。

| 灯 | 检查项 | 绿灯标准 |
|---|---|---|
| 🟢／🟡／🔴 | 卖点是否唯一且可感知 | 三句话内能让目标读者说出"这个我想看" |
| 🟢／🟡／🔴 | 引擎是否能自转 | 20 个事件列得出来且不重复 |
| 🟢／🟡／🔴 | 主角是否有不可替代性 | 换个人来也能解决＝主角多余 |
| 🟡 | 平台是否有同类在跑 | 同类有成绩＝有市场；没有＝可能没市场，也可能没被发现 |
| 🔴 | 是否靠"设定很宏大"充数 | 只有世界观没有前 20 章事件＝不能开写 |

### 五个必答的合理性追问（情节抓不住人时回来查）

1. 为什么是他？（主角不可替代的理由）
2. 为什么是现在？（此前为什么没发生）
3. 此前为什么没解决？（否则故事早结束了）
4. 他凭什么能介入？（能力／身份／信息，至少一项）
5. 规矩允许吗？（世界规则给出了什么限制，他怎么绕）

五问有一问答不上，这个情节点就是"作者需要它发生"，读者会闻到。

## 三、篇幅决策

| 形态 | 体量 | 判定依据 | 结构侧重 |
|---|---|---|---|
| 微小说／一分钟小说 | 300-1500 字 | 只有**一个**转折或一个画面 | 单点爆破，无副线（见 17） |
| 短篇 | 3 千-2 万字 | 一个主导变化＋一个效果，两三个人物 | 单线，结尾反转或余味（见 17） |
| 中篇 | 2 万-8 万字 | 一条主线＋一条副线，可有一个大高潮 | 三幕或 Fichtean（见 04） |
| 长篇连载 | 30 万字以上 | 引擎能自转、能换地图、有 3-4 条线 | 卷结构＋期待链（见 05） |
| 系列／多季 | 多本 | 主线可延续、世界观可扩 | 系列连续性（见 12） |

**判定口诀**：事件数决定体量，不是字数决定体量。能列出 20 个事件＝长篇；8-12 个＝中篇；3-5 个＝短篇；1 个＝微小说。
反过来也成立：**说好写 30 万字但只有 8 个事件，就是在注水**。

## 四、从点子到开写的最小交付

本模块一次只交付这五项，不写正文、不建工程：

```
1. 题材／子类型：
2. 目标读者与消费点：
3. 一句话 hook（≤25 字）：
4. Premise（四段齐全）：
5. 故事引擎（一句话＋3 个示例事件）：
6. 规模建议：字数区间／形态／卷数
7. 红黄绿灯：___（未过灯的先写缺什么）
```

## 五、常见死法

| 死法 | 症状 | 处置 |
|---|---|---|
| 设定先行 | 能讲半小时世界观，讲不出一件具体事件 | 回到故事引擎三问 |
| 卖点模糊 | "什么都有" | 只保留读者最容易说出口的那一个 |
| 主角多余 | 换谁都能解决 | 给主角一项别人没有的东西（信息／身份／代价承受力） |
| 长度虚高 | 8 个事件写 30 万字 | 要么加引擎，要么改短篇 |
| 抄袭型借鉴 | 结构和人设一起搬 | 只借结构，人物、场景、破局手段必须换（见 21 版权底线） |
