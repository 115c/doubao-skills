# 18 · 跨媒介：互动小说、漫剧改编、有声、出海

> 小说写完后，第一件可变现的事不是"再写一本"，是**换一种载体再讲一次**。
> 换载体不是翻译，是**重写**：每种载体的时间单位、信息密度、成本都不一样。

## 一、互动小说（分支叙事）

### 1. 先定状态，再定分支

```
变量表（3-5 个，不超过 7 个）
| 变量 | 取值 | 影响什么 |
| 信任 | -2..+2 | 决定能否说服某人 |
| 线索 | 集合 | 决定能否看破真相 |
| 时间 | 剩余回合 | 决定能否救到人 |
```

**没有变量的选择＝假选择。**读者选完什么都没变，下次就不认真选了。

### 2. 分支设计四条

| 条 | 规则 |
|---|---|
| 每个选择有代价 | 选 A 得到 X 失去 Y，不许"都得到" |
| 不可回退 | 不给"重新选择"，给"承受后果" |
| 每节点 2-3 个选项 | 超过 4 个读者会瘫；1 个不是选择 |
| 汇合点固定 | 每 3-5 个节点必须汇回主线，否则组合爆炸 |

### 3. 结局四型（至少两个，其中一个必须是"坏结局但合理"）

- 达成型（达成目标）
- 代价型（达成但失去）
- 认知型（知道了真相，处境没变）
- 崩塌型（失败且知道为什么）

### 4. 成本控制

分支数不是越多越好。**5 个关键选择 × 每处 2-3 条路径**，配 3 个结局，就是一部合格的中篇互动小说。超过这个量，写作成本翻倍而体验提升有限。

## 二、漫剧／短剧改编

### 1. 转换原则

| 小说 | 漫剧／短剧 |
|---|---|
| 心理描写 | 必须转成**可见动作、台词、旁白**，不能留"她心里很乱" |
| 长段铺垫 | 压成 1-2 个镜头 |
| 一章 3000 字 | 一集 1-3 分钟，**每集一个钩子** |
| 多线并行 | 一条主视觉线，其余压成背景 |
| 叙述者评论 | 删，或改成角色台词 |

### 2. 每集结构（1-3 分钟）

```
0-10 秒：钩（承接上集或抛异常）
10-60 秒：冲突推进（一到两个回合）
60-90 秒：反转或加压
最后 5 秒：钩子（下一集必须回应）
```

### 3. 改编自查

- [ ] 每集是否只有一个"必须看下一集"的理由
- [ ] 是否有无法视觉化的段落（大段内心、抽象议论）
- [ ] 角色是否能用**一个外形特征**被认出（发型、衣物、道具）
- [ ] 场景数是否超出预算（每集 ≤3 个场景）
- [ ] 对白是否超过字数上限（按平台与配音时长折算）
- [ ] 有没有必须靠旁白才能讲清的信息（超过两句就是没改好）

需要镜头表、导演台预演、分镜提示词时，交给 `manju-director` 技能，本模块只负责"小说→可视化脚本"的转换判断。

## 三、有声／广播剧改编

| 项 | 要求 |
|---|---|
| 听觉可辨识 | 同一场多人对话必须靠称呼与语气区分，不能靠"他说" |
| 时间感 | 用声音（脚步、门、雨）替代视觉转场 |
| 旁白比例 | ≤20%，且只交代无法演出的事 |
| 章节切分 | 按"听 10-15 分钟一个钩"重新切，不按小说章 |
| 音效 | 只保留推动情节的，不为氛围堆 |

## 四、出海／翻译

### 1. 四类处理

| 类型 | 处理 |
|---|---|
| 文化专有词（称谓、节庆、器物） | 保留＋首次出现用一句上下文解释，不写译名注释 |
| 成语典故 | 换成本地等效表达；没有等效就直说意思，不硬造 |
| 计量与货币 | 换算成读者能感知的量（"够交两学期学费"） |
| 人名地名 | 拼音保留，长度压到 2-3 音节；每章不要新增超过 3 个新名 |

### 2. 翻译三不要

1. **不要逐句直译**：中文的短句连排在英文里会碎，需要合并。
2. **不要把所有文化词都注掉**：注释会打断阅读。
3. **不要为过审改剧情**：改剧情是改编，不是翻译，两件事分开报。

### 3. 出海前的结构检查

- 前 3 章的信息密度是否过高（外语读者对陌生名词的耐受更低）
- 是否依赖中文语感（谐音、双关、诗词）才能成立的段落——这些必须改写
- 章节长度是否符合目标市场习惯（很多市场偏好 1500-2500 词的章节）

## 五、跨媒介改编的共同底线

1. **母题不变，事件可换**：改编可以换场景、换顺序，但不能换掉"这个故事到底在讲什么"。
2. **不许为规避平台识别做机械改写**（换词、打乱句序、抽帧镜像变速），这是作弊，不是改编。
3. **署名与授权**：改编他人作品必须获得授权；自己的作品改编，保留原始版本与授权记录。
