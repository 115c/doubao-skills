# 19 · 提示词库（可直接复制）

> 用法：把 `{}` 里的内容替换成你的实际信息，一次性发给我（或任何写作模型）。
> 每个模板都自带"不许做什么"，因为不写禁令的提示词一定会被模型注水。

## 1. 选题诊断

```
你是网文策划。这是我的点子：{一句话}
请只做诊断，不写正文：
1) 压成：题材／子类型、卖点、一句话 hook、premise（四段：谁／处境／被迫做什么／否则失去什么）、故事引擎
2) 故事引擎必须能列出 20 个不重复的事件，先列 5 个给我看
3) 给红黄绿判定（卖点唯一／引擎自转／主角不可替代），并说缺什么
4) 给规模建议：形态／字数／卷数
禁令：不要夸这个点子好；不要给世界观大设定；不要写正文。
```

## 2. 世界观体检

```
这是我已有的设定：{贴设定}
按四条检查，逐条给结论：
1) 每条规则能不能在某章真的挡住人物？指不出来的删
2) 每项能力有没有必须支付的代价？没付过的补一条
3) 四类势力（学本事的／变现的／试刀的／往上走的）缺哪类
4) 顶层标尺是否一致，有没有过早出现"全书最强"
输出：保留几条、删几条、补几条。禁令：不要新增设定，只做减法与补代价。
```

## 3. 卷纲

```
书名/类型/平台：{}；本卷目标字数：{}；本卷起止状态：从{}到{}
按八步结构出卷纲，必须给我：
- 本卷最大高潮在第几章（3/4 处）
- 4 个关键点（1/4 激励、中点逆转、3/4 转折、卷末高潮）各落哪章
- 每章一行：章号｜功能标签（爆发/推进/修炼/感情/日常/过渡）｜一句话情节点｜章尾钩子类型
- 爆发章占比、日常章占比
禁令：不要每章都写"冲突升级"；不许排超过 80 章；不许让本卷反派提前出场。
```

## 4. 章纲

```
第{N}章。本章功能：{标签}。上一章停笔点：{一句话}。本章必须发生：{1-3 件}。本章禁止发生：{…}
按字段出章纲：
章号｜标题｜功能标签｜结构拍｜情节点(3-6条,每条"谁做了什么导致什么")｜场景outcome(yes/yes-but/no/no-and)
｜章尾钩子(13式之一+落点一句话)｜本章埋/收(编号)｜字数范围｜停笔点
禁令：情节点不许写成"主角感到…"；停笔点不许是总结句。
```

## 5. 写正文（单章）

```
按这份章纲写第{N}章正文，{2100-2300} 字。
硬规则：
1) 第三人称贴身限知，只写主视角看到、听到、算到的
2) 情绪用四条通道之一（直写情绪／利害算账／台词与选择／有后果的动作），禁止用指尖一颤、瞳孔一缩这类微动作代偿
3) 密处（爽点/反转）逐拍写，不许用"激战数十回合""众人哗然"折叠
4) 章尾停在最后一个具体决定、动作、台词或画面上，不许写"他终于明白"
5) 同段超过 3 个动作要用"先…才""一…就"接成一句，不许写成逗号清单
6) 不许出现"他不知道的是""殊不知""命运的齿轮"
先给我 200 字开场，我确认后再续。
```

## 6. 去 AI 味（三层）

```
只改表达与用笔，不动剧情。原文：{贴}
按三层报：
- 表达：哪句读起来别扭／套式（给原句）
- 用笔：哪处该密被写疏、哪处该略写满了（给原句）
- 故事：哪里人物行为没有依据（只报，不改）
然后给我改后版本 + 2-4 组"原文 vs 改后"对照。
禁令：不许用新的微动作制造真人感；不许为清零把信息删残；不许把请求改辱骂、解释改挑衅。
```

## 7. 审稿

```
按六维评分（0/1/2）：母题卖点／结构位置／场景变化／人物依据／情绪落地／章末拉力与语言。
再查平庸清单 12 条命中几条。
然后五个读者各问一句并回答：老读者（上章等的事给了吗）／新读者（知道他在干什么吗）／挑刺者（哪步不信）／重度用户（套路见过几次）／编辑（能上推荐位吗）。
输出：总分、硬线是否通过、三个最贵的问题（位置＋后果＋最小改法）、不建议改的部分。
禁令：不许说"整体不错"；每条批评必须指到原句。
```

## 8. 一致性体检

```
这是我的追踪数据：{贴 _state.json 或伏笔表}
检查并列出：
1) planted 但未 paid-off 且超过 20 章的伏笔
2) 人物状态冲突（死了还在出场／伤好了没交代）
3) 时间线倒序未标注
4) 章节缺号
5) 章纲 outcome 连续 3 章 yes、章尾连续 3 章 resolution
硬错误与提示分开列。禁令：不要替我改，只出清单。
```

## 9. 短篇

```
写一个 {3000} 字短篇。一个主导变化：主角从{}变成{}。单一效果：{读完只剩一个情绪}。
结构：钩10%／立20%／转35%／顶20%／收15%。
禁令：人物≤3；场景≤4；前 3 行必须有钩；结尾不解释不总结；不许写"后来他们…"。
```

## 10. 书名与简介

```
题材：{}；核心冲突：{}；目标读者：{}；平台：{}
给 5 个书名，每个用不同打法（核心冲突／主角特征／意象／反差／留白），2-8 字。
再给 3 版简介，每版三句话：身份处境／异常或代价／承诺（不写结局）。
禁令：不许 XX之道/XX觉醒/XX纪元；不许"且看主角如何"；不许剧透反转。
```

## 11. 互动分支

```
把这个故事改成互动小说。给：3-5 个状态变量（含取值范围与影响）、5 个关键选择（每个 2-3 选项且各有代价）、
每 3-5 节点一个汇合点、3 个结局（其中一个是"坏但合理"）。
禁令：不许有"都得到"的选项；不许给重新选择；总节点不超过 40。
```

## 12. 改编漫剧

```
把第{N}章改成 1-3 分钟一集的分集脚本。每集给：时间码／画面（可视化的动作）／台词／钩子。
原则：心理描流转成可见动作或台词；每集一个钩；每集场景≤3。
禁令：不许用旁白交代超过两句；不许保留无法视觉化的段落。
```
