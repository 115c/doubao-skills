# 06 · 开篇：前 6000 字定生死

> 读者不是被"文笔"留下的，是在**前 300 字**决定要不要往下滑。
> 开篇不是"故事开始之前"，开篇就是故事的第一个事件。

## 一、三个成交窗口

| 窗口 | 必须给出 | 验收 |
|---|---|---|
| 前 300-500 字 | 一个**抓手**：异常、冲突、危机、反差、一句钩子 | 读者会问"怎么会这样" |
| 前 1500-3000 字 | 一个**卖点**：这本书最值钱的那口体验（爽／甜／怕／烧脑） | 读者能说出"这书是看什么的" |
| 前 6000 字 | 主角是谁、遇到什么、卖点是什么、接下来想看什么 | 四问全答得出 |

**"慢热"不是风格，是风险。** 除非你的卖点本身就是氛围与人物，否则不许在第 3 章之后才给爽点。

## 二、黄金三章的分工

| 章 | 任务 | 必须发生 | 禁止 |
|---|---|---|---|
| 第 1 章 | 立主角＋立危机＋立卖点 | 一个不可回避的麻烦落到主角身上 | 大段世界观、家族介绍、回忆 |
| 第 2 章 | 让主角**做出选择**并付出第一次代价 | 一个明确决定，一个即时后果 | 主角被推着走、全程被动 |
| 第 3 章 | 亮出本书的核心机制（金手指／关系／规则／谜） | 读者第一次看到"这本书独有的东西" | 机制只提不用 |

第 3 章结束时，读者应该已经知道：**这本书爽在哪、主角要干什么、他要对付谁。**

## 三、7 种开局（选一种，不要混合）

| 开局 | 首句／首段形态 | 适合 | 注意 |
|---|---|---|---|
| 未完成动作 | 动作进行中被截断（刚要开口，被人从身后捂住嘴） | 强情节、悬疑、动作 | 截断后必须立刻给新变量 |
| 危机压身 | 主角已经在麻烦里（退婚书摔在脸上） | 爽文、复仇、打脸 | 危机要有具体对方 |
| 悬念对话 | 直接从一句意味深长的话开始 | 都市、言情、关系戏 | 对话必须带信息，不是耍帅 |
| 倒计时 | 开头就建立时间压力 | 追逃、任务、竞赛 | 倒计时必须在章内推进 |
| 反差场景 | 两个截然不同的场面并列 | 双线、身份反差 | 两处必须在本章接上 |
| 异常日常 | 日常里出现一处不对（第三个杯子自己满了） | 悬疑、规则怪谈、恐怖 | 异常必须可被追问 |
| 意象预示 | 环境意象暗示即将发生的事 | 文学、氛围向 | 只在本章行动被环境卡住时用，不写天气开场 |

**首句三不要**：不要天气、不要"在某某年间"、不要"她是一个……的女孩"。

## 四、事件密度（最容易被忽略的硬指标）

密度＝**一段里发生几件事**，不是把一件事拆成十句。

```
❌ 低密度（1 件事／100 字）
"她是尚书府的大小姐，从小聪明伶俐，深得父亲喜爱。这一天，家里来了一位传旨的太监。"

✅ 高密度（4 件事／50 字）
"他替皇家当了七年人质，回京那天母后已经吊死冷宫，五岁幼子被亲弟弟打得痴傻，他提刀就闯进了东宫。"
```

四件事用逗号连成一句，照样是高密度。**断句不等于密度。**

## 五、开篇自查（写完前三章逐条过）

| 检查 | 不合格就改 |
|---|---|
| 第 1 章前 300 字有没有一个"不对"？ | 补异常或补冲突，不要补描写 |
| 主角在第 1 章有没有做一件**主动**的事？ | 把被动挨打改成主动试探 |
| 卖点在前 3000 字露头了吗？ | 把最能代表本书的那场戏提前 |
| 有没有超过 3 句的纯设定说明？ | 拆成动作、对话或文件 |
| 有没有出现 3 个以上需要记住的新名字？ | 前 3 章主要角色 ≤5 人 |
| 第 3 章结尾读者知道该期待什么吗？ | 补一个明确的目标或威胁 |
| 首章结尾有没有钩子？ | 见 08，第 1 章必须用强钩子 |

## 六、五种开篇死法

| 死法 | 症状 | 处置 |
|---|---|---|
| 传家谱式 | 先讲三代人、五个家族 | 全删，把必要信息拆到事件里 |
| 回忆式 | 从十年前那场雨讲起 | 从"现在正在发生"的那件事讲起，回忆当插入 |
| 设定说明书 | 前两页解释力量体系 | 只留能影响本章行动的两条 |
| 主角隐身 | 前 1000 字没有主角的动作 | 让主角在第一段内做一件事 |
| 假高潮 | 开场大战场，与主线无关 | 要么让它与主线有关，要么删 |
