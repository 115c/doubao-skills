# 11 · 去 AI 味：三层诊断与可执行修法

> 去 AI 味不是"润色"，是**把三件事分开治**：表达（读起来别扭）、用笔（笔墨没有重心）、故事（人物行为没有依据）。
> 三条纪律：**不为清零机械改稿；不用新的微动作制造"真人感"；不把"去 AI 味"理解成故意粗糙。**

## 一、三层诊断

| 层 | 检查什么 | 典型症状 |
|---|---|---|
| 表达 | 词句、声口、机械复现、电报体 | "不是A而是B"成段用；每个动作后面都"了一下"；句子全是短碎句 |
| 用笔 | 场景作用、详略、关键过程 | 该密的爽点被一句概括；不该写的流程全写；每段都贴着情绪标签 |
| 故事 | 行为、因果、立场、变化、后果、知情顺序 | 人物突然让步没有触发；关键决定没有前提；后果不落地 |

**顺序**：先判故事成立条件，再安排场景用笔，最后处理词句。反过来改，会把结构问题误修成文风问题。

## 二、处置三级（不要把"能改"和"该改"混了）

| 级别 | 含义 | 处置 |
|---|---|---|
| 可直接修 | 词句、承接、详略 | 直接改 |
| 需设计、未授权 | 改变事件、动机、结果、新增成立条件 | 只出方案，等授权 |
| 资料不足 | 无法核实前文 | 标"无法核实"，不许编 |

普通去味允许：修表达、恢复已有承接、调整已定内容的详略、删除整段无功能内容。
**保护项（不许动）**：伏笔、因果、人物选择、情绪体验、揭露顺序。

## 三、句式与组织信号（会误判，必须回上下文）

| 信号 | 检索形式 | 要确认什么 |
|---|---|---|
| 否定翻转 | 不是A，（而）是B；没有X，没有Y，只有Z | 是否先否定无人在意的靶子再宣布结论 |
| 工整并列 | 有的……有的……；一边……一边……；不V A，不V B | 是否重复同一意思或照抄提纲 |
| 万能状语／声线 | ，带着……；声音不大，却带着……；语气毫无波澜；平静得像在念…… | 是否只贴抽象态度，没有可辨内容 |
| 引号强调 | "机会""答案""蜕变" | 是否虚造术语或替读者划重点 |
| 解释结论链 | 这意味着；真正重要的是；之所以……是因为；他终于明白；这才意识到 | 是否重复读者已得到的意思 |
| 意义膨胀 | 意义深远；可谓；未来可期；一切……都……；这就是…… | 是否只扩大分量，没有具体影响 |
| 抽象收束／预告 | 命运＋齿轮／棋局／獠牙；这一刻终于明白；他不知道的是；殊不知；多年以后；仿佛预示着 | 是否越过本次揭露边界 |
| 隐性盖章 | 关切得恰到好处；笑得恰如其分；谁都看得出他在撒谎；像在宣判早已定好的事 | 是否替读者提前判定潜台词 |
| 告知与气场 | 他知道……；她感到……；显得（有些）X；浑身散发着一股X气息 | 是否只贴感受与标签 |
| 电报体 | 连续孤立短句；抬手、取过、放下、转身 | 是否丢失动作方向、对象与连接 |
| 论述腔 | 不难看出；事实上；综上所述；与此同时；机制；结构；体系；从而 | 是否与人物、年代、载体语域不合 |

## 四、套词与套式反应（连刷扎堆才算病）

| 类别 | 词例 |
|---|---|
| 弱化装饰 | 微微、淡淡、缓缓、轻轻、一丝、一抹、些许、几分、隐约、微不可察、毫无征兆 |
| 通用反应 | 深吸一口气、眼中闪过、嘴角勾起、嘴角微扬、脸色一变、眉头微皱、瞳孔一缩、指节泛白、指尖轻叩、攥紧袖口、目光移开、头皮发紧、眼皮一跳、心口一沉 |
| 通用心理 | 心头一震、心中一动、心下了然、心中暗道、心底泛起、心中一凛、不由得、涌起一股暖流 |
| 空泛定性 | 不容置疑、不容置喙、显而易见、毫无疑问、前所未有、闪烁着光芒、狡黠、深邃、凛冽 |
| 模板比喻 | 仿佛／犹如／宛若……一般、如潮水般、如闪电般、仿佛春风、像命运的齿轮、梨花带雨、如沐春风 |
| 自动过渡 | 映入眼帘、只见、此时此刻、不由自主、情不自禁、话锋一转、取而代之的是 |
| 语境敏感 | 突然、陡然、骤然、瞬间、猛地、死死地、好像、似乎、沉声道、淡淡地说 |

**判据**：单章偶发且贴合现场，不判错；**连刷扎堆或充当万能情绪翻译器**才改。
"她感到""意识到""知道""原来""仿佛"都可能准确表达感受、判断、发现与视角置信度——**只凭词不能定罪**。

## 五、退化检测（比词表更硬的病）

| 退化 | 症状 | 处置 |
|---|---|---|
| 逐字复读 | 同段同句反复出现 | 重写受损段，核对既有事实 |
| 打转 | 换词说同一件事，不推进 | 删重复，补推进 |
| 截断 | 句子中断、末尾无收 | 补完或删掉 |
| 占位符／工程词泄漏 | "此处可补充""待定""TODO""[XXX]" | 清干净，不许交付 |

## 六、标点谱系（跟着语气走）

| 语气／功能 | 可用 | 连法 | 禁忌 |
|---|---|---|---|
| 压迫／冷静／克制 | 句号、逗号、冒号 | 陈述＋逗号接动作与判断，冒号落判断 | 不为"有变化"乱加 `！` |
| 疑问／反问／算账 | 问号、逗号 | 正常发问、试探、反问、内心盘算 | 连五六句反问刷屏 |
| 命令／爆发／打脸 | 少量感叹号 | 重拍落点用 1 个 `！` | `!!!`、整段喊叫 |
| 犹豫／留白／面板 | `……`、逗号 | 对话吞吐、面板提示、偶发停顿 | 旁白连刷 `……` |
| 被打断／拖音 | 对话内 `——` 或 `……` | 引号内收于 `——`／`……`，接截断它的动作 | **叙述段不用** `——`／`—`／`--` |
| 信息揭示 | 冒号、句号 | "证据只有一个：门锁从里面扣上了。" | 论文式长分号链 |

**扫尾法**：精修时扫一遍句尾——整段只剩句号，检查是否把疑问、盘算、爆点压平；满屏 `？`／`！`，删到只留有功能的位置。

## 七、执行流程（五步，最多三轮）

1. **读原文＋三层扫描**：先跑 `scripts/novel_check.py --ai` 拿线索，零命中**不代替**人工三层扫描。
2. **定位与定法**：每条记"位置＋读起来的后果＋缺什么依据＋最小改法"，分处置三级。
3. **按授权改**：文件模式先备份原文到 `.work/去味原稿/{日期}_{原名}`。
4. **回读＋复扫**：对照改前原稿回读事实、人物选择、因果、情绪承接、空间方向、悬念；再跑机检。**信息齐全却仍逐项播报、对白仍像提纲，表达层不算完成。**
5. **标点整理**：语义改完、无 blocking 后再整标点。

三轮上限：只为新发现的具体问题继续修，没有新问题就停；到上限仍未解决的写进报告，不假装通过。

## 八、报告模板

```
## 改稿结果
- 表达：改了什么；哪些有效写法保留
- 用笔：哪处压缩、哪处展开，为什么
- 故事：已修的承接；仍需设计或无法核实的部分

### 代表性改动（2-4 组，原文 vs 改后，说明读者体验变化）

### 尚需处理（位置、缺什么、最小选项、影响后文）

改前原文留在 {备份路径}，想撤回告诉我。
```

## 九、禁令（做错了会毁稿）

1. **不许用新微动作、粗话、证据或冲突制造"真人感"**。
2. **不许为了归零把信息删残**（"白色的药片""手里那截链子"这类修饰承担区分功能）。
3. **不许全文机械替换**（把每个情绪词换成同一个微动作）。
4. **不许把请求改辱骂、解释改挑衅、凭空补锁门录音与群体动作**。
5. **没有的检查不许宣称通过**；脚本跑不了要如实说明。
