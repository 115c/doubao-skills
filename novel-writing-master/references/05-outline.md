# 05 · 大纲工程：卷纲刻度、章纲字段、节奏标签

> 大纲不是把故事写一遍，是**决定每一章承担什么功能**。
> 没有章纲的长篇一定出这五个病：支线乱长、设定膨胀、章末疲软、追更点断掉、中段发散。

## 一、刻度（先定数，再排章）

| 刻度 | 体量 | 用法 |
|---|---|---|
| 单章 | 快节奏档 2100-2300 字；均衡档约 3000 字 | 平台单章底线多为 2000 字；本书已有惯例按惯例 |
| 一段剧情 | 1.5-3 万字，约 5-15 章（开篇那段偏短） | 一个矛盾从起到收；出现两个独立高潮就拆段 |
| 每次兑现 | 3-6 章走完一次起势到兑现 | 兑现后可排 1-2 章低压过渡 |
| 大高潮 | 快节奏 14-20 章；均衡档不超过约 10 万字 | 拖久必掉追读 |
| 卷 | 约 4 个大高潮周期，50-80 章；超 100 章先拆卷 | 只精排当前卷，后续卷写功能与字数区间 |
| 全书 | 卷数 × 卷字数 ≈ 目标字数 | 不预排全书章号 |

## 二、关键点：四个位置

全书、卷、剧情段、章都有五处：开场、1/4、中点、3/4、结尾。中间三处放关键情节：

| 位置 | 放什么 | 不合格的样子 |
|---|---|---|
| 1/4 | **激励**：打破平静、逼主角上主线 | 还在铺垫、还在交代设定 |
| 中点 | **逆转**：用前文伏笔反败为胜，顺应期待且解法巧 | 天降帮手、突然觉醒 |
| 3/4 | **转折**：新信息或外力介入，把局势推向意外 | 只是"更难的同一件事" |
| 卷末 | 本卷最大高潮＋余波＋跨卷奖励 | 高潮在倒数第二章就打完，最后一章总结 |

**付费平台先定上架卡点高潮，再倒推开头。** 卡点前不写无关打脸，反派要围着卡点转。

## 三、每章松还是紧（功能标签）

"紧"指冲突烈度，与情感烈度分开：关系章、泪目章可以"松"而情感顶满。

| 标签 | 干什么 | 卷内占比（均衡档基线） | 章尾钩子 |
|---|---|---|---|
| 爆发 | 打脸、掉马、反转、高潮 | 15-20% | 强钩子，承载逆转／转折 |
| 推进 | 主线推进、冲突升级 | 40-50% | 中钩子，至少一个小爽点 |
| 修炼 | 实力／资源积累、试错 | 5-10% | 进度钩子（差一点） |
| 感情／关系 | 感情兑现、关系转折 | 5-10% | 情感钩子，仍要扣主线 |
| 日常 | 高潮后喘息、关系升温 | ≤10% | 允许弱钩子 |
| 过渡 | 转场、交代、缝合时间 | ≤5%，能并章就并 | 允许无爽点，结尾给下一段目标 |

三条铁律：

1. **期待不断，爆发可散**：松的章可以没爽点，但每章都要留往下看的理由。
2. **同一情绪母题不许连超 2-3 章**（家国、泪目、憋屈），靠换情绪与换钩子拉开，不靠砍钩子。
3. **题材分档**：番茄短平快、男频事业线爆发章可到 30% 以上；女频感情戏与日常章可更多，那本身就是看点。

## 四、卷结构三型

| 型 | 特征 | 适合 |
|---|---|---|
| 单元串联 | 单元各自完整，靠核心爽点与讨喜人设串，暗线托长线 | 无敌文、日常文 |
| 卷内套娃 | 每段是带爽点的小单元，同时给本卷大故事铺垫，卷高潮一起引爆 | 升级文、悬疑文 |
| 过渡型 | 开局单元串联，后期转强主线 | 长线养成 |

每卷先定**主角目的**与**本卷最大高潮**（常在 3/4），拉开起止状态反差。升级文可按"入口条件→核心挑战→关底对手→通关奖励"排卷。

## 五、主线、支线、暗线

- 本卷大冲突拆成阶段小冲突排成主线，每阶段留一个未解决冲突推着主角走。
- 支线必须是完成主线的**手段**，最终汇回主线。
- 全卷：主线＋感情线＋1-2 条支线或暗线，共 3-4 条。
- 暗线（反派布局／隐藏真相）从首次出现埋伏笔，在卷高潮与明线交汇。
- 主线暂歇时支线接上；单线触顶时双主线交替升级（破案涨实力，实力引大案）。

## 六、剧情单元设计（每段先答五问）

1. 核心情绪是什么（爽／甜／虐／怕／惊）？
2. 具体缺口是什么人／什么物？
3. 此前为何未解？
4. 本次导火索是什么？
5. 主角不可替代的行动与兑现是什么？

**四步抓人法**：写清主角搭进多少心血 → 眼看办成被谁卡住 → 成败怎么改写关系 → 合乎情理的反应。不靠堆死人、绝症、哭喊。

**相邻两段换破局手段**：每段运行一次核心梗或推进铺垫，A 段埋 B 段的苗头；不要让每个单元都人格蜕变一次。

## 七、升级轴与对手梯队

- 先列本卷起止的身份、地位、资源，反向铺缺口（道具先写稀缺、地位先写待遇差、人物先写分量）。
- 循环：挑战 → 道具/资源 → 升级 → 新挑战。每次升级在**能力、待遇、人际**里至少体现两项差别；单段重点升级 ≤3 次。
- 实力涨而周围认知未跟上 → 排打脸，由环境与旁人确认变强。
- 对手梯队：B 胜 A → C 胜 B → 主角胜 C → 引出更大对手。友方、中立、敌方依次表态或出手，主角最后改写各方态度。
- 以弱胜强要铺垫；强强对决一大段最多一次。

## 八、中段加压四法（轮换用）

| 法 | 做法 | 效果 |
|---|---|---|
| 公开升级 | 把冲突搬到家宴、大比、直播等公开场合 | 输了不只丢脸，还丢位置 |
| 双重背叛 | 已知的背叛上再揭一层 | 让"已经最坏"变成"还能更坏" |
| 代价加速 | 不行动的代价随时间递增 | 逼主角必须动 |
| 战略性沉默 | 暂不反击，令对方更放肆 | 蓄力，为反转攒势 |

加压段必须让读者**看见翻盘筹码**，否则是纯虐。

## 九、期待链与收卷／开卷

- 主线拆成接力大钩子，前一个兑现前立起下一个；兑现按单元高潮、卷高潮逐级加码。
- 多视角或有限全知可向读者明写反派计划、只瞒主角；默认贴身限知时，靠主角察觉的迹象、旁人传话或后果让读者先起疑。
- 收卷：写高潮余波与跨卷奖励，留 1-2 条未解麻烦或伏笔钩住下卷。
- 开新卷：先承接上卷未兑现的期待与待收伏笔；**最终卷不再新增主矛盾**。

## 十、MICE 收口（判断"这故事该在哪结束"）

四条线各有自己的开与合，开在谁身上，就得在谁身上合：

| 线 | 开（进入） | 合（离开） |
|---|---|---|
| M milieu 环境 | 进入一个新世界／新地图 | 离开它（回到原世界或换下一个） |
| I inquiry 疑问 | 提出一个谜／问题 | 回答它 |
| C character 人物 | 人物对自身处境不满 | 人物改变了处境或自身 |
| E event 事件 | 一个外部危机开始 | 危机结束、秩序恢复 |

**用法**：全书主线的 MICE 类型决定高潮形态。事件线（E）故事靠"打赢／解决"收；疑问线（I）靠"揭真相"收；人物线（C）靠"选择改变"收；环境线（M）靠"离开／归来"收。
四条线都要在结局前合上，**漏合一条就是烂尾**；最后 1-2 章不要再开新线。

## 十一、章纲字段（统一表头，不许缺列）

| 字段 | 必填 | 写法 |
|---|---|---|
| 章号 | ✓ | 连号，不跳 |
| 标题 | ✓ | 具体名词或动作，不写"风波""变故" |
| 功能标签 | ✓ | 爆发／推进／修炼／感情／日常／过渡（见第三节） |
| 结构拍 | ○ | 该章承担的节拍名（激励／中点／一切尽失…） |
| 情节点 | ✓ | 3-6 条，每条一个"谁做了什么导致什么" |
| 场景 outcome | ✓ | yes／yes-but／no／no-and（见 07） |
| 章尾钩子 | ✓ | 13 式之一＋一句话落点（见 08） |
| 本章埋／收 | ✓ | 伏笔编号（无则写 0） |
| 字数范围 | ✓ | 如 2100-2300 |
| 停笔点 | ✓ | 最后一个决定／动作／画面，不许写"他明白了" |

章纲写完用 `scripts/pacing_grid.py` 出网格，检查：连续 3 章 yes、连续 3 章 resolution 结尾、缺钩子、字数离群、节拍扎堆。

## 十二、拆书（拿一本对标，拆成可复用的东西）

六步，每步出一张纸，不是写读书笔记：

1. **选本**：同题材、同平台、成绩在你目标之上，但别挑十年一遇的神作（学不来）。**一本只拆一件事**——结构、章法、规则体系，挑一样。
2. **先定统计口径再动手**：章数、每章汉字均值／中位、对话占比、均句、均段、章末句式分布、章首开场分布、付费信号首见章（上架／打赏／推荐票／订阅／月票）。用 Python 跑一遍，别手数。
3. **抽 20 章标钩子**：逐章对 13 式（08），算强钩比例；再看章末最后一段平均字数。
4. **盘规则体系**：给了几个名？有没有总数与计数器？每条规则第一次出现在第几章、怎么当场演出来的？
5. **写成卡**：只留"可复制做法＋数字＋出处章号"，**不抄句子**（硬规则 18）。存 `references/benchmark/<书名>.md`，格式照 `benchmark/阴阳鬼咒.md`（含复现思路）。
6. **对照己稿**：列硬差距（章长／对话／钩子强度／情报密度），逐条标"已处理"或"不处理＋理由"。不处理不许沉默。

拆完必须能一句话答出：**这本书靠什么让读者点下一章？** 答不出＝白拆。

> 反向用法：文字成绩差的书也能拆，拆它"哪一步先崩"，直接落进 22 坑库。
